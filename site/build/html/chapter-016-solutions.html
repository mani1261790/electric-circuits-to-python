第16章 演習解答

E1

完全解答

周期ポテンシャルは、位置を格子間隔aだけずらしても同じ位置エネルギーを返すという意味である。a=0.5 nm=5.0×10^-10 m。したがってka=(2.0×10^9 m^-1)(5.0×10^-10 m)=1.0で無次元となる。ここでVは位置エネルギーなので単位はJまたはeV、kは1/mである。電位V（volt）と混同しない。

再挑戦

a=2 Å、k=π/aのときkaはいくつか。aをmへ直した場合のkの単位も書け。

E2

完全解答

ψ_k(x+a)=exp(i k(x+a))u_k(x+a)。周期性u_k(x+a)=u_k(x)を使うと、ψ_k(x+a)=exp(i k a)exp(i k x)u_k(x)=exp(i k a)ψ_k(x)となる。複素指数の絶対値は|exp(i k a)|=1なので、|ψ_k(x+a)|²=|ψ_k(x)|²である。従ってBloch境界は波動関数の振幅・位相まで毎回同じという条件ではなく、胞を移ると位相が変わることを許す条件である。

再挑戦

ka=π/2とka=πで、隣の胞へ移ったときの位相因子を複素数で書け。どちらも確率密度を変えないことを確認せよ。

E3

完全解答

周期境界からexp(i k L)=1、従ってkL=2πmであり、k_m=2πm/(N_cell a)となる。N_cell=4なら、第一Brillouin領域の代表kは4個である。例えばm=−2,−1,0,1を選ぶ半開区間なら、k=-π/a, -π/(2a), 0, π/(2a)となる。端点の取り方を変えてm=−1,0,1,2としても、k=π/aとk=-π/aが周期的に同値なので重複を一つ除けば4個である。a=0.5 nmは状態数を変えず、kの数え上げを単位付きにする。

再挑戦

N_cell=10のとき、kの間隔と一バンドの状態数を式で答えよ。スピン二種類ならスロット数はいくつか。

E4

完全解答

係数c_n=exp(i k n a)を使うと、右隣はc_{n+1}=exp(i k a)c_n、左隣はc_{n-1}=exp(-i k a)c_nとなる。Hamiltonianの作用は[epsilon-t exp(i k a)-t exp(-i k a)]c_nなので、exp(iθ)+exp(-iθ)=2cosθからE(k)=epsilon-2t cos(ka)。epsilon=0、t=1 eVなら、k=0でE=−2 eV、k=π/(2a)でE=0、k=π/aでE=+2 eV。バンド幅は2−(−2)=4 eV=4|t|である。

再挑戦

tを−1 eVへ変えたときの端のエネルギーを求め、バンド幅が変わらず、最小位置が入れ替わることを説明せよ。

E5

完全解答

上三角の要素は-t(1+exp(-ika))、下三角は-t(1+exp(+ika))で、実数tなら互いに複素共役である。対角要素は実数なのでH=H†。ゾーン境界ではka=π、cos(π/2)=0であり、固有値はepsilon_A=0 eVとepsilon_B=0.4 eV。ギャップは0.4 eVである。一般式では|epsilon_A-epsilon_B|。epsilon_A=epsilon_Bなら境界で二つの固有値が一致し、この模型ではgap=0となる。gap=0は有効な物理パラメータであり、数値エラーではない。

再挑戦

epsilon_A=0.2 eV、epsilon_B=−0.2 eVで、k=0とk=π/aの固有値を式(16.9)から書け。t=1 eVとする。

E6

完全解答

バンドの占有はf(k)=1/[exp((E(k)-μ)/(k_B T))+1]。スピンを縮退2として代表kだけを数えるなら、N=sum_k 2 f(k)である。k状態が各バンドにN_cell個あるので、満杯ならN=2N_cell。スピンを状態ラベルへ含める場合はN=sum_{k,s} f(E(k))とし、s=↑,↓を個別に足す。この表記ではさらに2を掛けない。どちらでも、k状態数とスピン状態数を一度だけ数えることが重要である。

再挑戦

二つのバンドn=±とスピン縮退2を代表表記で使うときのNの和を書け。バンドごとにk状態がN_cell個あることも含めよ。

E7

完全解答

δ(E-E(k))はエネルギーについて積分すると1になるので、D(E)の単位はstates/eVまたはstates/Jである。N_cell個の単位胞を持つ一サイトバンドで、スピン一種類のtotal_crystal DOSならエネルギー全域の積分は∫D_total(E)dE=N_cell、per_cell DOSなら1である。スピン二種類ならそれぞれ2N_cellと2になる。数値binを解析式(16.12)と比較するには、total_crystalをN_cell（スピン込みなら2N_cell）で割ってper_cellへそろえるか、解析曲線を同じ係数で拡大する。

再挑戦

二サイト単位胞で上下二バンド、N_cell個の単位胞、スピン二種類なら、全バンドのDOS積分は何か。各バンドだけの積分も答えよ。

E8

完全解答

有限差分の運動エネルギー係数をc=hbar^2/(2*m*dx^2)とし、端点を重複させないM点格子でa=M*dxを満たすとする。擬似コードは次のようになる。

H = zeros((M, M), complex)
for j in range(M):
    H[j,j] = 2*c + V[j]
    if j+1 < M: H[j,j+1] = -c
    if j-1 >= 0: H[j,j-1] = -c
H[0,M-1] = -c * exp(-1j*k*a)
H[M-1,0] = -c * exp(+1j*k*a)
hermitian_residual = max_abs(H - H.conjugate().T)
assert hermitian_residual < tolerance
eigenvalues = eigh(H)

実際には、端点が単位胞を一つまたぐ配置か、全結晶を一周する配置かを先に定義し、a=M*dxと端点非重複を検査してから、位相を掛ける結合を一箇所だけにする。cとVを同じエネルギー単位にそろえ、固有値、境界残差、Hermitian残差、boundary_geometry_mismatchの有無を別々に保存する。

再挑戦

Bloch位相を誤って両方向の端点結合へ同じexp(+ika)で掛けた場合、Hermitian性がどう壊れるかを共役関係で説明せよ。

E9

完全解答

(a)はgrid_convergence_passの兆候で、dx依存の誤差が減ったと分類する。(b)はwave_number_unit_mismatch。kは1/mで入力し、指数のkaを無次元にする。(c)はnon_hermitian_matrixで、端点の共役位相や実数対角を点検する。(d)はstate_count_mismatchで、k点の欠落、bin幅の係数、スピン係数の重複を調べる。(e)はinvalid_lattice_spacingで物理入力を拒否する。(f)はgap_closed_predictionという有効な解析caseであり、失敗ではない。ギャップが数値誤差の範囲で小さいことと、入力Delta=0の厳密なgap=0を区別する。

再挑戦

DOS積分が2N_cellになったが、runnerのspin_degeneracyも2だった。スピンをラベル列挙していないなら、どの設定を直すべきか。

E10

完全解答

E(k)は横軸k、縦軸エネルギーで、単位はkが1/m、EがJまたはeV。波動関数ψ_k(x)は横軸位置xを含む複素振幅で、確率振幅の単位は一次元ならm^-1/2である。D(E)は横軸エネルギー、縦軸states/eVまたはstates/Jで、エネルギー幅あたりの状態数を数える。分散の固有値だけでは、単位胞内のu_k(x)の形、波動関数の位相、外場との行列要素が一般に一意に決まらない。したがってDOSは固有値の数え上げから得られるが、波動関数の詳細は別計算が必要である。

再挑戦

同じE(k)を持つ二つの模型でも、異なるu_k(x)を持ち得る具体的な自由度を一つ挙げよ。測定で区別するには何を追加すべきか。

E11

完全解答

最低限のキーは、artifact_id、status、source_kind、measured、inputs（a、単位胞、t、epsilon、k、境界条件、dx、質量）、equation_ids、predicted（E、gap、DOS、occupancy）、diagnostics（Hermitian残差、境界残差、状態数積分、収束誤差）、runner_version、created_atである。解析式だけならsource_kind="analytic_prediction"、有限差分を手計算または既存数値コードで評価した段階なら"numeric_prediction"、共通runnerが入力由来の契約モデルから生成したら"runner_analytic_contract"とstatus="executed_analytic"。実測があれば別途"measurement"と測定条件を保存する。共通runnerは実行済みでも実測ではなく、measurement.status="not_run"を維持する。計算値を測定値と書くと、装置誤差や試料条件が存在したかのように誤認させる。

再挑戦

解析予測とrunner出力の固有値が一致しなかった場合、artifactを上書きせずに原因追跡できるよう、どの二つの識別子を追加すべきか答えよ。

E12

完全解答

第17章では、バンド端、ギャップ、状態密度を使い、各エネルギーの状態へFermi–Dirac占有を掛けて電子数を積分する。化学ポテンシャルμと温度Tが占有率を決め、伝導帯の電子と価電子帯の正孔を別々に数える。本章から渡せるのは、一粒子バンドと状態数の枠組みである。一方、キャリア密度の実値には結晶の有効質量、体積状態密度、電荷中性、ドーピング、欠陥などが必要で、抵抗にはさらに散乱と移動度が必要になる。したがってバンド図だけで半導体の抵抗を決めることはできない。

再挑戦

100字以内で、バンド端・ギャップ・状態密度・μ・Fermi–Dirac占有の関係と、本章だけでは抵抗が決まらない理由をまとめよ。

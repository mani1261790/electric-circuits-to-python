第17章　真性半導体とキャリア

1　バンドの中の電子と、空いた場所

第16章では、結晶の一粒子エネルギーがバンドに広がることを見た。上側の伝導帯の底をE_c、下側の価電子帯の頂上をE_vと書き、

E_g = E_c - E_v > 0                              (17.1)

をバンドギャップと呼ぶ。真性半導体では、外から不純物を足していない理想化された結晶を考える。温度が0 Kに近いと価電子帯はほぼ満たされ、伝導帯はほぼ空である。温度が上がると、価電子帯から伝導帯へ電子が熱励起される。

伝導帯へ移った電子を電子キャリアと呼び、個数密度をnと書く。電子が抜けた価電子帯の空席を正孔と呼び、個数密度をpと書く。正孔は「電子がない」という記述だが、電場に対して正電荷+eを持つ粒子のように数えられる。電子の電荷はq_e=-e、正孔の電荷はq_h=+eである。nとpは電荷そのものではなく、単位体積あたりの個数で、単位はm^-3またはcm^-3である。

まず、シリコンに似た数値を使った教材用の解析予測を考える。E_g=1.12 eV、T=300 K、有効状態密度をN_c=2.8×10^19 cm^-3、N_v=1.0×10^19 cm^-3と与えると、

k_B T ≈ 0.02585 eV
n_i = p_i = sqrt(N_c N_v) exp[-E_g/(2 k_B T)]
    ≈ 6.5×10^9 cm^-3                         (17.2)

となる。これは採用した有効質量・ギャップ・非縮退近似からの予測であり、装置で測ったシリコンの値ではない。book run 17 1は固定runnerの入力由来契約モデルまで実行済みで、外部domain tool・実測は未実行（measurement.status=not_run）である。

この章の中心問題は次である。

バンドの状態数とFermi–Dirac占有から、真性半導体の電子と正孔をどう数えるか。

第16章からは、バンド端E_c,E_v、ギャップE_g、状態密度D(E)、化学ポテンシャルμ、温度Tを受け取る。第18章では、ここで求めた真性状態へドナー・アクセプタと電荷中性条件を加え、Fermi準位を動かす。

2　電子、正孔、電荷の符号

2.1　正孔は「空席」を数える

伝導帯の電子は、伝導帯の状態を占有する粒子である。価電子帯の正孔は、価電子帯の一粒子状態が空いている割合を数える。エネルギーEの電子占有率を第15章のf(E)とすると、同じ状態の空席の割合は、

h(E) = 1 - f(E)                              (17.3)

である。価電子帯をほぼ満たす低温では、f≈1なので空席hは小さい。伝導帯ではfが小さく、電子数をfで数える。

正孔の「正」は、抜けた電子の電荷をそのまま正に反転したという帳簿上の表現である。電子が電場と逆向きに動いても、正孔の電流への寄与は正電荷が電場方向へ動く形で書ける。pを負にしたり、正孔に電子の符号-eをもう一度掛けたりしてはいけない。

結晶全体の電荷密度を簡単化して書くと、自由キャリアだけなら

rho_free = (-e)n + (+e)p = e(p-n)          (17.4)

である。真性で熱平衡なら、電子と正孔は対になって生成されるのでn=pとなり、自由キャリアの正味電荷は0になる。これは電子と正孔が同じ位置にいるという意味ではなく、個数密度が等しいという意味である。

2.2　真性、熱平衡、非縮退を分ける

「真性」はドナーやアクセプタを指定しない物質の条件、「熱平衡」は一つのTとμで占有を記述する条件、「非縮退」はバンド端の占有が十分小さい近似条件である。これらは同じ言葉ではない。固定した正のE_gを持つ真性模型では、温度を下げるほど両バンド端からμまでの距離をk_BTで割った値が大きくなり、Boltzmann近似はむしろ改善する。高温や高密度では非縮退近似が壊れることがあり、ドープした半導体でも熱平衡ならFermi–Dirac式自体は使える。

本章の質量作用則は、放物線バンド、熱平衡、非縮退、一定のE_gという条件で導く。既定の相対誤差1%を目標にする場合、(E_c-μ)/(k_BT)と(μ-E_v)/(k_BT)をそれぞれ少なくともln(100)≈4.6、実装上は5以上と記録する。許容誤差をδへ変えるなら、対応する目安はln(1/δ)である。高密度でμがバンド内へ入る、またはこの閾値を満たさないときは、Fermi–Dirac積分を数値的に評価し、Maxwell–Boltzmann近似を結果として採用しない。

3　バンド端の状態密度

3.1　伝導帯の三次元放物線

伝導帯の底の近くを、等方的な有効質量m_n^*で近似する。

E_c(k) = E_c + hbar^2 k^2/(2 m_n^*)       (17.5)

m_n^*はkg、kはm^-1、エネルギーはJでそろえる。波数状態を球殻として数えると、単位体積・単位エネルギーあたりの伝導帯DOSは、

D_c(E) = g_c/(4 pi^2) (2 m_n^*/hbar^2)^(3/2) sqrt(E-E_c)
          for E >= E_c                       (17.6)

となる。g_cにはスピンや谷の縮退を含める。スピン2だけを含む一つの谷ならg_c=2で、よく見る係数1/(2 pi^2)になる。E<E_cではこの放物線模型の状態はないのでD_c=0である。

3.2　価電子帯と正孔のDOS

価電子帯の頂上近くは、電子のエネルギーを

E_v(k) = E_v - hbar^2 k^2/(2 m_p^*)       (17.7)

と書く。m_p^*は正孔に対する有効質量として正値で定義する。価電子帯の電子DOSはE≤E_vで、正孔のDOSは同じ状態をE_v-Eの距離で数える。

D_v,h(E) = g_v/(4 pi^2) (2 m_p^*/hbar^2)^(3/2) sqrt(E_v-E)
            for E <= E_v                      (17.8)

D_v,hの添字hは正孔を数えるDOSだという意味で、負のDOSではない。DOSの単位は、SIで式を計算すればstates/(m^3 J)。エネルギー軸をeVへ変えるときは、dE_J=e dE_eVを忘れず、DOSの単位もstates/(m^3 eV)へ変換する。

3.3　有効状態密度

非縮退近似で伝導帯の電子数を積分すると、DOSの係数を一つの数へまとめられる。

n = ∫[E_c,∞] D_c(E) f(E) dE
  ≈ N_c exp[-(E_c-mu)/(k_B T)]                 (17.9)
N_c = g_c (m_n^* k_B T/(2 pi hbar^2))^(3/2)   (17.10)

同様に、価電子帯の空席を数えると、

p = ∫[-∞,E_v] D_v,h(E) [1-f(E)] dE
  ≈ N_v exp[-(mu-E_v)/(k_B T)]                 (17.11)
N_v = g_v (m_p^* k_B T/(2 pi hbar^2))^(3/2)   (17.12)

となる。N_c,N_vはDOSそのものではなく、温度で変わる「有効状態密度」で、単位は個数密度である。g_c,g_vを式(17.6)ですでに含めたなら、式(17.10)でさらに同じ縮退を掛けない。

式(17.9)から、電子数はE_cからμまでの距離が大きいほど指数関数的に小さくなる。式(17.11)から、正孔数はμからE_vまでの距離が大きいほど小さい。fは無次元だが、積分の結果n,pは体積あたりの個数になる。

4　質量作用則と真性キャリア

4.1　電子数と正孔数を掛ける

式(17.9)と(17.11)を掛けると、化学ポテンシャルが消えて、

np = N_c N_v exp[-(E_c-E_v)/(k_B T)]
   = N_c N_v exp[-E_g/(k_B T)]             (17.13)

を得る。これを質量作用則と呼ぶ。熱平衡・非縮退・同じ温度・指定したバンド模型の範囲で成り立つ。化学反応の質量作用則と名前は同じでも、ここでは電子と正孔の状態数え上げから出ている。

真性なら電荷中性からn=p=n_iなので、

n_i = p_i = sqrt(N_c N_v) exp[-E_g/(2 k_B T)]  (17.14)

となる。E_gが大きいほど、また温度が低いほど、熱励起で作られる対は少ない。N_c,N_vが個数密度であるため、sqrt(N_c N_v)も個数密度であり、指数は無次元である。

4.2　真性化学ポテンシャル

n=pを式(17.9)と(17.11)へ入れて解くと、非縮退近似で

mu_i = (E_c+E_v)/2 + (k_B T/2) ln(N_v/N_c)  (17.15)

となる。N_c=N_vならμはギャップの中央、N_c>N_vなら中央より少し価電子帯側へずれる。これは有限温度のμを単に「ギャップの真ん中」と決めつけないための補正である。式(17.15)は放物線・非縮退・熱平衡の近似値であり、測定から直接得た値ではない。

4.3　ドーピングをまだ入れない理由

ドナー濃度N_D^+とアクセプタ濃度N_A^-を入れる一般の電荷中性条件は、符号を明記すれば、

p + N_D^+ = n + N_A^-                    (17.16)

である。本章の真性条件はN_D^+=N_A^-=0で、この式からp=nを得る。ドナーがあるとnとpは同じでなくなり、μも変わる。それでも式(17.9)から(17.13)を使えるかは、熱平衡・非縮退の条件を再確認する必要がある。ドーピングの詳細や接合の空間電荷は後の章へ残す。

5　温度依存を対数で読む

5.1　指数とTの3/2乗

有効状態密度は、式(17.10),(17.12)からT^(3/2)に比例する。E_gを温度に依存しない近似なら、

n_i ∝ T^(3/2) exp[-E_g/(2 k_B T)]            (17.17)

である。温度上昇でT^(3/2)も増えるが、半導体では通常、指数因子の変化が大きい。現実の材料ではE_g(T)も変わるため、広い温度範囲の直線を無条件に外挿しない。

自然対数を取ると、対数の引数を無次元にするため基準密度n_refと基準温度T_refを置いて、

ln[(n_i/n_ref)/(T/T_ref)^(3/2)] = constant - E_g/(2 k_B) (1/T)  (17.18)

となる。実装で固定単位の数値ln(n_i/T^(3/2))を表示する場合も、n_refとT_refをメタデータへ保存する。縦軸をこの無次元化した対数、横軸を1/Tにすれば、一定ギャップの模型では傾き-E_g/(2 k_B)の直線になる。log10を使う場合は傾きにlog(10)の換算が必要なので、自然対数か常用対数かを図のメタデータへ保存する。

5.2　教材用数値予測

先のE_g=1.12 eV、N_c=2.8×10^19 cm^-3、N_v=1.0×10^19 cm^-3を300 Kの基準値として使うと、n_i≈6.5×10^9 cm^-3。有効質量を固定する温度掃引では、N_c(T)=N_c(300)(T/300)^(3/2)、N_v(T)=N_v(300)(T/300)^(3/2)とスケールする。このとき式(17.15)のμはギャップ中央より、

(k_B T/2) ln(N_v/N_c) ≈ -0.0133 eV

だけ低い。300 K、400 K、500 Kと温度を上げた表では、N_c,N_vのT^(3/2)変化と指数因子が同じcaseへ反映され、n_iが急に増える予測になる。ここで使ったN_c,N_v,E_gは教材入力で、特定ロットの測定値ではない。

5.3　対数グラフの単位

縦軸へn_iをcm^-3で載せるなら、全温度で同じ単位にする。m^-3からcm^-3へは1 m^-3=10^-6 cm^-3である。基準単位を変えると無次元化前の切片は移動するが、混在させると傾きや比較を誤る。横軸1/Tの単位はK^-1で、セルシウス温度をそのまま逆数にしない。

6　数値ノートと負のテスト

6.1　解析積分と数値積分

予定ノートは二つの経路を持つ。一つ目は式(17.14)の有効状態密度による解析予測、二つ目はDOSをエネルギーbinへ置いて、

n_num = sum(Dc_bin(E) * f(E) * Delta_E)
p_num = sum(Dv_h_bin(E) * (1-f(E)) * Delta_E)  (17.19)

を計算する数値予測である。n_num,p_numの単位を揃え、伝導帯・価電子帯の積分範囲、bin幅、打ち切りを保存する。非縮退近似と数値Fermi–Dirac積分を比較し、差が許容範囲を超えたら近似を使い続けない。

6.2　数値安定性

E_g/(2 k_B T)が大きいと、式(17.14)の指数がunderflowしてn_i=0と表示されることがある。対数で

ln n_i = 0.5(ln N_c + ln N_v) - E_g/(2 k_B T)  (17.20)

を計算し、必要なときだけ最後に指数へ戻す。N_c,N_vの単位はlogへ入れる前に基準単位を固定する。Fermi–Dirac積分ではfを0から1へ無条件にclipして成功扱いにせず、指数の安定評価と入力診断を分ける。

6.3　負のテストと符号

次の入力は、物理的に意味の違う失敗として記録する。

E_g < 0、E_c < E_v、T < 0、m_n^* <= 0、m_p^* <= 0
n,p,N_c,N_vが負、NaN、非有限、体積が0以下
DOSをstates/(m^3 J)のままエネルギーをeVで積分
cm^-3とm^-3の混在、1/Tへ摂氏を入力
電子へ+e、正孔へ-eを割り当てる符号反転
非平衡なのに質量作用則を平衡の証拠として使う
高密度でmuがバンド内、または両バンド端から5 kBT未満なのに非縮退式を使う
equilibrium_modelがthermal_equilibriumでない（準Fermi準位を含む非平衡は本章の範囲外）
解析予測をmeasured=trueとして保存する

7　出力と次章への橋渡し

5　模型の境界と章間の橋

この章の模型は、適用範囲を明示して初めて安全に使える。次の限界を一つずつ、本文のどの主張に効くかと一緒に読む。

  • 真性は不純物を指定しない理想条件であり、現実の試料の欠陥やドーピングがないことを保証しない。
  • 有効質量DOSは三次元・放物線・等方的なバンド端の最小模型で、強い非放物性や全バンドを含まない。
  • 質量作用則とniの式は熱平衡・非縮退・一定Egの近似であり、高密度や非平衡ではFermi積分や別のモデルが必要になる。本章runnerはthermal_equilibrium以外をunsupportedとして拒否する。
  • 正孔は空席の有効記述であり、電子と同じ局所的な粒子軌道を実在する正電荷粒子として主張するものではない。
  • DOSをeVあたりで表示するときは、JあたりのDOSとの変換を含め、密度単位も固定する。
  • log(n_i)の直線性は温度範囲、Egの温度依存、測定誤差、近似の妥当性を別に検査して初めて解釈できる。対数は固定した基準単位で無次元化して保存する。
  • バンドギャップとキャリア数だけでは導電率、抵抗、移動度、散乱、接合の空間電荷は決まらない。
  • 本章の固定runnerは契約を再生済みだが、図・対数曲線の外部tool実行は未実行で、具体値は解析または数値予測である。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

9　逆向きに説明する

今度は出力から出発し、どの入力と規則が必要だったかを逆向きに書く。画面の文字、論理値、レジスタ値、電圧、エネルギーのように異なる表現を、途中のartifactなしで直接つないではいけない。各矢印のそばに、保証する契約と保証しない詳細を一つずつ書く。

逆向きの説明で最初に見つかる欠落は、たいてい三種類のどれかである。入力の単位または幅がない、モデルの適用条件がない、または実行と測定の境界がない。この章の本文へ戻り、欠落を埋める行を一つ追加する。

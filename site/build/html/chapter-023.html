第23章　非理想性、微細化、現代トランジスタ

1　この章の問い

トランジスタを小さくすれば速く安くなるという単純な話が、どこで破綻するのか。第22章の長チャネル平方則は、チャネル長が十分長く、電界が穏やかで、端子が理想接触されている場合の基準である。寸法を縮めると、ドレイン側電場がソース側へ届き、速度が飽和し、しきい値と漏れが変わる。

本章では、非理想性を一つの「補正係数」に隠さず、静電、輸送、端子、時間の失敗に分ける。各補正は実測定数ではなく、適用範囲を明示した最小模型として導入する。

2　チャネル長変調

長チャネルの飽和ではI_D,satをV_DSに依存しないとした。実際にはドレイン側の空乏領域がチャネルへ食い込み、実効チャネル長が短くなる。一次近似は

I_D = I_D,sat (1+lambda V_DS)　　　　　　　　　　　(23.1)

である。lambdaはチャネル長変調係数（1/V）。代表caseでlambda=0.1 V^-1、V_DS=0.8 Vなら、式(22.4)のI_D,sat=0.00032315269763958363 AからI_D=0.00034900491345075035 Aとなる。これは出力抵抗が有限になる効果であり、飽和電流が完全に水平でない理由を示す。

3　高電界と速度飽和

3.1　移動度近似の限界

第22章は速度をv=mu_e Eと置いた。電場が高くなると散乱が増え、速度は比例せず飽和速度v_satへ近づく。一つの連続な近似は

v = mu_e E/(1+mu_e |E|/v_sat)　　　　　　　　　　(23.2)

である。短いチャネルではE≈V_DS/L_chが大きく、平方則のmu_e一定仮定が壊れる。強反転電荷を|Q_inv|とすれば、速度飽和の極限で

I_D≈W_ch |Q_inv| v_sat　　　　　　　　　　　　　　(23.3)

という上限の見積もりが得られる。ただし、電荷の位置分布、端部電場、温度依存を無視しているため、SPICEの短チャネルモデルと同一ではない。

3.2　代表比較

V_GS=1.2 V、V_th=0.5881749985302475 V、W_ch=1.0e-5 m、C_ox=0.0034531332493319996 F/m^2、v_sat=1.0e4 m/sの極限見積もりは、W_ch C_ox V_OV v_sat=0.00021127132553478022 Aである。長チャネル飽和値と単純に大小を比べるのではなく、同じ電荷近似を使っているか、電界分布を解いているかをartifactへ記録する。

4　DIBLとbody effect

4.1　ドレイン誘起障壁低下

短チャネルではドレイン電圧がソース側の障壁を下げ、見かけのしきい値が下がる。線形なDIBL（drain-induced barrier lowering）近似を

V_th(V_DS)=V_th0-eta_DIBL V_DS　　　　　　　　　(23.4)

と置く。eta_DIBLは無次元。eta_DIBL=0.05、V_DS=0.8 Vならしきい値低下は0.04 Vで、V_GS=1.2 Vの長チャネル式へそのまま入れればI_D,sat=0.00036678821604627256 Aという予測になる。これはDIBLだけを足した感度試験であり、速度飽和と同時に適用するには重複補正を検討する。

4.2　body effect

V_SB=V_S-V_Bをソースからbodyへ測る電圧と定義する。body–source電圧V_SBを正にすると、表面を反転するための空乏電荷が増え、しきい値が上がる。長チャネルの一次模型は

V_th(V_SB)=V_th0+gamma[sqrt(2phi_F+V_SB)-sqrt(2phi_F)]　(23.5)

である。代表値gamma=0.4 V^(1/2)、V_SB=0.5 V、phi_F=0.35715857599399026 Vでは、しきい値増分0.1027150965007865 V、V_th=0.6908900950310339 Vとなる。body端子を固定しない計算でこの式を省略してはいけない。

5　サブスレッショルドと漏れ

V_GS<V_thでは強反転チャネルはないが、熱励起による拡散電流が0になるとは限らない。簡略なサブスレッショルド式は

I_D=I_0 exp[(V_GS-V_th)/(n_sub V_T)] [1-exp(-V_DS/V_T)]　(23.6)

で、n_sub>1は空乏容量などをまとめた係数である。I_0=1.0e-12 A、n_sub=1.5、V_GS=0.4 V、V_DS=0.1 V、300 Kの代表予測は7.644716187768662e-15 A。I_0は測定値ではなく校正入力である。

ゲート酸化膜のトンネル漏れ、ソース・ドレイン接合漏れ、GIDL、接触リークは異なる経路である。I_Dへ一括加算する前に、経路、電圧、温度依存、source_kindを分ける。

6　寄生容量と速度

ゲート–ソース、ゲート–ドレイン、接合、配線には寄生容量がある。負荷容量C_loadを充放電する遅延の粗い上限は

t_pd≈C_load V_swing/I_drive　　　　　　　　　　　　(23.7)

である。これは論理反転器の過渡を見積もる式で、短絡電流、抵抗、波形の立上り定義を含まない。容量を小さくするための微細化が、漏れやばらつき、熱密度を増やすこともある。

7　数値実験と現代トランジスタへの橋渡し

予定commandはbook run 23 1からbook run 23 8。長チャネル基準、lambda掃引、速度飽和、DIBL、body effect、サブスレッショルド、寄生容量、SPICE短チャネル比較と負のテストを分ける。各出力はideal_long_channel、one_correction、spice_model、measurementを混ぜず、補正の組み合わせと適用順を保存する。

FinFETやgate-all-around（GAA）は、ゲートがチャネルを多面または全周から囲むことで、短チャネル静電を改善する構造である。ただし「新しい形状なら非理想性が消える」という意味ではなく、界面、量子、接触、熱、ばらつきの別問題が残る。次章では、相補的なnMOSとpMOSを組み合わせて、連続電圧から論理反転器を作る。

本文を読み終える前に、次の五列を紙またはテキストへ写す。『層』『入力』『内部状態』『上位の契約』『破綻条件』である。層には物理量、数値模型、回路、命令、OS、処理系のどれかを入れ、同じ名前の量を別層で使うときは型と単位を併記する。

内部状態から上位の契約へ進むとき、隠した変数を一つ選ぶ。たとえば連続電圧を論理値へ写すなら、しきい値の近くの電圧と雑音を隠している。命令列を関数呼出しへ写すなら、レジスタやstack pointerを隠している。隠した変数が変化しても契約が保たれる範囲が、その抽象化の強さである。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

途中で予測と結果が異なったら、最後の行から修正しない。入力、仮定、更新、表現、実行環境の順に一つずつ戻り、最初に不一致になった行へ診断名を付ける。診断名を付けられない差は、未解決として後段へ渡さない。

9　逆向きに説明する

今度は出力から出発し、どの入力と規則が必要だったかを逆向きに書く。画面の文字、論理値、レジスタ値、電圧、エネルギーのように異なる表現を、途中のartifactなしで直接つないではいけない。各矢印のそばに、保証する契約と保証しない詳細を一つずつ書く。

逆向きの説明で最初に見つかる欠落は、たいてい三種類のどれかである。入力の単位または幅がない、モデルの適用条件がない、または実行と測定の境界がない。この章の本文へ戻り、欠落を埋める行を一つ追加する。

10　再現記録の最小形

再現記録には、章ID、実験ID、case、入力hash、toolまたはmodelの版、終了コード、出力artifact、source_kind、status、measuredを残す。時刻やhost名は再現性の補助情報であり、計算値や状態遷移の一部として扱わない。

この最小形を満たせないときは、実験が難しいのではなく、契約がまだ閉じていない。閉じていない契約は、成功結果を保存するより先に、未指定欄と診断欄を保存する。

11　次章の読者への引き継ぎ文

最後に、次章の読者がこの章を読み返さなくても前提を再構成できる引き継ぎ文を書く。第一文はこの章が固定した定義、第二文は代表入力と途中状態、第三文は守る不変条件、第四文は最も近い破綻条件、第五文は未実行または未照合の境界である。

引き継ぎ文の主語を『この値は』だけにしない。『この模型では』『この版のtoolでは』『このmemory領域では』『このsource spanでは』のように、値の所有者を明記する。所有者が変わるところが、章間のbridgeであり、独立レビューが最初に読む境界である。

引き継ぎ文を書いたら、manifestの bridge_in と bridge_out、handoffのopen question、required artifactを照合する。本文に書いた橋と台帳の橋が異なる場合は、どちらかを勝手に合わせず、差分を未解決として残す。

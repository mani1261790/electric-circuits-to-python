第10章 演習解答　Kirchhoff則の由来と限界

E1　制御体積の電荷収支

完全解答

外向き電流の和は、

ΣI_b^out = 2.0 mA - 0.50 mA + 1.0 mA
          = 2.50 mA

連続の式を積分した収支dQ_n/dt+ΣI_b^out=0から、

dQ_n/dt = -2.50 mA = -2.50×10^-3 C/s

となる。外へ出る電流が正味であるため、制御体積の電荷は減少している。電荷蓄積を無視するKCLなら外向き電流の和は0でなければならないが、2.50 mAなので、この三つの値は単純なKCLを満たさない。これはKCLが間違いなのではなく、dQ_n/dtを0と置けない入力である。

再挑戦

I_1=1.2 mA、I_2=−0.7 mA、I_3=−0.5 mAなら、和は0、したがってdQ_n/dt=0 C/sである。負の外向き電流は内向き電流を意味するので、内向きの0.7+0.5=1.2 mAと外向きの1.2 mAがつり合う。

E2　枝の向きと単位

完全解答

I_12 = (V_1−V_2)/R
      = (1.2−3.2) V / 100 Ω
      = −0.020 A
      = −20 mA

負号は、正方向として選んだ1→2ではなく、実際にはnode 2からnode 1へ20 mA流れることを表す。R=100 kΩ=100000 Ωと正しく換算すれば、

I_12 = −2.0/100000 A = −20 μA

となり、大きさは元の1000分の1である。抵抗値を100 kΩと表示しながら数値100を使うと、さらに1000倍の誤差を作るので、表示単位と計算単位を別に記録する。

再挑戦

V_1=3.2 V、V_2=1.2 V、R=100 Ωへ反転すると、I_12=+20 mAとなる。同じ枝の正方向を保ったまま電圧差だけを反転したため、電流の符号も反転する。

E3　二つの電流源を節点解析する

完全解答

抵抗をΩ、電流をAへそろえると、コンダクタンス行列と注入ベクトルは、

G = [ 0.0020  −0.0010 ] S
    [−0.0010   0.0015 ]

j = [0.0030, 0.0010]^T A

である。よって、

2.0 V_1 − V_2 = 3.0
−V_1 + 1.5 V_2 = 1.0

（左辺をmAとkΩで表す）を解けば、

V_1 = 2.75 V
V_2 = 2.50 V

となる。枝電流を指定した向きで計算すると、

I_12 = (2.75−2.50)/1 kΩ = 0.25 mA   (1→2)
I_1g = 2.75/1 kΩ = 2.75 mA           (1→ground)
I_2g = 2.50/2 kΩ = 1.25 mA           (2→ground)

node 1では、外向き抵抗電流が2.75+0.25=3.00 mAで、groundからの注入3.00 mAに等しい。node 2では、外向き抵抗電流1.25 mAが、node 1から入る0.25 mAとgroundからの注入1.00 mAの和に等しい。これは解析予測であり、runner出力または実測値ではない。

再挑戦

node 2への注入を2 mAへ変えると、第二式の右辺は2になる。第一式からV_2=2V_1−3、第二式から−V_1+1.5V_2=2なので、V_1=3.25 V、V_2=3.50 V。従ってI_12=(3.25−3.50)/1 kΩ=−0.25 mAとなり、実際のnode 2からnode 1へ流れる。入力を変えたときに枝電流の符号が反転しても、向きの定義を変更したとは限らない。

E4　Faraday則とKVLの右辺

完全解答

磁束をSI単位へ直すと2.0 μWb=2.0×10^-6 Wbである。

dΦ_B/dt = (2.0×10^-6)(1.0×10^5) cos(1.0×10^5 t) V
         = 0.20 cos(1.0×10^5 t) V

Faradayの積分則から、

Σv_b = −dΦ_B/dt

なので、t=0では、

Σv_b = −0.20 V

である。磁束の時間変化が0ではないため、単純なΣv_b=0というKVLはこの条件では使えない。右辺の負号は、閉路の向きと面の法線を右手系で対応させた規約による。閉路の向きを逆にすれば、枝電圧と磁束の符号は同時に反転する。

再挑戦

t=π/(2×10^5) sならcosineが0なので、瞬間的にはΣv_b=0 Vである。ただし磁束自体が変化しないと結論してよいわけではない。時間全体でdΦ_B/dtを調べ、測定帯域内で無視できるかを判断する。

E5　節点と独立な方程式

完全解答

(a)全nodeは4個で、groundを一つ除くため、基本的な独立KCLは

4−1=3本

である。(b)連結グラフの独立閉路数は、

5−4+1=2本

である。(c)groundは、全ての電圧を比較する基準を固定し、未知数を一つ減らすために選ぶ。全nodeへKCLを書いて足し合わせると、各branchの電流が一度は外向き、一度は内向きに現れて相殺する。よって全nodeの式には一つの従属関係があり、4本全てが独立ではない。groundの電圧を0へ固定することは、他nodeとの電圧差を失わせることではない。

再挑戦

二つの連結成分がgroundから分離している場合、単純な閉路数の式は連結成分数Cを含めてB−N+Cと書く。groundへつながらない成分には電位の基準がなく、抵抗だけなら各成分の共通電位が決まらないため、行列は特異になり得る。物理的な絶縁成分を扱うなら、測定器の入力抵抗など基準を与える要素を明示する。

E6　浮いた電圧源をMNAで解く

完全解答

三つのMNA方程式は、

0.001 V_1 + i_s = 0
0.001 V_2 − i_s = 0
V_1 − V_2 = 5

である。上二式を足すとV_1+V_2=0、第三式と組み合わせると、

V_1 =  2.50 V
V_2 = −2.50 V
i_s = −0.00250 A = −2.50 mA

となる。電圧源電流の正方向をnode 1からnode 2と定義したため、負号は実際にnode 2からnode 1へ2.50 mA流れることを表す。

各抵抗の電力は、

P_1 = (2.50 V)^2/1000 Ω = 6.25 mW
P_2 = (−2.50 V)^2/1000 Ω = 6.25 mW

である。電圧源の正端子へ入る電流をi_sとする受動符号規約なら、

P_s = (5 V)(−2.50 mA) = −12.5 mW

である。したがってP_1+P_2+P_s=0。抵抗は12.5 mWを消費し、電圧源が12.5 mWを供給する。

再挑戦

電圧源を−5 Vへ反転すると、V_1=−2.50 V、V_2=+2.50 V、i_s=+2.50 mAとなる。抵抗の電力は変わらず、電圧源の電力も(−5 V)(+2.50 mA)=−12.5 mWで、供給という分類は変わらない。

E7　行列stampを手で作る

完全解答

node 1-groundの抵抗のコンダクタンスは1/(2 kΩ)=0.0005 S、node 1-node 2の抵抗は0.001 Sである。従って、

G = [ 0.0015  −0.0010 ] S
    [−0.0010   0.0010 ]

電流源は2→0向きなので、node 2から外へ出る電流である。注入ベクトルでは、

j = [ 0       ] A
    [−0.0030  ]

となる。node 1は2 kΩでgroundへつながり、node 2はnode 1との抵抗を通してgroundへつながるため、回路全体は浮いていない。実際に解くと、第一式からV_1=(2/3)V_2、第二式からV_2=−9 V、V_1=−6 Vである。この負電圧は、groundからnode 2へではなく、node 2からgroundへ電流源が押し出すという向きの結果である。

再挑戦

電流源の向きを0→2へ反転するとj_2=+0.003 A、電圧はV_2=+9 V、V_1=+6 Vとなる。行列Gを変えず右辺だけを反転する点が、独立電流源の向きのstampである。

E8　最小ソルバの入力検査

完全解答

入力分類理由
(a) R=0入力エラー（または明示的な短絡制約へ変換）1/Rが有限の導電率にならず、抵抗stampへそのまま入れられない
(b) node 7、node_count=3入力エラーnodeの許容範囲0..3を外れている
(c) 同じnode間に5 Vと3 Vを並列矛盾した系同じ電圧差を同時に二つの値へ固定し、解がない
(d) 電圧源だけでgroundへつながらないnode特異な系の候補その部分回路の共通電位を決める基準がない

部分ピボットは、現在の列で絶対値の大きい要素をpivotへ選び、行を交換する。小さいpivotで割ると丸め誤差が大きくなるため、数値安定性を上げる目的で行う。ただし部分ピボットを入れても、矛盾した制約や浮いた回路を物理的に解決してくれるわけではない。

再挑戦

R=1e-15 Ωは数学的には正だが、通常の回路尺度では非常に大きい導電率になり、行列の条件数や許容誤差を悪化させる。正値検査だけで通すのではなく、想定する抵抗範囲、単位、正規化残差を記録し、必要なら理想短絡モデルを電圧制約へ置き換える。

E9　符号・単位・接地の故障診断

完全解答

  1. E3の電流源はgroundからnode 1へ3 mAを注入している。右辺の符号+は、jをnodeへ注入する定義なら正しい。しかし行列をSI単位で作るなら、数値は+0.003 Aでなければならない。+3.0をそのまま入れる故障は、符号ではなく単位・スケールの故障である。jを外向き電流の右辺と定義していたなら符号は逆になるので、定義をartifactへ保存する。
  2. 1 kΩを1.0へ変換なしで入力すると、コードは1 Ωとして扱う。抵抗と電流源が全て同じ変換を受ければ電圧が変わらない場合もあるが、他の単位がSIなら枝電流、電力、比較結果が壊れる。入力境界で1000 Ωへ一度だけ変換し、単位欄を保存する。
  3. node 2のground接続を削除した回路は、node 2の共通電位を決められず、抵抗網の接続も確認しなければ特異行列になる。ソルバがV_2=0を返すのは解ではなく、特異行を0埋めした実装故障である。特異として止め、node接続、ground、理想電圧源を診断する。

再挑戦

電流源をnode 1→groundへ向けるなら、node 1への注入は−0.003 Aになる。電流源の矢印を反転したとき、抵抗stampではなく右辺だけが反転することを確認する。

E10　残差と電力のチェック

完全解答

MNAの第1行へ代入すると、

0.001(2.50) + (−0.00250) − 0 = 0 A

第2行は、

0.001(−2.50) − (−0.00250) − 0 = 0 A

第3行は、

2.50 − (−2.50) − 5.00 = 0 V

である。したがって、丸め前の解析予測では三つの残差は0である。実装では、浮動小数点丸めを考慮した絶対残差・規格化残差を記録する。

抵抗の電力は、

P_1 = (2.50)^2/1000 = 6.25 mW
P_2 = (−2.50)^2/1000 = 6.25 mW

である。電圧源は正端子から負端子への電流をi_s=−2.50 mAと定義しているので、

P_s = 5.00 V × (−2.50 mA) = −12.5 mW

となる。全電力は6.25+6.25−12.5=0 mW。負の電力は、受動符号規約で電源が回路へ供給していることを示す。

再挑戦

V_1=2.500001 Vへ丸め誤差程度の変更をすると、第1行残差は1.0 nAになる。残差が小さいことと、入力の抵抗値・単位・磁束条件が正しいことを分けて判断する。

E11　負のテストの設計

完全解答

例として次の六つを設計できる。

テスト入力期待状態止める段階と理由
T1抵抗がNaNinvalid_input入力検査。有限値でないため
T2抵抗が−10 Ωinvalid_input入力検査。受動抵抗の正値契約に違反
T3node 4、node_count=3invalid_input入力検査。node範囲外
T4groundのない抵抗成分singular_systemstamp後。共通電位を決める基準がない
T5同じ二nodeへ5 Vと3 Vの電圧源inconsistent_systemまたはsingular_systemstamp後・残差検査。制約が矛盾
T61 kΩを1 ΩのSI数値として渡すunit_warning（解は返せても警告）入力契約または物理妥当性検査。数学的には解けるがスケールが違う

T1〜T3はstamp前に拒否する。T4・T5は線形系を作った後、pivot不足または制約残差で解を返さない。T6のような単位混同は純粋な線形代数だけでは検出できないので、入力に単位タグを付ける、想定範囲を持つ、電力・電圧の物理的上限を別検査するなどの契約を置く。全テストの出力へ実測値を入れず、invalid_inputやsingular_systemを計算結果と別状態にする。

再挑戦

Cを追加した次章の入力では、C=0 Fを単純な容量枝として扱うか、枝を省略するかを仕様へ書く。抵抗のR=0と同様、値の極限を数値へ無理に押し込まず、理想制約または別モデルとして記録する。

E12　KCL・KVLの適用範囲を引き渡す

完全解答

(a)t_prop/t_rise=5は伝搬時間が信号の変化時間と同程度以上であり、配線上の位置ごとの電圧・電流を一つの枝へ隠すのが危険である。したがって単純なΣV=0を同じ時刻の集中枝電圧へ適用する仮定が特に危険である。nodeのdQ_n/dtが無視できないので、単純なΣI=0も危険である。ただしKCL自体を捨てるのではなく、容量電流または節点電荷の変化を含む一般式へ戻す。

(b)集中過渡として扱うなら、node電圧V_n(t)とコンデンサの電圧を状態にし、

I_C = C dV_n/dt

をKCLへ含める。インダクタがあればインダクタ電流とL dI/dtの枝電圧も残す。κ=5の線路なら、V(x,t)とI(x,t)、終端条件、分布したR',L',G',C'を残す分布模型を使う。

(c)第11章へ、抵抗の代数枝、コンデンサ電圧の初期値、インダクタ電流の初期値、入力波形、接地、許容誤差を引き渡す。磁束変化が大きい閉路では、

Σv_b = −dΦ_B/dt

を使い、誘導起電力を電圧源のように別枝または外部入力として記録する。右辺0のKVLへ押し込めない。

再挑戦

κ=0.01へ下がり、node容量も測定帯域で無視できるなら、KCL・KVLの単純形を集中定数候補として使える。ただし、これは自然法則の固定境界ではなく、伝搬、磁束、容量、終端、測定器の影響が許容誤差以下という実験契約を満たした場合の判断である。

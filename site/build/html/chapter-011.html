1　同じ回路でも、過去が違えば今の値が違う

5 Vの電源、1 kΩの抵抗、1 μFのコンデンサを直列につなぎ、時刻0で電源を0 Vから5 Vへ変える。コンデンサの初期電圧を0 Vとする。理想的な段差入力を仮定すると、時定数は

τ = R C = (1000 Ω)(1.0×10^-6 F) = 1.0 ms

である。充電中のコンデンサ電圧は

V_C(t) = 5 V (1 - exp(-t/τ))

となる解析予測で、t=τでは約3.1606 V、t=5τでは約4.9663 Vになる。電源を0 Vへ戻すと、初期値が5 Vなら

α   = R/(2L)      = 5.0000×10^2 1/s
ω_d = sqrt(ω_0^2 - α^2) ≈ 9.9875×10^3 rad/s

2　状態を保存する二つの素子

2.1　受動符号規約と電力

各素子の電圧は、正端子を決めてvと書く。電流は正端子へ入る向きを正にする。この受動符号規約（passive sign convention）では、素子へ入る瞬時電力は

p(t) = v(t) i(t)                              (11.1)

である。p>0はその素子がその瞬間にエネルギーを受け取ること、p<0は外へ渡すことを表す。電源の電力が負でも、計算に失敗したとは限らない。電源が回路へエネルギーを供給している可能性がある。

抵抗の端子式は第8章から引き継ぐ。

v_R = R i_R,
P_R = v_R i_R = R i_R^2 >= 0                 (11.2)

抵抗に蓄積エネルギーはなく、受け取った電力は熱などへ出ていく理想模型である。Rの単位はΩ=V/Aである。

2.2　コンデンサは電荷と電場エネルギーを保存する

線形コンデンサの端子電圧を、正端子と負端子の差v_Cとする。正端子へ入る電流をi_Cとすれば、

q = C v_C
i_C = dq/dt = C dv_C/dt                   (11.3)

である。Cの単位はF=C/Vで、式(11.3)の右辺はF·V/s=C/s=Aになる。これは既存のcapacitor_currentの式である。

式(11.3)と式(11.1)を使うと、コンデンサの電力は

p_C = v_C C dv_C/dt
    = d[1/2 C v_C^2]/dt                    (11.4)

となる。従って線形コンデンサに蓄えられるエネルギーは

U_C = 1/2 C v_C^2                           (11.5)

である。v_Cを急に変えるには、式(11.3)から非常に大きな電流、理想極限ではインパルス電流が必要になる。そのため、有限の抵抗を通じた通常の回路では、コンデンサ電圧は連続に変わる。

2.3　インダクタは電流と磁気エネルギーを保存する

線形インダクタの電流を、正端子へ入る向きi_Lとする。受動符号規約で、

v_L = L di_L/dt                           (11.6)

である。Lの単位はH=V·s/Aであり、L di/dtの単位はVになる。電力は

p_L = L i_L di_L/dt
    = d[1/2 L i_L^2]/dt                   (11.7)

だから、蓄えられる磁気エネルギーは

U_L = 1/2 L i_L^2                           (11.8)

である。有限の電圧で式(11.6)を積分する限り、インダクタ電流は連続に変わる。電流を瞬時に変えるには理想極限でインパルス電圧が必要である。

コンデンサ電圧とインダクタ電流は、回路の現在だけでなく過去を表す状態変数になる。抵抗値だけを知っても、コンデンサの初期電圧またはインダクタの初期電流が分からなければ、過渡応答は一意に決まらない。

3　RC回路をKCLから一階微分方程式へ

3.1　充電の式

電圧源V_in(t)、抵抗R、コンデンサCを直列に置き、コンデンサ下端をgroundとする。抵抗を電源側からコンデンサ側へ流れる電流i、コンデンサ上端の電圧をv_Cと定義する。第10章のKVLをこの向きで書くと、

V_in(t) - R i(t) - v_C(t) = 0              (11.9)

コンデンサの端子式i=C dv_C/dtを代入すれば、

R C dv_C/dt + v_C = V_in(t)                (11.10)

になる。これはKCLでi_R=i_Cと書いても同じ式である。定数段差V_in=V_fの後では、

dv_C/dt = (V_f - v_C)/(R C)                 (11.11)

となる。時定数τ=RCはΩ·F=sなので、指数の引数t/τは無次元である。

3.2　解析解と初期条件

時刻0のコンデンサ電圧をV_iとすると、式(11.11)の解は

v_C(t) = V_f + (V_i - V_f) exp(-t/τ),
τ = R C                                  (11.12)

である。これはrc_responseの登録式である。t=0を代入するとv_C(0)=V_i、t→∞ではv_C→V_fとなる。抵抗電流は

i_R(t) = (V_f - V_i)/R · exp(-t/τ)         (11.13)

である。充電では正、放電では負になる場合があるが、負号は選んだ向きと逆向きに流れるという情報である。

t=τでは初期値との差がe^-1≈0.3679倍、最終値へ近づいた割合が1-e^-1≈0.6321になる。5τで差は約0.00674倍なので、実験の許容誤差が1%なら約4.605τを一つの目安にできる。ただし、これは段差入力、線形R、線形C、負荷なしという模型の範囲での値である。

3.3　初期値を勝手に書き換えない

コンデンサの初期電圧は、過去の回路が決めた状態である。例えばV_i=2 VのコンデンサへV_f=5 Vを加えると、

v_C(t) = 5 + (2 - 5) exp(-t/τ) V

であり、時刻0の値を0 Vとしてはいけない。コンデンサを理想電圧源へ直接接続し、V_iとV_fが異なるのに抵抗がない場合は、有限値の常微分方程式として扱えない。必要な電荷を瞬時に移すインパルス電流、電源内部抵抗、配線抵抗、スイッチのオン抵抗を別に模型化する。

放電では電源を切り離し、抵抗だけをコンデンサへ接続する。V_f=0とすれば式(11.12)が

v_C(t) = V_i exp(-t/τ)                       (11.14)

になる。充電と放電は「別の法則」ではなく、同じ初期値付き方程式のV_fが違う場合である。

4　RLC回路で二つの状態が交換する

4.1　直列RLCの状態方程式

電源、抵抗、インダクタ、コンデンサを直列に置く。電流i(t)は電源からR、L、Cへ流れる向きを正、コンデンサ電圧v_Cは上端が正とする。KVLは

V_in(t) - R i(t) - L di/dt - v_C(t) = 0    (11.15)

である。コンデンサの式を併せると、

dv_C/dt = i/C
di/dt   = [V_in(t) - R i - v_C]/L          (11.16)

となる。状態ベクトルをx=[v_C, i]^Tとすれば、二つの一階微分方程式として数値積分できる。Cは電圧を、Lは電流を状態として持つ。初期条件は

v_C(0) = V_C0,
i(0)   = I_0                              (11.17)

の二つが要る。

式(11.16)を微分してまとめると、一定入力の区間では

L C d²v_C/dt² + R C dv_C/dt + v_C = V_in   (11.18)

となる。LCの単位はs²、RCの単位はsであり、各項は電圧になる。抵抗を0へ近づけると減衰が弱まり、LまたはCを0へ近づけると状態数が減る極限が現れる。ただし、0を数値入力へそのまま渡せるかは、runnerの模型契約で別に判定する。

4.2　解析解の型

無入力の同次方程式の特性方程式は

s² + 2αs + ω_0² = 0,
α = R/(2L),
ω_0 = 1/sqrt(LC)                           (11.19)

である。αの単位は1/s、ω_0の単位はrad/s（ラジアンは無次元）である。

  • α<ω_0なら不足減衰で、ω_d=sqrt(ω_0²-α²)を使う減衰振動になる。
  • α=ω_0なら臨界減衰で、振動せず最短に近づく境界になる。
  • α>ω_0なら過減衰で、二つの実指数の和になる。

直列RLCへV_fの段差を加え、初期状態がV_C(0)=0、i(0)=0なら、不足減衰の場合の解析解は

v_C(t) = V_f [1 - exp(-αt)
                 {cos(ω_d t) + (α/ω_d) sin(ω_d t)}]

である。i(t)=C dv_C/dtから、

i(t) = (V_f/(L ω_d)) exp(-αt) sin(ω_d t)  (11.20)

を得る。ここでV_f/(Lω_d)の単位はAになる。初期電圧や初期電流が0でない場合は、同じ指数・正弦の形へ初期条件に合う係数を決める。形だけを暗記して初期条件を消してはならない。

最初の電圧ピークは、式(11.20)で電流が0になる最初の正の時刻、近似的にはt_p=π/ω_dである。ピークの超過率は

M_p = exp(-πα/ω_d)                          (11.21)

となる。これは理想段差と線形素子の予測であり、電源の立上り、抵抗公差、コイル直列抵抗、コンデンサESR、測定器の負荷を含まない。

4.3　エネルギーの収支

RLCでは、抵抗で失われる電力と、C・Lへ出入りする蓄積エネルギーを分けて書く。

V_in i = R i² + dU_L/dt + dU_C/dt       (11.22)

左辺は電源から回路へ入る電力（向きの定義によって符号が変わる）、右辺第一項は抵抗の消費、残りは磁気・電場エネルギーの時間変化である。電源を切った理想R=0のLCでは、U_L+U_Cが一定になる。R>0なら総蓄積エネルギーは減少し、減った分は抵抗で熱になる。

これは第7章のP=J·E、第10章の符号付き電力収支の回路版である。電圧や電流の絶対値だけを足しても、供給と蓄積と消費を区別できない。

5.2　RCの陽Euler法

式(11.11)を、現在の値から次の値へ進める陽Euler法で近似する。

v[n+1] = v[n] + Δt (V_f - v[n])/(R C)     (11.23)

これは既存のeuler_rc_updateである。h=Δt/(RC)と置くと誤差の増幅因子は1-hになる。充電の物理的な単調収束を保つには、少なくとも0<h<1が分かりやすい条件である。線形方程式の数値安定性だけなら|1-h|<1、すなわち0<h<2が条件だが、1<h<2では符号が交互に変わるため、段差応答の形を正しく表す刻みとは別に判定する。

例えばτ=1 msでΔt=0.1 msならh=0.1で、1ステップ後の充電電圧は0.5 Vという数値予測になる。Δt=2.1 msならh=2.1で誤差が増幅し、計算は発散する。刻み幅を小さくすれば必ず実測値に近づくわけではなく、模型と入力条件が同じかを確認する。

5.3　RLCの状態積分

式(11.16)を状態x=[v_C,i]の関数f(t,x)として、陽Euler法なら

v_C[n+1] = v_C[n] + Δt i[n]/C
i[n+1]   = i[n] + Δt [V_in[n] - R i[n] - v_C[n]]/L  (11.24)

とする。Δtは秒、i/CはV/s、[V-Ri-v_C]/LはA/sでなければならない。RLCでは振動周期2π/ω_dに対して十分細かい刻みが必要であり、RCの時定数だけを基準にするとピークを見落とすことがある。

四次Runge–Kutta法など高次の方法を追加すると同じ微分方程式を別の数値近似で解ける。ただし、方法を変えた結果が解析解と違えば、刻み幅、状態の順序、入力の時刻、初期条件、符号を順に点検する。数値手法の名称を増やすこと自体が検証ではない。

6　失敗を分類する

6.1　単位と接頭語

時間発展の実装は、単位を混ぜるともっともらしい波形を返す。1 kΩを1000 Ω、1 μFを1.0×10^-6 F、10 mHを1.0×10^-2 Hへ入力境界で一度だけ変換する。mはSI接頭語ではミリ、SPICEの接尾辞や変数名では別の意味を持ち得るので、ネットリストとJSONの単位欄を分けて保存する。

指数の引数、振動の角周波数、エネルギーの単位を点検する。

t/(R C)                 : dimensionless
α t                     : dimensionless
ω_d t                   : dimensionless
1/2 C V², 1/2 L I²      : J

R=1000、C=1e-6を使うならRC=1e-3 sである。C=1と入力してしまうと、時定数が100万倍になり、計算は解けても物理的な入力契約に違反する。

6.2　初期条件と入力波形

次の四つを出力へ必ず保存する。

  1. v_C(0-)とv_C(0+)
  2. i_L(0-)とi_L(0+)
  3. 電源の値、極性、遅延、立上り・立下り時間
  4. 開始時刻と数値積分の最初のサンプル

有限の素子値と有限の電圧・電流では、通常v_C(0+)=v_C(0-)、i_L(0+)=i_L(0-)である。異なる初期値を入力した場合は、瞬時の電荷・磁束移動を表す追加のインパルスや理想制約が必要になる。初期条件を0で埋めて「初期条件なし」にしてはいけない。

6.3　波形が違うときの順番

解析解と数値積分が違うなら、まずR,C,LのSI単位、状態の並び、入力のサンプル時刻、初期値、受動符号規約を比べる。次にΔt/τとΔt·ω_dを確認し、刻み幅の収束を見る。解析解と数値が一致してSPICEだけが違うなら、ネットリストのnode、素子の向き、有限立上り、初期条件、最大刻み、SPICEの接尾辞を確認する。

実測だけが違うなら、抵抗公差、コイルの直列抵抗、コンデンサESR・漏れ、発振器の出力抵抗、プローブ容量、配線インダクタンス、帯域、接地を挙げる。本章の理想RLCへこれらを黙って混ぜず、別の模型または測定条件として記録する。

11.実践ケースブック　宣言から観測へ

このケースブックは、抵抗、コンデンサ、インダクタの時間発展の中心問題「回路が過去の状態を記憶するのは、どの物理量にエネルギーが残るからか。」を、manifestに宣言された入力から追い直すための作業欄である。本文の結論を写すのではなく、入力、途中状態、出力、境界、出所の順に自分で埋める。ここにない値を補ってはいけない。

ケースを読む共通手順

  1. case名と入力を最初に固定する。数値には単位、bit列には幅、状態には初期条件、sourceには版を付ける。
  2. 途中状態を一つだけ更新し、更新前後を表にする。式の左辺と右辺の次元、レジスタの幅、stackの深さ、回路端子の向きを照合する。
  3. 期待値を出力欄へ写す。ただし analytic_prediction、runner_output、measurement を同じ欄へ置かない。
  4. 近い反例を一つ選び、失敗がどの層で止まるべきかを書く。正常値への丸めや、未実行の成功表示は禁止する。
  5. 最後に、次章へ渡す値と、その値が成立する条件を一文でまとめる。

反例は、正常例を否定するためではなく、契約の範囲を見つけるために作る。次の各項目は、入力、最初に破綻する層、期待する診断、後段を止める理由を一組で書く。

5　模型の境界と章間の橋

この章の模型は、適用範囲を明示して初めて安全に使える。次の限界を一つずつ、本文のどの主張に効くかと一緒に読む。

  • q=Cv_C、v_L=L di_L/dt、v_R=Riは線形・集中定数の端子模型であり、漏れ、ESR、巻線抵抗、飽和、周波数依存を自動的に含まない。
  • コンデンサ電圧とインダクタ電流の連続性は、有限の素子値・有限の入力を前提にする。理想電圧源直結や理想電流源直結ではインパルスを含む制約へ変わり得る。
  • RC解析解は段差入力、一定R・C、指定初期値の式であり、有限立上り、負荷、温度、測定器を含まない。
  • RLCの不足減衰解は線形・一定係数の理想模型で、実コイルの直列抵抗やコンデンサESRを隠す。
  • Euler法の安定条件は方程式・刻み幅に依存し、数値安定でも物理的に正しい波形になるとは限らない。
  • SPICEの収束は実測の証明ではない。ネットリスト、素子模型、最大刻み、初期条件、入力立上りを解析解と同じ契約にそろえる必要がある。
  • 小さい解析誤差や残差は、単位、部品値、配線、測定器負荷、モデルの妥当性を証明しない。
  • 本章の固定runnerは契約を再生済みで、ホストngspiceもnetlistを実行済みである。ただし、両者は解析・数値・SPICE計算であり、実回路・オシロスコープ・シリコンの測定ではない。具体的な電圧・電流・ピークは、どのsource_kindから来たかを付けて解釈する。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

途中で予測と結果が異なったら、最後の行から修正しない。入力、仮定、更新、表現、実行環境の順に一つずつ戻り、最初に不一致になった行へ診断名を付ける。診断名を付けられない差は、未解決として後段へ渡さない。

9　逆向きに説明する

今度は出力から出発し、どの入力と規則が必要だったかを逆向きに書く。画面の文字、論理値、レジスタ値、電圧、エネルギーのように異なる表現を、途中のartifactなしで直接つないではいけない。各矢印のそばに、保証する契約と保証しない詳細を一つずつ書く。

逆向きの説明で最初に見つかる欠落は、たいてい三種類のどれかである。入力の単位または幅がない、モデルの適用条件がない、または実行と測定の境界がない。この章の本文へ戻り、欠落を埋める行を一つ追加する。

10　再現記録の最小形

再現記録には、章ID、実験ID、case、入力hash、toolまたはmodelの版、終了コード、出力artifact、source_kind、status、measuredを残す。時刻やhost名は再現性の補助情報であり、計算値や状態遷移の一部として扱わない。

この最小形を満たせないときは、実験が難しいのではなく、契約がまだ閉じていない。閉じていない契約は、成功結果を保存するより先に、未指定欄と診断欄を保存する。

11　次章の読者への引き継ぎ文

最後に、次章の読者がこの章を読み返さなくても前提を再構成できる引き継ぎ文を書く。第一文はこの章が固定した定義、第二文は代表入力と途中状態、第三文は守る不変条件、第四文は最も近い破綻条件、第五文は未実行または未照合の境界である。

引き継ぎ文の主語を『この値は』だけにしない。『この模型では』『この版のtoolでは』『このmemory領域では』『このsource spanでは』のように、値の所有者を明記する。所有者が変わるところが、章間のbridgeであり、独立レビューが最初に読む境界である。

引き継ぎ文を書いたら、manifestの bridge_in と bridge_out、handoffのopen question、required artifactを照合する。本文に書いた橋と台帳の橋が異なる場合は、どちらかを勝手に合わせず、差分を未解決として残す。

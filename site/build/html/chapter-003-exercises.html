第3章　演習

演習では、数値だけでなく、対象、形、単位、成立条件を記録する。式の次元が合っていることは必要条件だが、それだけで自然法則や実装の正しさを証明したことにはならない。各問には段階的なヒントを付けた。変更課題または故障診断では、解答を見た後に再挑戦問題を解き、別の条件でも同じ境界を説明する。

E1　次元を読む

次の式について、左右の次元を計算し、物理量として足し算・掛け算が許されるか答える。

  1. 3 m + 20 cm
  2. 5 V + 2 A
  3. 5 V × 2 A
  4. 5 V / 2 A
  5. R C（RはΩ、CはF）
ヒント
  • ヒント1: 足し算では、単位を換算した後も次元が同じでなければならない。
  • ヒント2: V×Aは電力、V/Aは抵抗である。
  • ヒント3: ΩFを基本次元へ分解して、秒になるか確認する。

E2　抵抗と容量の次元を導く

基本次元の順を(M,L,T,I)とする。P=VI、q=It、R=V/I、C=q/Vから、電圧、抵抗、容量の次元を導け。途中の引き算も書く。

ヒント
  • ヒント1: 電力の次元は(1,2,-3,0)、電流の次元は(0,0,0,1)。
  • ヒント2: 掛け算は指数を足し、割り算は指数を引く。
  • ヒント3: 容量は電荷を電圧で割る。

E3　故障診断：時定数を足してしまう

次のコードは、抵抗と容量の数値を足して時定数を求めようとしている。

R = 1_000       # ohm
C = 1e-6        # farad
tau = R + C
  1. tauの数値を表示できても、なぜ時間と呼べないか。
  2. 最小の修正を書き、tauの単位を検査する方法を説明する。
  3. tau = 2 * R * Cは単位検査を通るが、係数2が正しいかを別に検査しなければならない理由を書く。
ヒント
  • ヒント1: R+CはΩとFの足し算である。
  • ヒント2: RC回路の時定数の候補は積であり、ΩFは秒になる。
  • ヒント3: 次元解析は係数や符号、回路の接続を決めない。

E4　ベクトルと仕事

力F=(3,4) N、変位Δr=(2,0) mとする。

  1. Fの大きさを求める。
  2. 仕事W=F·Δrを求め、単位を付ける。
  3. 変位を(0,2) mへ変えたとき、仕事がどう変わるか。
  4. 電場E=-∇Vで、VがV、位置がmならEの単位がV/mになる理由を書く。
ヒント
  • ヒント1: 大きさは√(F_x^2+F_y^2)、内積は成分積の和。
  • ヒント2: 仕事は力×変位なのでN m = J。
  • ヒント3: ∇は空間方向の微分なので、電位を長さで割る。

E5　微分と積分の単位

電荷q(t)の単位をC、時間の単位をsとする。

  1. dq/dtの単位を示し、電流Iとの関係を書く。
  2. 電力P(t)を時間で積分した量の単位を示す。
  3. I=2 Aが3 s一定に流れたときの電荷変化を求める。
  4. dx/dt ≈ (x(t+Δt)-x(t))/Δtで、Δtの単位を明記しない危険を説明する。
ヒント
  • ヒント1: 微分は「分子の単位/分母の単位」で考える。
  • ヒント2: W sはJである。
  • ヒント3: 差分は近似であり、刻み幅を変えると誤差・丸め・計算量が変わる。

E6　RCの常微分方程式

入力V_s=5 V、R=1 kΩ、C=1 μF、初期値V_C(0)=0の理想RC充電を考える。

  1. I_R=(V_s-V_C)/RとI_C=C dV_C/dtから、dV_C/dtの式を導く。
  2. 時定数τを求める。
  3. V_C(t)=V_s(1-exp(-t/τ))で、t=τの電圧を有効数字3桁で求める。
  4. この式が破綻し得る条件を二つ挙げる。
ヒント
  • ヒント1: 直列枝では、近似の範囲でI_R=I_Cと置く。
  • ヒント2: R C=10^3×10^-6 s。
  • ヒント3: 1-exp(-1) ≈ 0.632。

E7　変更課題：Euler法を一歩だけ計算する

E6と同じRC回路について、Euler法

V_(n+1) = V_n + Δt (V_s - V_n)/(R C)

を使う。

  1. V_0=0 V、Δt=0.2 msでV_1を求める。
  2. Δt=2 msで同じ一歩を計算し、連続時間の解の範囲0≤V_C≤V_sを破るか確認する。
  3. この二つの刻み幅を同じだと扱うプログラムの故障を、単位と数値の両方から診断する。
ヒント
  • ヒント1: τ=1 msなので、Δt/τを先に計算する。
  • ヒント2: V_1=V_0+(Δt/τ)(V_s-V_0)。
  • ヒント3: Euler法は安定性を持つ刻み幅の範囲があり、次元だけでは決まらない。

E8　複素数とインピーダンス

角周波数ω=1000 rad/s、容量C=1 μFの理想コンデンサについて、

Z_C = 1/(i ω C)

を考える。

  1. ωCの単位を求める。
  2. Z_Cの大きさと位相の向きを求める。
  3. iを含む表現が、端子で「虚数の電圧を測る」という意味ではない理由を書く。
  4. スイッチ投入直後の非正弦波過渡を、この一つのZ_Cだけで完全に表せない理由を説明する。
ヒント
  • ヒント1: radは無次元、ωは1/s、CはF。
  • ヒント2: 1/(ωC)=1000 Ωで、1/i=-i。
  • ヒント3: 複素数は振幅と位相を計算しやすくする表現である。

E9　フーリエとサンプリングの境界

次の文を、正しい、条件付きで正しい、誤りのいずれかに分類し、条件または訂正を書く。

  1. 周期信号は周波数成分の和として表せる。
  2. サンプリング周波数が信号の最高周波数の2倍なら、どんな信号でも元に戻せる。
  3. CPU traceをフーリエ変換すれば、命令の因果関係が完全に分かる。
  4. 測定窓を短くすると、時間位置と周波数分解能の両方が無限によくなる。
ヒント
  • ヒント1: 有限帯域、サンプリング定理、aliasingの条件を明示する。
  • ヒント2: traceの周波数成分は周期性を要約するが、個々の順序を保存しない。
  • ヒント3: 時間分解能と周波数分解能には窓長によるトレードオフがある。

E10　固有値と状態の反復

次の行列を考える。

A = [[0.8, 0.1],
     [0.2, 0.7]]
  1. トレースと行列式を求める。
  2. det(A-λI)=0から固有値を求める。
  3. x_(n+1)=Ax_nで、絶対値が1未満の固有値があることをどう解釈するか。
  4. 行列の要素が無次元なら、固有値も無次元になる理由を書く。
  5. 連続時間のdx/dt=B xで、Bの固有値が持ち得る単位を答える。
ヒント
  • ヒント1: トレースは対角和、行列式はad-bc。
  • ヒント2: 方程式はλ^2-1.5λ+0.54=0。
  • ヒント3: 離散時間の一ステップ写像と、連続時間の変化率を分ける。

E11　確率と平均アクセス時間

キャッシュ探索時間をT_c=4 ns、ミス時に追加される主記憶時間をT_m=80 ns、hit率をh=0.95とする。ミスでもキャッシュ探索は一度行う契約を採用する。

  1. T_avg=hT_c+(1-h)(T_c+T_m)を計算する。
  2. この式の全項の単位を示す。
  3. hit率が時間の単位を持つと仮定したプログラムが、どの演算で破綻すべきか。
  4. TLB missも含めるには、どの事象と時間を追加するか。
  5. 平均値だけでは表せない性能指標を一つ挙げる。
ヒント
  • ヒント1: T_avg=T_c+(1-h)T_mへ整理できる。
  • ヒント2: 確率は無次元で、nsを保つ。
  • ヒント3: tail latency、分布、相関、並列性のどれかを使う。

E12　グラフと形式文法

  1. 回路の節点を頂点、素子や配線を辺とするグラフで、辺に何の重みを付けられるか二つ挙げる。
  2. CPUの制御フローグラフで、分岐命令はどのような辺を作るか。
  3. 次の文法が受理する文字列を二つ、受理しない文字列を一つ挙げる。
expression = term , { ( "+" | "-" ) , term } ;
term       = factor , { ( "*" | "/" ) , factor } ;
factor     = number | identifier | "(" , expression , ")" ;
  1. 1 + 2 * 3の構文木で、+と*のどちらが上位になるか。
  2. 文法が受理したことから、変数が宣言済みで副作用がないと結論してはいけない理由を書く。
ヒント
  • ヒント1: 辺の重みは遅延、抵抗、容量、確率など、定義を付けて選ぶ。
  • ヒント2: 条件分岐先ごとに有向辺を作る。
  • ヒント3: termがfactorをまとめるので、*が先に構造化される。

E13　統合故障診断：形を消した計算

次の処理系の最適化が、入力に関係なく平均アクセス時間を8と返している。

def average(h, tc, tm):
    return 8

本来の契約は、hが確率、tcとtmが時間で、 tc + (1-h)*tmを返すことである。

  1. この実装が単位検査を通るかどうかと、意味を満たすかどうかを分けて答える。
  2. h=0.5, tc=10 ns, tm=100 nsで、固定値が誤ることを示す。
  3. 変更課題として、Q型の単位検査を使う実装方針を三行以上で書く。
  4. 固定値を返す最適化を許す条件を一つ以上挙げる。
ヒント
  • ヒント1: 「8」は単位を持たない数値であり、nsを付けるかは呼出し側の契約に依存する。
  • ヒント2: 10 + 0.5*100 = 60 ns。
  • ヒント3: 単位検査は、関数の引数と戻り値の形を検査するが、入力依存性の保存までは自動で保証しない。

合格の記録

次の項目を自分の記録へ残す。

  • R+Cを拒否し、RCの次元を説明した。
  • ベクトルの内積、微分・積分、RCのODEを単位付きで説明した。
  • Euler法の刻み幅、固有値、平均アクセス時間で、次元と安定性・確率の条件を分けた。
  • 複素数、フーリエ、グラフ、形式文法を、後続の回路・CPU・OS・処理系の用途へ接続した。
  • 少なくとも一つの故障を、観測、期待、条件、分類、次の観測の形式で診断した。

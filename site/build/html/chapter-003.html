第3章　必要な数学を必要な場所で使う

この章の中心問題

第2章では、自然法則、理想化したモデル、設計上の契約、特定の実装を分けるための抽象化台帳を作った。本章では、その台帳に書かれる式を、数値だけでなく「単位」と「形」を持つものとして扱う。

最初に、次の二つの式を比べる。

正しい候補:   τ = R C
誤った候補:   τ = R + C

抵抗 R = 1 kΩ、コンデンサ C = 1 μFなら、RC = 1 msである。R+Cは数値を無理に足しても、ΩとFを足しているので時間にならない。値を電卓へ入力できることと、式が物理量として意味を持つことは別である。

同じ確認は下位の回路だけに限らない。平均メモリアクセス時間（average memory access time）では時間を確率で重み付けし、状態の反復では行列の固有値を使い、Pythonの処理系では文字列を形式文法で分解する。数式は、後の章で突然登場する呪文ではない。何を表し、どの単位を持ち、どの境界で使えるかを先に決めれば、電磁場、回路、量子、CPU、OS、処理系を同じ台帳へ接続できる。

この章の目標は、数学をすべて先に学習することではない。次の問いに答えられる共通の記法を作ることである。

  • その式の左右は同じ種類の量か。
  • 量の単位は何か。単位を変えても式の意味は変わらないか。
  • スカラー、ベクトル、行列、関数、確率、グラフ、文字列規則のどれで表すべきか。
  • どの下位状態を隠しており、どの範囲で予測が成立するか。
  • 計算結果を、後の回路・CPU・OS・MiniPyのどこへ渡すのか。

1　記号台帳を先に置く

1.1　数値、単位、次元

「5」という数値だけでは、電圧5 V、時間5 s、メモリ容量5 byteを区別できない。物理量は、数値と単位の組として記録する。

電圧:       V = 5 V
時間:       t = 5 s
容量:       C = 5 F

ここでいう次元（dimension）は、単位の名前よりさらに粗い種類である。第3章では、力学量と電気量を次の4つの基本次元で表す。

記号意味
M質量 (mass)
L長さ (length)
T時間 (time)
I電流 (electric current)

SI単位系で、いくつかの量は次の次元を持つ。

時間ts(0,0,1,0)
長さxm(0,1,0,0)

抵抗RΩ(1,2,-3,-2)
容量CF(-1,-2,4,2)

電力PW(1,2,-3,0)

導出の例を一つ書く。電圧は電力を電流で割ったものなので、

V = P/I

である。したがって

dim(V) = (1,2,-3,0) - (0,0,0,1)
       = (1,2,-3,-1)

抵抗は電圧を電流で割るから、

dim(R) = dim(V) - dim(I)
       = (1,2,-3,-2)

容量は電荷を電圧で割るから、

dim(C) = (0,0,1,1) - (1,2,-3,-1)
       = (-1,-2,4,2)

次元を掛けると指数を足し、割ると指数を引く。足し算と引き算は、同じ次元の量だけに許す。これが次元解析（dimensional analysis）の最小規則である。

1.2　単位と次元を混同しない

メートルとセンチメートルは単位が異なるが、次元は同じ長さである。1 m = 100 cmという換算は、同じ次元の単位を取り替える操作だ。一方、メートルと秒の間に換算係数を置いて足すことはできない。

角度のラジアンは、弧の長さを半径で割った比であり、次元は無次元である。しかし「無次元だから何でも足せる」という意味ではない。角度、確率、論理値は次元が同じでも別の意味と契約を持つ。単位検査は、意味の検査を完全には代替しない。

同じ注意は計算機にもある。0x10000000という値は、RISC-V機体のアドレス、プロセス内の整数、単なる16進表記の数として現れ得る。数値が同じでも、単位または層の契約が異なる。数式台帳には、数値だけでなく対象と層を書く。

2　次元解析で式の入口を検査する

2.1　足せるもの、掛けられるもの

同じ次元の量だけを足せる。

3 m + 20 cm = 3.20 m       （同じ長さへ換算してから足す）
5 V + 2 A                  （そのままでは意味が決まらない）

後者が常に禁止という意味ではない。回路の状態を (V, I)という二成分ベクトルにまとめることはできる。ただし、成分を別々に保持する構造を明示し、スカラーの和として扱わない。

掛け算は、次元を合成する。

P = V I       [W] = [V][A]
q = I t       [C] = [A][s]
τ = R C       [s] = [Ω][F]

τ=RCでは、ΩとFを基本次元へ分解すると時間だけが残る。したがって、RC回路の時定数（time constant）が時間であるという予測を、実験や微分方程式を解く前に検査できる。

2.2　無次元数は「小さい」ことと同じではない

指数関数や対数の引数は無次元でなければならない。

exp(-t/τ)       t/τ は無次元なので許される
exp(-t)         t が秒なら、単位を無視している
log(n/n0)       比が無次元なので許される
log(n)          n が個数なら、基準を明示しないと曖昧になる

この条件は、数式の見た目ではなく、単位を変えたときの不変性を守るために必要である。t=1 sを1000 msに書き換えても、t/τの値は変わるが、exp(-t)と書いた式では入力する数値が変わり、結果まで変わってしまう。

2.3　次元解析が見抜けないもの

次元が合っていても、式が正しいとは限らない。τ=2RCも単位は秒だが、係数2が必要かどうかは回路の構成と微分方程式から決まる。符号、境界条件、係数、初期値、近似の範囲は、次元検査だけでは分からない。

同様に、T = h T_c + (1-h) T_mは時間の次元を持つが、ミス時にキャッシュ探索時間を再度加えるか、メモリ並列性をどう扱うかは、アクセス契約の定義に依存する。次元検査を通過した式を、実装の観測値と同一視しない。

3　ベクトルは「方向のついた量」を記録する

3.1　スカラーとベクトル

温度、電位、抵抗値は、場所を固定すれば一つの数で表すスカラーである。力、速度、電場は、値だけでなく向きを持つのでベクトルである。

二次元ベクトルを列として書く。

a = (a_x, a_y)^T
b = (b_x, b_y)^T

同じ形のベクトルは成分ごとに足す。

a + b = (a_x + b_x, a_y + b_y)^T

内積（dot product）は二つのベクトルからスカラーを作る。

a · b = a_x b_x + a_y b_y

内積は、力が移動方向へした仕事 W = F · Δr、電場から電位差を得る線積分、行列の行と列の計算に現れる。外積（cross product）は3次元で向きを持つベクトルを作り、磁場中の力やトルクで使う。外積の向きは座標系の向きに依存するため、右手系を明示する。

3.2　単位付きベクトル

ベクトルの各成分は、通常同じ次元を持つ。位置 r=(x,y,z)の各成分はm、速度 v=(v_x,v_y,v_z)の各成分はm/sである。異なる単位の成分を一つのベクトルへ置くなら、成分の役割を台帳へ書く。

電磁気では、電場 E(r,t)は位置と時間を入力に取り、各点でベクトルを返すベクトル場である。スカラー電位 V(r,t)から電場を求める式

E = -∇V

では、∇が空間方向の微分をまとめている。VがV、位置がmなら、∇VはV/mとなり、電場の単位と整合する。ここでは式の意味と単位だけを固定し、境界条件を含む解法は第5章以降で扱う。

3.3　CPU、OS、処理系のベクトル

ベクトルは物理量だけの道具ではない。CPUのレジスタ状態を

x = (x0, x1, ..., x31)^T

と書けば、一つの命令を状態ベクトルへの写像として表せる。OSのプロセス表も、各プロセスの状態を集合またはレコードの列として持つ。MiniPyの実行時環境も、スタック、環境、ヒープを状態ベクトルに似た構造として記録できる。ただし、これらは物理ベクトルではなく、成分に意味を割り当てた離散状態である。形が似ているからといって、物理の単位をそのまま付けてはいけない。

4　微分と積分は「変化」と「累積」をつなぐ

4.1　微分の単位

時間に関する微分は、単位あたりの変化を表す。

dq/dt        [C/s] = [A]
dV/dt        [V/s]
dT/dt        [K/s]

電流は、電荷の時間変化率として

I = dq/dt

と定義される。qがC、tがsなので、IはAになる。

微分を「小さい差分」とだけ扱うと、刻み幅を変えたときの誤差を見失う。数値計算では

dx/dt ≈ (x(t+Δt) - x(t)) / Δt

と置くが、これは近似である。Δtを小さくすれば常によくなるわけではない。丸め誤差、測定ノイズ、計算時間、モデルの時間尺度を一緒に調べる必要がある。第4章では、この近似と解析解を比較する。

4.2　積分の単位

積分は、微小な量を足し合わせる。

q(t) - q(t0) = ∫[t0,t] I(u) du

IがA、duがsなので、積分結果はCである。速度を時間で積分すれば位置の変化になり、電力を時間で積分すればエネルギーになる。

Δr = ∫ v(t) dt       [m/s] [s] = [m]
U  = ∫ P(t) dt       [W] [s]   = [J]

積分区間、初期値、境界値を省略した式は、数値だけ合っていても再現できない。台帳には必ず区間と基準を残す。

4.3　RC回路の常微分方程式

抵抗 Rと容量 Cを直列につなぎ、入力電圧を一定値 V_s、コンデンサ電圧を V_C(t)とする。抵抗を流れる電流は、受動符号規約のもとで

I_R = (V_s - V_C) / R

であり、コンデンサの関係は

I_C = C dV_C/dt

である。直列枝で電流が同じという近似を置くと、

C dV_C/dt = (V_s - V_C) / R

または

dV_C/dt = (V_s - V_C) / (R C)

となる。左辺はV/s、右辺もV/(ΩF)=V/sで、単位がそろう。

入力を時刻0で急に0 Vから V_sへ変え、初期値を V_C(0)=0とする理想モデルでは、解は

V_C(t) = V_s (1 - exp(-t/τ))
τ = R C

である。t/τが無次元なので指数関数の引数が成立し、V_Cの単位はV_sのVのままである。

この式を使える条件を台帳へ書く。

4.4　偏微分方程式への入口

V_C(t)は時間だけの関数なので、常微分方程式（ordinary differential equation、ODE）である。電場 E(r,t)や電位 V(r,t)のように位置と時間の両方に依存する量では、偏微分方程式（partial differential equation、PDE）が必要になる。

例えば熱や拡散の模型には

∂u/∂t = D ∇²u

の形が現れる。uが温度なら、左辺はK/s、∇²uはK/m²なので、Dはm²/sである。電磁場の波動方程式も空間微分と時間微分を結びつける。ここで重要なのは、微分記号を増やすことではない。変数の数が増えると境界条件・初期条件・空間の離散化が必要になり、回路の一つの時定数だけでは予測できなくなることである。

5　複素数とフーリエは「変化の形」を分ける

5.1　複素数を二つの実数として読む

複素数（complex number）は

z = a + i b,  i^2 = -1

と書く。aは実部、bは虚部である。複素数を導入しても、測定器が負の電圧を直接「虚数V」として測るわけではない。複素数は、二つの成分を一つの計算規則で扱う表現である。

Eulerの公式

exp(i θ) = cos θ + i sin θ

を使うと、正弦波の位相を掛け算で表せる。θは角度で無次元、exp(iθ)も無次元である。交流回路の定常状態では、電圧や電流の振幅を複素数で表すフェーザ（phasor）を使うことがある。その場合、抵抗はR、コンデンサは

Z_C = 1/(i ω C)

というインピーダンスで表せる。角周波数 ωはrad/s、ラジアンは無次元なので、ωCは1/Ω、Z_CはΩとなる。

この表現は、正弦波の定常状態という範囲に限る。スイッチを入れた直後の過渡応答、非線形素子、広い周波数帯の信号では、複素数一つの値に隠れている条件を開く必要がある。

5.2　フーリエ分解の用途

周期信号を、異なる周波数の正弦波の和として表す考えをフーリエ級数（Fourier series）と呼ぶ。連続時間の概念的な形は

x(t) = Σ_k A_k exp(i k ω0 t)

である。A_kは各周波数成分と同じ量の単位を持つ係数、ω0は基本角周波数である。有限長の記録へ同じ式を適用する場合は、記録を周期延長した離散フーリエ変換（DFT）なのか、窓を掛けた近似なのか、または連続フーリエ変換なのかを別に記録する。現実の回路では、信号の帯域、配線の遅延、測定器の帯域、サンプリング周波数を区別する。

フーリエ変換を使う場所は三つに分ける。

対象周波数表現が与えるもの隠される危険
RC回路周波数ごとの減衰と位相過渡初期、非線形、有限窓
デジタル回路クロック (clock)、立上り、ノイズの帯域連続波形を0/1へ戻す閾値
CPUの実行記録 (trace)周期・待ち時間の統計的な成分事象の順序、因果関係、分岐

連続時間信号を一定間隔で読むとき、十分なサンプリング周波数がなければ高い周波数が低い周波数に見えるエイリアシング（aliasing）が起きる。したがって、スペクトルの図が滑らかでも、元信号を完全に復元したことにはならない。第4章でサンプリングと数値積分を並べて扱う。

6　線形代数と固有値で状態の変化を表す

6.1　行列は入力ベクトルを別のベクトルへ写す

線形写像（linear map）は、ベクトルの足し算とスカラー倍を保つ写像である。行列 Aを使って

y = A x

と書く。行列の行は出力成分、列は入力成分に対応する。Aが2×2、xが2×1なら、yも2×1になる。

各成分の単位が同じなら、行列の要素は無次元でよい。入力の温度を出力の温度へ写すなら係数は無次元である。入力を電圧、出力を電流へ写す行列の要素はS（ジーメンス）のように単位を持つ。異なる次元を持つ状態を一つのベクトルへ積む場合、行列の各要素が行と列の単位比を持つことを台帳へ書く。

6.2　固有値は反復で残る形を見つける

ゼロでないベクトル vについて

A v = λ v

を満たすλを固有値（eigenvalue）、vを固有ベクトル（eigenvector）という。vの向きは行列Aで変わらず、長さだけがλ倍される。

反復状態

x_(n+1) = A x_n

では、絶対値が1未満の固有値に対応する成分は減衰し、絶対値が1を超える成分は増大する（他の条件が整っている場合）。この見方は、RC回路の離散時間計算、反復解法、キャッシュの状態遷移、マルコフ連鎖、量子力学の状態演算子に再利用される。

6.3　小さな固有値問題

次の無次元行列を使う。

A = [[0.8, 0.1],
     [0.2, 0.7]]

固有方程式は

det(A - λI) = 0

であり、トレースと行列式から

λ^2 - 1.5 λ + 0.54 = 0

となる。判別式は1.5^2 - 4×0.54 = 0.09なので、固有値はλ=0.9とλ=0.6である。行列が無次元で、状態ベクトルの入力と出力の単位が同じなら、固有値も無次元である。

ここで「固有値はいつでも0.9や0.6」と覚えてはいけない。行列の成分、状態の定義、時間を一回進める幅、境界条件を変えれば固有値は変わる。連続時間の微分方程式では、固有値が1/sのような単位を持ち、exp(λt)の引数を無次元にすることもある。離散時間の遷移行列の固有値と、連続時間系の減衰率を同じ単位で扱わない。

6.4　量子、回路、CPUへの接続

量子力学では状態をベクトル、観測量を演算子として表し、固有値が測定結果の候補になる。回路の小信号解析では、複数の節点電圧をベクトル、線形化した抵抗・容量関係を行列で表す。CPUでは、同じ形式を制御状態やパイプラインの状態遷移へ使える。

これらは数学的な形を共有するが、量子状態の複素振幅、回路の実電圧、CPUのビット列は同じ物理量ではない。台帳の「対象」と「契約」を毎回分ける。

7　確率、対数、平均を性能の式へつなぐ

7.1　確率は単位を持たない重み

確率pは0以上1以下の無次元量である。互いに排反な事象の確率を足すと全体の確率になる。時間や電力を確率で重み付けすると、期待値（expected value）が得られる。

2段のキャッシュを単純化し、

T_c = キャッシュを調べる時間
T_m = 主記憶から追加で読む時間
h   = キャッシュに見つかる確率

とする。ミスのときは、キャッシュ探索に加えて主記憶の時間がかかるという契約なら、平均アクセス時間は

T_avg = h T_c + (1-h)(T_c + T_m)
       = T_c + (1-h) T_m

である。すべての項が時間なので、T_avgも時間になる。

例えばT_c=4 ns、T_m=80 ns、h=0.95なら、

T_avg = 4 ns + 0.05 × 80 ns = 8 ns

となる。ただし、書込みと読出し、複数段キャッシュ、並列要求、TLBミス (TLB miss)、ページフォルトを含めるなら、事象を分けて式を作り直す。hを測定せずに理想値として固定すれば、平均値は予測であって観測ではない。

7.2　対数は桁と比を扱う

対数は積を和へ変える。

log(ab) = log(a) + log(b)
log2(2^n) = n

logの底は用途で変わる。情報量をbitで数えるときはlog2、指数的な時間変化を扱うときは自然対数lnが現れる。log(x)のxは正で、物理量を入れる場合は基準量との比 x/x0 を使う。

CPUのアドレス幅w bitで表せるアドレス数が2^w、必要なbit数がlog2(N)という関係は、メモリ設計で使う。アルゴリズムの計算量のO(log N)は、入力サイズが増えたときの増え方を表す模型であり、CPUの実時間を直接保証するものではない。キャッシュ、分岐予測、I/O、割込み、メモリ階層が隠れている。

RC回路のexp(-t/τ)と対数は逆関数である。測定した電圧から時刻を推定するなら

t = -τ ln(1 - V_C/V_s)

となる。ただし0 ≤ V_C < V_s、入力と初期値がモデルどおり、測定ノイズが小さいという条件がある。V_CがV_sに近いほど、微小な誤差が推定時刻を大きく変える。

8　離散数学、グラフ、形式文法

8.1　集合と論理

集合（set）は要素の集まりである。回路の信号名、CPUのレジスタ、OSのプロセス、MiniPyの変数名を集合として記録できる。集合の包含、共通部分、差分は、資源の所有や可視性を表す。

論理値trueとfalse、論理積、論理和、否定は、条件分岐とゲート回路に共通する。ただし、回路の論理値は電圧範囲から読み出す契約であり、Pythonのboolは言語の値である。同じ真偽表を使えても、入力の型と成立条件は別である。

数学的帰納法は、有限ビットの加算器、リスト処理、命令列の不変条件を証明するために使う。

  1. 基底の場合に成立することを示す。
  2. nで成立すると仮定し、n+1でも成立することを示す。

この二段を省いて、いくつかの例が動いたことだけで全長のプログラムを保証してはいけない。後の形式検証では、命令の全ビットパターンや回路の全入力に対する性質を、機械的に調べる。

8.2　グラフは接続を表す

グラフG=(V,E)は頂点集合Vと辺集合Eからなる。辺に向きがある有向グラフなら、処理の流れ、信号の向き、依存関係を表せる。

グラフの頂点辺の意味後の対象
回路の節点素子端子や配線の接続KCL、ネットリスト
CPUの状態命令による状態遷移control-flow、pipeline
OSのプロセス親子・待ち・通信process tree、socket
処理系の構文文法規則による遷移AST、parser
メモリ階層命中・不命中 (hit/miss) や転送経路キャッシュ (cache)、TLB、ページ

グラフで経路を見つけるだけでは、辺を通る時間、容量、単位は決まらない。重み付き辺に遅延や確率を付ける場合、その重みの定義を台帳へ追加する。

8.3　形式文法は文字列から構造へ写す契約

処理系では、入力文字列が許される構造を形式文法（formal grammar）で定める。簡略化した式の文法をEBNF風に書く。

expression = term , { ( "+" | "-" ) , term } ;
term       = factor , { ( "*" | "/" ) , factor } ;
factor     = number | identifier | "(" , expression , ")" ;

{ ... }は0回以上、|は選択、,は並びを表す。この文法は、例えば1 + 2 * 3を受理するが、演算子の優先順位はexpressionとtermを分けた構造によって表す。文法が受理することは、式の計算結果が正しいことや、実行時に副作用がないことを保証しない。

文法から構文木を作る処理は、字句解析、構文解析、意味検査へ分かれる。identifierが宣言済みか、型が演算に適合するか、関数呼出しに副作用があるかは、文法だけでは決まらない。第91章以降で、MiniPyの文法、AST、bytecodeを同じ境界で追う。

形式文法と回路の真理値表は、どちらも「許される入力と結果」を定める規則だが、文法は記号列の構造、真理値表は論理入力の状態遷移を対象とする。型や単位まで同じだと考えてはいけない。

10　再現可能な単位検査の実験

10.1　runnerの位置づけ

この章の必修実験は、数値を手で計算するだけでなく、式の各演算に次元を持たせて誤った加算を止める。共通runnerの入口は次である。

book run 3 1

現在の book run 3 1 は固定Linux環境の解析・契約adapterで実行済みであり、コード、入力hash、期待結果、検査結果を保存する。ただしEuler/RK4や実測器を実行した結果ではない。読者が直接Pythonを実行する手順を併記する場合も、CPythonや外部domainの測定値へは昇格させない。

10.2　単位付き量の最小コード

以下は実験で使う最小の検査コードである。4基本次元を指数のタプル (M,L,T,I)にし、掛け算・割り算では指数を計算し、足し算・引き算では一致を要求する。

from dataclasses import dataclass
from math import sqrt

DIMLESS = (0, 0, 0, 0)
TIME = (0, 0, 1, 0)
VOLT = (1, 2, -3, -1)
OHM = (1, 2, -3, -2)
FARAD = (-1, -2, 4, 2)


@dataclass(frozen=True)
class Q:
    value: float
    dim: tuple[int, int, int, int]

    def __add__(self, other):
        if self.dim != other.dim:
            raise ValueError(f"dimension mismatch: {self.dim} + {other.dim}")
        return Q(self.value + other.value, self.dim)

    def __sub__(self, other):
        if self.dim != other.dim:
            raise ValueError(f"dimension mismatch: {self.dim} - {other.dim}")
        return Q(self.value - other.value, self.dim)

    def __mul__(self, other):
        if isinstance(other, (int, float)):
            return Q(self.value * other, self.dim)
        return Q(self.value * other.value,
                 tuple(a + b for a, b in zip(self.dim, other.dim)))

    __rmul__ = __mul__

    def __truediv__(self, other):
        if isinstance(other, (int, float)):
            return Q(self.value / other, self.dim)
        return Q(self.value / other.value,
                 tuple(a - b for a, b in zip(self.dim, other.dim)))


def require_dim(label, q, expected):
    if q.dim != expected:
        raise AssertionError(f"{label}: got {q.dim}, expected {expected}")


R = Q(1_000.0, OHM)
C = Q(1e-6, FARAD)
tau = R * C
require_dim("RC time constant", tau, TIME)

Vs = Q(5.0, VOLT)
Vc = Vs * (1.0 - 2.718281828459045 ** (-1.0))
require_dim("RC voltage", Vc, VOLT)

# A is a map from a dimensionless state to the same state.
A = ((0.8, 0.1), (0.2, 0.7))
assert all(isinstance(a, float) for row in A for a in row)
trace = A[0][0] + A[1][1]
det = A[0][0] * A[1][1] - A[0][1] * A[1][0]
disc = trace * trace - 4.0 * det
eigenvalues = ((trace + sqrt(disc)) / 2.0,
               (trace - sqrt(disc)) / 2.0)
eigenvalue_dim = DIMLESS
require_dim("eigenvalue of dimensionless A", Q(eigenvalues[0], eigenvalue_dim), DIMLESS)

Tc = Q(4e-9, TIME)
Tm = Q(80e-9, TIME)
h = Q(0.95, DIMLESS)
Tavg = h * Tc + (Q(1.0, DIMLESS) - h) * (Tc + Tm)
require_dim("average access time", Tavg, TIME)

print("RC tau", tau.value, "s")
print("eigenvalues", eigenvalues)
print("average access", Tavg.value, "s")

上のVcの計算は、RC式が電圧を返すことを確認するための値であり、測定値ではない。Aの要素を無次元と宣言しているのは、状態を「基準値で正規化した二成分」としたからである。正規化しない電圧と電流を同じベクトルへ入れるなら、行列の各要素の単位比を記録し直す必要がある。

runnerが生成すべき期待形は次である。数値はこの入力から計算した予測であり、実験環境で取得したログの主張ではない。

RC tau 0.001 s
eigenvalues (0.9, 0.6)
average access 8e-09 s

10.3　失敗を成功として記録する

次の行を追加すると、ΩとFを足そうとして例外になる。

bad = R + C

これはrunnerの故障ではなく、検査が誤った式を見つけたという成功である。次元検査を無効化して数値だけを足し、1000.000001という答えを得ることは、物理的に意味のある計算ではない。

反対に、2 * R * Cは単位検査を通過するが、RC回路の時定数が2倍になる根拠はこの検査から出ない。係数は回路の接続、微分方程式、定義した時定数の閾値から検証する。

12　この章で確定した境界

本章の道具は、次の順で取り出す。

  1. 対象をスカラー、ベクトル、行列、関数、確率、グラフ、文字列のどれで記録するか決める。
  2. 各記号に単位または次元を付け、足し算・指数・対数の入口を検査する。
  3. 微分・積分なら、変化率または累積量の単位、初期値、積分区間を記録する。
  4. 行列・固有値なら、状態の成分、行列の行列、時間刻み、固有値の単位を記録する。
  5. 確率・平均なら、事象を重複なく分け、平均が隠す分布や最悪値を残す。

逆に、次の主張は本章の数学だけでは保証しない。

  • 次元が合う式の係数、符号、初期条件が正しいこと。
  • RC解析解が、寄生素子を含む実部品の波形と一致すること。
  • 固有値が小さいから、任意の非線形系が安定すること。
  • 平均アクセス時間が、個々の要求の遅延やtail latencyを代表すること。
  • フーリエ係数があるから、有限サンプルから元の信号を一意に復元できること。

これらは、第4章以降の測定、回路モデル、量子状態、CPU状態、OS trace、処理系の意味規則で別に検証する。

次章では、ここで出したRCの常微分方程式を、解析解、Euler法、Runge--Kutta法、SPICEの四つの表現で比べる。Δt、丸め、初期条件、測定器の入力抵抗を含め、同じ「波形」がどの層の模型と実装から得られたかを記録する。

5　模型の境界と章間の橋

この章の模型は、適用範囲を明示して初めて安全に使える。次の限界を一つずつ、本文のどの主張に効くかと一緒に読む。

  • 次元解析は式の係数、符号、境界条件、初期値、モデルの正しさを証明しない。
  • 単位が同じでも、角度、確率、論理値、アドレスなど意味の異なる無次元量を足してよいとは限らない。
  • ベクトル、行列、固有値の形が共通でも、電磁場、回路電圧、CPUビット列、OS状態、Python値を同一の物理量と扱わない。
  • RCの解析解は線形・一定parameter・集中定数・指定入力と初期値の範囲に限る。
  • Euler法の単位が合っても、刻み幅の安定性、丸め、モデル誤差は別に検査する。
  • 複素インピーダンスは線形な正弦波定常状態の表現であり、任意の過渡・非線形素子の完全な記述ではない。
  • フーリエ変換は時間の順序、分岐、因果関係を完全には保存せず、有限窓とサンプリングに依存する。
  • 固有値の減衰・増大は、固定線形写像の範囲に限り、非線形・飽和・外乱を含む実装全体の安定性を保証しない。
  • 平均アクセス時間は、個々の遅延、tail latency、相関、並列性を表さない。
  • グラフは接続の模型であり、辺の遅延・抵抗・確率の意味と単位を別途定義する。
  • 形式文法は文字列構造を定めるが、名前解決、型、実行時副作用、例外の安全性を定めない。
  • 単位検査の解析adapter成果物は生成済みだが、外部toolの測定ログは未生成であり、期待出力を実測結果として扱わない。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

途中で予測と結果が異なったら、最後の行から修正しない。入力、仮定、更新、表現、実行環境の順に一つずつ戻り、最初に不一致になった行へ診断名を付ける。診断名を付けられない差は、未解決として後段へ渡さない。

9　逆向きに説明する

今度は出力から出発し、どの入力と規則が必要だったかを逆向きに書く。画面の文字、論理値、レジスタ値、電圧、エネルギーのように異なる表現を、途中のartifactなしで直接つないではいけない。各矢印のそばに、保証する契約と保証しない詳細を一つずつ書く。

逆向きの説明で最初に見つかる欠落は、たいてい三種類のどれかである。入力の単位または幅がない、モデルの適用条件がない、または実行と測定の境界がない。この章の本文へ戻り、欠落を埋める行を一つ追加する。

10　再現記録の最小形

再現記録には、章ID、実験ID、case、入力hash、toolまたはmodelの版、終了コード、出力artifact、source_kind、status、measuredを残す。時刻やhost名は再現性の補助情報であり、計算値や状態遷移の一部として扱わない。

この最小形を満たせないときは、実験が難しいのではなく、契約がまだ閉じていない。閉じていない契約は、成功結果を保存するより先に、未指定欄と診断欄を保存する。

11　次章の読者への引き継ぎ文

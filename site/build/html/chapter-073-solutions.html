第73章 演習解答

E1 抽象機械

object・値・評価・副作用を分けて追跡する。

E2 object representation

byte列と型による解釈を別欄に置く。

E3 lvalueとrvalue

lvalueは場所、rvalueは評価された値である。

E4 pointer arithmetic

p+iはi*sizeof(*p) byte進む。

E5 struct layout

alignmentからoffsetとpaddingを計算する。

E6 stack frame

保存ra、locals、引数領域、sp整列を表にする。

E7 ABI呼出し

引数・結果registerと保存規則を固定する。

E8 heapとstorage duration

automatic/static/allocatedの生存期間を分ける。

E9 assembly比較

sourceの役割を命令・register・stackと対応する。

E10 負のテスト

未定義動作を正常値とせず診断する。

自己採点キー

E1はc@0、x@4、padding=3、size=8、alignment=4。E2はlittle endianで44 33 22 11。E3は場所と値を別欄にする。E4は0x200c（one-pastは0x2010）。E5はalignmentからoffset/paddingを導く。E6は24 bytes（整列単位16）。E7はa0=2、a1=3からa0=5。E8はstatic/automatic/allocatedを分ける。E9はa0→addi 1→a0→return。E10は4種類の未定義動作を正常値へ丸めず止める。

追加演習の完全解答

変更課題の解答: use-after-free、stack escape、alignmentを確認する。まず入力、単位、境界条件、実装の中間値を順に比較し、最初にずれた値を故障箇所とする。

条件変更の解答: stack上の配列を返すと寿命切れで無効になり、heapなら所有者がfreeまで保持する。

再挑戦の解答: allocation方式を変えると寿命契約も変わるため、呼出し側のfree責任を明示する。変更前後の入力・期待値・実測値を表にし、実装・入力・期待値のどれに属するかを明記する。

第16章　結晶、Blochの定理、エネルギーバンド

1　原子の準位が、結晶では帯になる

第15章では、一粒子準位E_i、縮退度g_i、温度T、化学ポテンシャルμから、Fermi–Dirac占有率を数えた。結晶では、原子や単位胞が空間に規則正しく並ぶ。隣の単位胞と同じ形のポテンシャルを感じるため、孤立原子の一本の準位は、互いに少し異なる多数の準位へ分かれ、エネルギーの連続した範囲である「バンド」に見える。

最初の模型として、格子間隔a=0.5 nm、単位胞数N_cell=100、最近接結合エネルギーt=1.0 eV、中心エネルギーε=0 eVの一次元鎖を考える。計算される分散は

E(k) = ε - 2t cos(ka)                         (16.1)

で、-π/a≤k<π/aの範囲にN_cell個のk状態が並ぶ。バンド幅は4|t|=4 eVである。スピンを別のラベルとして数えれば、各k状態に二つのスロットがある。これは第15章の「準位・状態数・占有」を、周期系へ渡した例である。

この章の中心問題は次である。

規則正しく並んだ原子の一粒子準位を、波数、バンド、ギャップ、状態密度としてどう数えるか。

ここでのバンドは一次元・一粒子・最近接の模型から得る予測であり、実際の固体の測定スペクトルではない。book run 16 1は固定入力から契約モデルを実行済みだが、外部固体domain solverや実スペクトル測定は未実行（measurement.status=not_run）である。

第15章からは、準位E_i、縮退g_i、温度T、化学ポテンシャルμ、占有率f_iを受け取る。第17章では、バンド端と状態密度を使って、電子と正孔のキャリア数へ進む。

2　周期ポテンシャルとBlochの定理

2.1　結晶の最小幾何

一次元結晶の単位胞を長さaとし、同じポテンシャルが繰り返すとする。

V(x+a) = V(x)                                 (16.2)

Vは電圧ではなく、一粒子の位置エネルギーなので単位はJまたはeVである。xの単位はm、aもmでなければならない。三次元なら格子ベクトルRに対してV(r+R)=V(r)となるが、まず一方向だけを見る。

孤立原子の波動関数が一つの中心に局在しているのに対し、結晶では隣の中心との重なりがある。重なりが小さければ、各原子の同じ軌道を足し合わせた状態を出発点にできる。重なりを無視すれば一本の準位、重なりを入れれば異なるkの準位へ分かれる。

2.2　Blochの定理を形で読む

周期ポテンシャルの固有状態は、

ψ_k(x) = exp(i k x) u_k(x),
u_k(x+a) = u_k(x)                         (16.3)

と書ける。u_kは格子周期の細かな形、exp(i k x)は単位胞をまたぐ位相の変化を表す。したがって

ψ_k(x+a) = exp(i k a) ψ_k(x)                (16.4)

である。これをBloch境界条件と呼ぶ。ψそのものが毎回同じになる必要はなく、複素位相だけが変わってよい。確率密度|ψ|²は位相を消すので、周期性を保つ。

これは「波動関数が結晶の中で一定」という意味ではない。u_kは単位胞内で変化し、kは異なる位相の結合を区別するラベルである。kの単位は1/m、kaは無次元である。

2.3　有限結晶でk状態を数える

単位胞N_cell個を輪にして全体を長さL=N_cell aとする。全体の境界を周期にすれば、

ψ(x+L)=ψ(x),
k_m = 2πm/(N_cell a)                         (16.5)

となる。異なる整数mをBrillouin領域-π/a≤k<π/aへ折りたたむと、k状態はN_cell個になる。状態数を増やすには、許されるkの間隔Δk=2π/(N_cell a)を細かくする。結晶を大きくすると、同じバンドの中に状態が密に見える。

スピンを数える場合は、各空間状態kへ↑と↓を別々に付ける。スピン縮退2をすでに付けた表では、さらに2を掛けない。第15章と同じ二重計数の注意がここでも必要である。

3　tight-bindingでバンド分散を作る

3.1　隣の原子へ飛ぶ行列

各単位胞に一つの局在軌道|n>があり、そのエネルギーをεとする。最近接の隣へ結合する振幅をtとすると、最小Hamiltonianは

H = ε Σ_n |n><n|
    - t Σ_n (|n><n+1| + |n+1><n|)          (16.6)

である。Hの単位はエネルギー、tもエネルギーである。tは力や電圧ではない。符号は局在軌道の位相の選び方で変わることがあるので、まず|t|とバンド幅を確認する。

Bloch型の係数c_n=exp(i k n a)を(16.6)へ入れると、隣の二項がexp(ika)とexp(-ika)になり、

E(k)=ε - t[exp(ika)+exp(-ika)]
     =ε - 2t cos(ka)                          (16.7)

を得る。t>0なら最小エネルギーはk=0、最大はゾーン境界k=π/aである。t=0では全kが同じεとなり、孤立原子の準位へ戻る。これは「結合を強めると一本が幅を持つ」という検算になる。

3.2　二サイト単位胞とギャップ

単位胞内に異なるサイトA、Bを一つずつ置き、オンサイトエネルギーをε_A、ε_B、結合を同じtとする。Bloch境界を使った2×2行列の一例は

H(k) = [[ε_A, -t(1+exp(-ika))],
        [-t(1+exp(+ika)), ε_B]]             (16.8)

である。H(k)は複素数を含むが、下三角が上三角の複素共役なのでHermitianである。固有値は

ε_bar = (ε_A+ε_B)/2
Δ     = ε_A-ε_B
E_±(k)=ε_bar ± sqrt((Δ/2)^2 + 4t^2 cos^2(ka/2))  (16.9)

となる。ゾーン境界k=π/aでは結合項が消え、二つのバンドの差は|Δ|になる。Δ≠0なら、上下のバンドの間にギャップが開く。Δ=0ならこの最小模型の境界ではギャップは閉じる。ギャップは「状態が存在しないエネルギー範囲」であり、単に占有率が小さい範囲ではない。

二サイト模型の単位胞は二つのサイトを持つため、N個の単位胞には空間状態が2N個ある。上下の各バンドにN個ずつ、スピンを含めれば各バンドに2N個の一粒子スロットがある。式(16.9)を使うときは、単位胞の長さa、サイト間隔、kの範囲を先に固定する。

3.3　バンドとFermi–Dirac占有をつなぐ

第15章の式を、離散準位E_iからバンドの状態E_n(k)へ置き換えると、

f_n(k)=1/[exp((E_n(k)-μ)/(k_B T))+1]
N=Σ_{n,k} g_spin f_n(k)                   (16.10)

となる。ここでも指数の引数は無次元、g_spin=2はスピンを別に数えない表記でのみ掛ける。kを連続積分へ置き換える場合は、状態密度またはL/(2π)という状態数の係数が必要である。

温度を上げるとμの周りの占有がなだらかになる。バンドギャップがある場合、「ギャップ内に状態がない」ことと「ギャップの近くで占有が少ない」ことを区別する。前者は一粒子Hamiltonianのスペクトル、後者は温度とμを含む統計の結果である。

4　状態密度を最小限で導入する

4.1　状態密度の定義

状態密度D(E)は、エネルギー幅dEの中に何個の状態があるかを表す関数である。有限結晶の全状態を数える定義をD_total(E)とし、離散kなら形式的には

D_total(E) = Σ_k δ(E-E(k))                   (16.11)

であり、数値ではエネルギーbinへヒストグラムする。D(E)の単位は「状態数/eV」または「状態数/J」で、確率密度とは違う。バンドに状態がない範囲ではD(E)=0、バンド端では一次元tight-bindingの曲線が大きくなる。

一サイト単位胞の(16.7)を連続kとして数えると、単位胞あたり・スピン一種類の状態密度はバンド内で

D_cell(E)=1/[π sqrt(4t^2-(E-ε)^2)]       (16.12)

と書ける（|E-ε|<2|t|）。有限N_cell結晶の全DOSを解析曲線と比較するときはD_total(E)=N_cell D_cell(E)とする。平方根の中身が負の外側では状態はない。スピンを含めるならさらに2倍する。端で発散する形は一次元模型の特徴で、現実の三次元結晶の状態密度をそのまま表すわけではない。

4.2　数値binと解析式の比較

k_mを有限個生成しE(k_m)を計算し、同じエネルギー幅ΔEのbinへ全状態数として数える。bin幅を小さくすると形は細かくなるが、各binの統計的な揺らぎは大きくなる。N_cellを増やすとk点が増え、D_bin/N_cellが解析式(16.12)へ近づく。したがって、状態密度の見た目だけでなく、全エネルギー範囲で

Σ_bins D_bin_total(E) ΔE ≈ N_cell

となることを確認する。ここでD_bin_totalは全結晶のDOSである。スピン一種類なら右辺はN_cell、スピン二種類なら2N_cellとなり、単位胞あたり曲線と比較する場合は左辺をN_cell（または2N_cell）で割る。

5　有限差分と行列で計算する

5.1　連続Schrödinger方程式の有限差分

第14章の一次元Hamiltonianを、単位胞長a=M Δxとなるよう端点を重複させずj=0,...,M-1の格子点x_j=j Δxへ置く。周期ポテンシャルV_j=V(x_j)に対し、二階微分を中心差分へ置き換えると、

H_jj       = hbar^2/(m Δx^2) + V_j
H_j,j+1    = H_j,j-1 = -hbar^2/(2m Δx^2)       (16.13)

となる。hbar^2/(m Δx^2)はJ、V_jもJにする。端点j=0とj=M-1を単純に同じ値で結ぶと、周期境界を課したことになるが、Bloch境界では

ψ(x+a)=exp(i k a) ψ(x)

の位相を端点接続へ入れる必要がある。a=MΔxと格子の定義を固定し、格子点を重複させない端の結合へexp(±ika)を一度だけ掛ける。同じa、M、Δx、ポテンシャル周期を満たさない入力はboundary_geometry_mismatchとして失敗にする。

5.2　行列のHermitian性と固有値

数値行列H(k)を作ったら、

max_abs(H - H.conjugate().T) < tolerance

を検査する。これが壊れると固有値が複素になり、保存系のエネルギーとして解釈しにくい。固有値を小さい順に並べ、同じkでの解析式または十分細かい基準計算と比較する。

tight-bindingの結合tは最初からeVで与えられる。一方、有限差分の隣接係数hbar²/(2mΔx²)はJで計算するか、hbarと質量とΔxをeVに換算してから使う。両者を同じ「ホッピング」と呼んでも、単位と由来は異なる。

5.3　数値収束の順番

最初に単位胞内の格子数を増やしてΔx依存を調べ、次に単位胞数またはk点数を増やしてバンドのサンプリング依存を調べる。誤差は一つの数字だけでなく、

relative_energy_error = |E_num-E_ref|/max(|E_ref|, energy_scale)
boundary_residual      = |ψ(x+a)-exp(i k a)ψ(x)|
hermitian_residual      = max_abs(H-H†)

として保存する。格子を細かくしても境界条件が間違っていれば、物理的に正しい収束にはならない。

6.2　負のテスト

次の入力は成功として扱わない。

a <= 0, Δx <= 0, m <= 0, T < 0
V_jをJ、hbarをeV sのまま混在
kを1/mでなく無次元のままexp(i k a)へ入れる
周期境界を指定したのに端点を開放のままにする
H != H†、NaN、非有限な固有値
二サイト単位胞の状態を一サイトとして数える
bin積分がN_cellまたは2N_cellに合わない
測定データがないのにmeasured=trueと記録する

T=0は第15章と同じくFermi–Dirac式へ直接代入せず、占有の極限として扱う。Δ=0はギャップが閉じる有効なcaseであり、エラーと「gap=0の物理入力」を区別する。

7　ここで分かったことと、まだ分からないこと

Blochの定理は周期性を、単位胞内の関数u_kと、胞をまたぐ位相exp(ika)へ分ける。tight-bindingは隣接サイトの結合を行列にし、固有値E_n(k)をバンド分散へ変える。二サイト模型ではオンサイト差によってギャップを作れる。状態密度は、k状態をエネルギーへ写したときの数え上げである。

しかし、バンド図だけで電気抵抗や半導体のキャリア数が決まるわけではない。散乱、格子振動、欠陥、電子間相互作用、試料の境界、三次元の状態密度は別の模型である。第17章では、本章のバンド端、ギャップ、状態密度と、第15章のμ・T・Fermi–Dirac占有を使って、真性半導体の電子・正孔を数える。

8　次章へ渡す設計判断

第17章へ渡すcanonical recordでは、バンド番号とkに加えて、DOSの正規化基準（total_crystal、per_cell、またはper_volume）、エネルギー単位、単位胞長、スピン係数を必須フィールドにする。有限差分ではa=MΔx、端点重複なし、Bloch位相の向きを同じrecordへ保存する。これらが埋まらない出力は、数値がもっともらしくてもキャリア密度の入力に昇格させない。

バンド端とギャップは一粒子Hamiltonianの性質、DOSは状態数の正規化、Fermi–Dirac占有は温度とμを含む統計の性質である。第17章ではこの三つを、体積あたりの状態密度と電子・正孔の数え上げへ接続する。散乱、移動度、欠陥、電荷中性はさらに別の入力として残す。

16.補助演習　手を動かす導出帳

結晶、Blochの定理、エネルギーバンドの計算を、結果だけでなく途中の状態から再構成する。以下では、各実験を同じ順序で読む。順序をそろえることで、物理の積分、回路の連立方程式、命令の状態遷移、処理系のstack操作を同じ観測方法で比較できる。

0　共通の書式

最初の行に入力と単位、二行目に使う式または遷移規則、三行目に途中状態、四行目に出力、五行目に検証条件を書く。五行を書けない場合は、本文の式・表・仕様のどれかがまだ手元にない。数値を計算機へ渡す前に、符号、桁、基数、配列の添字、アドレス幅を声に出して確認する。

2　式・状態・コードを往復する

式を一度紙へ書き、同じ式をコードの変数名へ対応づける。コードの一行を読んだら、式のどの項を計算しているかを指で戻る。この往復を省略して出力だけを比較すると、係数の取り違え、整数のwrap、境界条件の欠落を見逃す。

導出では、既知の値と未知の値を分ける。未知量を一つずつ消去し、最後に単位・符号・範囲を検査する。数値計算では刻み幅や反復回数も入力であり、結果の末尾の桁だけを見て精度を判断しない。

3　失敗を一段ずつ切り分ける

故障診断では、まず入力を固定したまま実行し、次に一つの条件だけを変更する。二つの変更を同時に入れると、見えた差がどの条件の効果か分からなくなる。

第一の切り分けは入力である。有限値、型、単位、符号、配列長、アドレス範囲を確認する。第二は計算である。式の項、丸め、符号拡張、stack effect、遷移の順序を確認する。第三は境界である。ROM/RAM、host/target、解析/実測、適用内/適用外を確認する。

失敗を直した後は、成功例だけを再実行しない。失敗例を同じ入力で再実行し、診断名が維持されることを確認する。診断名が消えた場合は、修正がエラーを隠している可能性がある。

5　次の層へ渡す最小データ

次章へ渡すのは、結論の文章だけではない。入力の意味、途中状態、単位または幅、成立条件、破綻条件、source_kind、status、measuredを一つの記録にまとめる。次章が別の模型を使う場合は、同じ記号でも定義が変わることを明示する。

この章の成果物を開いた次の読者が、本文を読まずに同じ実験を再現できることを目標にする。ただし、実行可能モデルや契約再生の結果を実測値へ昇格させない。外部toolや機器が必要な例は、その未実行理由を残したまま次のゲートへ渡す。

6　短い口頭試問

最後に、次の質問へ答える。『入力は何か』『隠した変数は何か』『どの不変条件を検査したか』『一番近い失敗は何か』『測定値と呼べない理由は何か』。五問に答えられれば、結果の暗記ではなく契約の再構成ができている。

16.実践ケースブック　宣言から観測へ

このケースブックは、結晶、Blochの定理、エネルギーバンドの中心問題「周期的な原子配列の中で、電子はなぜ局在せず結晶全体へ広がった状態を持てるのか。」を、manifestに宣言された入力から追い直すための作業欄である。本文の結論を写すのではなく、入力、途中状態、出力、境界、出所の順に自分で埋める。ここにない値を補ってはいけない。

ケースを読む共通手順

  1. case名と入力を最初に固定する。数値には単位、bit列には幅、状態には初期条件、sourceには版を付ける。
  2. 途中状態を一つだけ更新し、更新前後を表にする。式の左辺と右辺の次元、レジスタの幅、stackの深さ、回路端子の向きを照合する。
  3. 期待値を出力欄へ写す。ただし analytic_prediction、runner_output、measurement を同じ欄へ置かない。
  4. 近い反例を一つ選び、失敗がどの層で止まるべきかを書く。正常値への丸めや、未実行の成功表示は禁止する。
  5. 最後に、次章へ渡す値と、その値が成立する条件を一文でまとめる。

1　代表入力の棚卸し

3　実験カード

4　反例と故障診断

反例は、正常例を否定するためではなく、契約の範囲を見つけるために作る。次の各項目は、入力、最初に破綻する層、期待する診断、後段を止める理由を一組で書く。

明示的な負のテストがない場合も、範囲外・単位違い・幅超過・未初期化のうち一つを追加して診断を書く。

5　模型の境界と章間の橋

この章の模型は、適用範囲を明示して初めて安全に使える。次の限界を一つずつ、本文のどの主張に効くかと一緒に読む。

  • Blochの定理は周期ポテンシャルの一粒子固有状態についての構造であり、相互作用や無秩序を自動的には含まない。
  • tight-bindingは局在軌道と最近接結合の最小模型で、実材料の全軌道、格子振動、欠陥、散乱を含まない。
  • 一次元の状態密度のバンド端特異性は次元に依存し、三次元結晶のDOSへそのまま移せない。
  • バンドギャップは一粒子スペクトルの状態のない範囲であり、Fermi–Dirac占有率が小さいこととは別である。
  • 有限差分の収束は、正しい単位と境界条件を使ったときだけ物理的な収束を意味する。
  • スピン縮退を掛ける表とスピンラベルを列挙する表を混ぜると状態数を二重に数える。
  • 第15章の平衡占有を非平衡輸送、強い相互作用、時間依存励起へそのまま適用しない。
  • 本章の固定runnerは契約を再生済みだが、図・バンド計算の外部tool実行は未実行で、具体値は解析または数値予測である。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

途中で予測と結果が異なったら、最後の行から修正しない。入力、仮定、更新、表現、実行環境の順に一つずつ戻り、最初に不一致になった行へ診断名を付ける。診断名を付けられない差は、未解決として後段へ渡さない。

9　逆向きに説明する

今度は出力から出発し、どの入力と規則が必要だったかを逆向きに書く。画面の文字、論理値、レジスタ値、電圧、エネルギーのように異なる表現を、途中のartifactなしで直接つないではいけない。各矢印のそばに、保証する契約と保証しない詳細を一つずつ書く。

逆向きの説明で最初に見つかる欠落は、たいてい三種類のどれかである。入力の単位または幅がない、モデルの適用条件がない、または実行と測定の境界がない。この章の本文へ戻り、欠落を埋める行を一つ追加する。

10　再現記録の最小形

再現記録には、章ID、実験ID、case、入力hash、toolまたはmodelの版、終了コード、出力artifact、source_kind、status、measuredを残す。時刻やhost名は再現性の補助情報であり、計算値や状態遷移の一部として扱わない。

この最小形を満たせないときは、実験が難しいのではなく、契約がまだ閉じていない。閉じていない契約は、成功結果を保存するより先に、未指定欄と診断欄を保存する。

11　次章の読者への引き継ぎ文

最後に、次章の読者がこの章を読み返さなくても前提を再構成できる引き継ぎ文を書く。第一文はこの章が固定した定義、第二文は代表入力と途中状態、第三文は守る不変条件、第四文は最も近い破綻条件、第五文は未実行または未照合の境界である。

引き継ぎ文の主語を『この値は』だけにしない。『この模型では』『この版のtoolでは』『このmemory領域では』『このsource spanでは』のように、値の所有者を明記する。所有者が変わるところが、章間のbridgeであり、独立レビューが最初に読む境界である。

引き継ぎ文を書いたら、manifestの bridge_in と bridge_out、handoffのopen question、required artifactを照合する。本文に書いた橋と台帳の橋が異なる場合は、どちらかを勝手に合わせず、差分を未解決として残す。

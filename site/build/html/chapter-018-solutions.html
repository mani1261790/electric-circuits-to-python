第18章 演習解答

E1

完全解答

ドナーは伝導帯端Ecの少し下に準位EDを作り、電子を伝導帯へ渡しやすい不純物の模型。アクセプタは価電子帯端Evの少し上に準位EAを作り、価電子帯から電子を受け取りやすい不純物の模型である。ドナーが電子を失うと正にイオン化し、その密度がND_plus。アクセプタが電子を受け取ると負にイオン化し、その密度がNA_minus。前者は伝導帯電子nを増やす方向、後者は価電子帯の空席である正孔pを増やす方向へ働く。総濃度ND,NAとイオン化濃度は温度とEFに依存するため別に保存する。

再挑戦

ドナーが中性のときと正にイオン化したときの電荷と、対応する伝導帯電子の変化を二行で書け。

E2

完全解答

E_F-E_D=-0.205+0.045=-0.160 eV、従って指数の引数は-0.160/0.02585≈-6.19。exp(-6.19)≈0.00205なので、N_D^+/N_D=1/(1+2×0.00205)≈0.9959。よってN_D^+≈9.959×10^15 cm^-3、イオン化率は約99.6%である。これは完全イオン化近似に近い解析予測であり、runnerや測定結果ではない。

再挑戦

同じE_D、N_D、g_DでT=50 Kにする。ただし、300 Kで使ったE_F=E_c-0.205 eVを固定してはいけない。まず式(18.5)のF(E_F)=0を50 Kのk_BTで二分法にかけ、その解を式(18.3)へ戻す。k_BT≈0.00431 eVなので、同じ準位差は約6倍の大きさの指数となり、N_D^+とnが大きく下がる凍結を判定できる。固定したEFで率だけを計算するのは「そのEFを外から与えた場合」のチェックであり、ドープ半導体の自己無撞着な凍結計算ではない。

E3

完全解答

E_A-E_F=0.055-0.1785=-0.1235 eV、指数の引数は-0.1235/0.02585≈-4.78。exp(-4.78)≈0.00838、分母は1+4×0.00838≈1.0335なので、N_A^-/N_A≈0.9676、N_A^-≈9.676×10^15 cm^-3。EFを上げるとEA−EFが小さくなり、指数が小さく、分母が1へ近づくため、NA_minusはNAへ近づく。縮退因子の規約はモデル入力として記録する。

再挑戦

gAを1へ変えた場合、同じEFと温度でイオン化率はいくつか。縮退因子を定義なしに固定してはいけない理由も添えよ。

E4

電子は-e、正孔は+e、正にイオン化したドナーは+e、負にイオン化したアクセプタは-e。電荷密度はrho=e(p+N_D^+-n-N_A^-)であり、バルク中性rho=0からp+N_D^+=n+N_A^-。真性ではND=NA=0なのでp=n。nやpやイオン化濃度は正の個数密度で、電荷の符号は別に掛ける。

再挑戦

n=3×10^15、p=1×10^15、N_D^+=0のとき、電荷中性を満たすN_A^-を求めよ。単位は同じとする。

E5

完全解答

(i) donor-onlyでpが小さければ、式(18.5)からn≈N_D=1.0×10^16 cm^-3。(ii)質量作用則からp≈n_i^2/N_D=(6.5×10^9)^2/(1.0×10^16)≈4.2×10^3 cm^-3。(iii)n=N_c exp[-(E_c-E_F)/(kBT)]よりE_c-E_F=kBT ln(N_c/N_D)。比は2.8×10^3、自然対数は約7.94なので、E_c-E_F≈0.02585×7.94≈0.205 eV。n型でEFがEc側へ寄る。

再挑戦

NDを1.0×10^18 cm^-3へ増やしたとき、同じ非縮退式でEc-EFを見積もり、NCに近づくことで近似が危うくなる理由を説明せよ。

E6

完全解答

(i) acceptor-onlyでnが小さければp≈N_A=1.0×10^16 cm^-3。(ii)n≈n_i^2/N_A≈4.2×10^3 cm^-3。(iii)p=N_v exp[-(E_F-E_v)/(kBT)]からE_F-E_v=kBT ln(N_v/N_A)。比は1.0×10^3、lnは6.91なので、E_F-E_v≈0.02585×6.91≈0.1785 eV。p型ではEFがEv側へ寄り、E5のn型と反対である。

再挑戦

NAを1.0×10^18 cm^-3へ増やしたとき、EF-Evの近似値を計算し、NVとの比較から近似限界を説明せよ。

E7

完全解答

assert T > 0
assert all(levels and densities are finite and nonnegative)
F(EF) = p(EF) + ND_plus(EF) - n(EF) - NA_minus(EF)
lo, hi = choose_bracket(Ev, Ec, ED, EA)
if F(lo) < 0 or F(hi) > 0:
    return status="bracket_failed"
for iteration in range(max_iter):
    mid = (lo + hi)/2
    residual = F(mid)
    if abs(residual) < tolerance_density:
        return EF=mid, residual=residual, status="converged"
    if residual > 0:
        lo = mid
    else:
        hi = mid
return EF=mid, residual=residual, status="not_converged"

EFが増えるとpとND_plusは減り、nとNA_minusは増えるのでFは通常減少する。従ってF(lo)>0、F(hi)<0の区間を保つ。端点で符号を挟めない場合は準位範囲、単位、濃度、モデルの不足を診断し、適当なEFを返さない。

再挑戦

F(lo)>0,F(hi)>0だった場合にhiを広げるべきか、loを動かすべきか。Fが減少関数であることを使って答えよ。

E8

領域イオン化率キャリアFermi準位
凍結浅い不純物でも低く、ND_plusまたはNA_minusが総濃度より小さい多数キャリアも少なく、熱励起が支配的でない不純物準位とバンド端の関係を有限イオン化式で解く
外因浅い不純物がほぼイオン化donor-onlyならn≈ND、acceptor-onlyならp≈NA、反対側はni²/NdonorならEc側、acceptorならEv側へ寄る
真性ドーパントよりniが支配的nとpが再び近づき、n≈p≈ni真性化学ポテンシャルへ近づく

領域の境界は固定温度ではなく、イオン化率、ND/NA、ni、許容誤差から判定する。温度上昇でniは指数的に増え、低温ではkBTが小さいため準位差によるイオン化の指数効果が強くなる。

再挑戦

ドナー濃度を二桁増やすと、外因領域から真性領域へ移る温度がどう動くかを、niとNDの大小で説明せよ。

E9

完全解答

比較すべき量は、N_D^+/N_D、n、p、EF、電荷中性残差F(EF)、質量作用残差、二分法の反復数と近似の適用判定である。300 Kでは浅いドナーの準位差が数個のkBTに比べて大きく、E2のようにイオン化率がほぼ1なら完全イオン化でn≈NDがよい初期予測になる。50 KではkBTが約0.00431 eVと小さく、同じ準位差が多数のkBTになり、ドナーの占有が変わってN_D^+がNDよりかなり小さくなり得る。完全イオン化と非縮退は別々の仮定なので、300 Kで一方が成立しても低温で両方が成立するとは限らない。

再挑戦

有限イオン化solverと完全イオン化近似の差が1%を超えたとき、近似を失敗と記録するか、解析予測として残すか。source_kindとstatusを使って答えよ。

E10

完全解答

(a)invalid_concentration。濃度を0以上へ修正する。(b)invalid_band_orderまたはinvalid_band_gap。半導体caseならEc>Evを確認する。(c)ionization_out_of_bounds。式・縮退・単位を点検し、0≤ND_plus≤NDにする。(d)density_unit_mismatchまたはenergy_unit_mismatch。全濃度とDOS、全エネルギーとkBTを同じ単位へ揃える。(e)zero_temperature_limit。有限温度式へ0を代入せず、占有とイオン化の極限を別statusで扱う。(f)missing_quasi_fermi_levels。non_equilibriumでmu_nまたはmu_pが欠けているので両方を入力する。両方がそろっていても本章の不純物 kinetics は未定義なのでunsupported_non_equilibrium_modelとする。(g)bracket_failed。探索範囲、濃度、準位、単位、模型の状態数を確認する。各診断を一つの「計算失敗」へまとめない。

再挑戦

T=0 Kで浅いドナーのイオン化状態を決めるには、EDとEFの大小をどう場合分けするか。EF=EDの境界は別扱いにせよ。

E11

完全解答

最低限、artifact_id、status、source_kind、measured、inputs（Ec、Ev、ED、EA、ND、NA、gD、gA、Nc、Nv、ni、T、単位、equilibrium_model、regime_thresholds）、outputs（EFまたはmu、mu_n、mu_p、ND_plus、NA_minus、n、p、majority、minority）、diagnostics（neutrality_residual、mass_action_residual、bracket、iterations、ionization_ratio、net_ionized_dopant、approximation_scope）、equation_ids、runner_version、created_atを保存する。組み合わせ例は、(i)analytic_prediction+predicted、(ii)numeric_prediction+not_executed、(iii)runner_analytic_contract+executed_analytic、(iv)measurement+measuredである。共通runnerは入力由来の契約モデルを実行済みだが実測ではなく、measurement.status="not_run"を維持する。測定の場合だけ試料・温度・ドーパント評価法・装置条件を追加する。

再挑戦

解析式と二分法の結果を同じartifactへ上書きせず比較するため、run_id以外に保存すべき設定値を三つ挙げよ。

E12

完全解答

第19章へは、ドーピング後の正の個数密度n,p、電子の電荷-e、正孔の有効電荷+e、Fermi準位EF、温度T、平衡か非平衡か、可能なら準Fermi準位を渡す。第19章はこれらへ散乱時間や移動度を加えてdrift、濃度勾配と拡散係数を加えてdiffusion、生成・再結合係数や寿命を加えて再結合を計算する。n,pだけでは、キャリアがどの速さで動くか、電場や勾配がどの方向か、何秒で失われるかが決まらない。非平衡ではmu_nとmu_pを分け、平衡のnp=ni^2を無条件に使わない。

再挑戦

第19章へ渡す入力を「密度」「符号」「平衡条件」「輸送へ追加する量」の4項目に分けて80字以内で書け。

第19章　drift、diffusion、再結合

1　キャリアは電場と濃度のむらで動く

第18章では、ドナーとアクセプタを含む半導体で、伝導帯電子の密度n、価電子帯正孔の密度p、Fermi準位E_Fを電荷中性から求めた。ここでは、その数が空間と時間で変化するとき、電流と再結合をどう書くかを開く。

電場Eだけがあると、電子と正孔は反対向きへ動く。しかし電子の電荷は-qなので、慣用電流は電子の運動方向と反対になる。濃度にむらがあると、粒子は高濃度から低濃度へ拡散する。電子の拡散電流と正孔の拡散電流の符号は、この二つの反転を別々に記録しなければ決められない。

電荷の大きさをq=e>0とする。移動度は電子をmu_e、正孔をmu_hと書き、単位はm^2/(V s)、拡散係数D_n,D_pの単位はm^2/s、電流密度J_n,J_pの単位はA/m^2である。mu_n,mu_pは第18章から受け取る準Fermi準位専用の記号として予約する。一定の電場E=100 V/m、n=1.0×10^21 m^-3、p=1.0×10^20 m^-3、mu_e=0.10 m^2/(V s)、mu_h=0.05 m^2/(V s)なら、drift電流の解析予測は

J_n,drift = q mu_e n E ≈ 1.60×10^3 A/m^2
J_p,drift = q mu_h p E ≈ 8.01×10^1 A/m^2             (19.1)

である。これは指定した移動度と密度の計算値であり、実材料の測定値ではない。book run 19 1は固定runnerの入力由来契約モデルまで実行済みで、外部domain tool・実測は未実行（measurement.status=not_run）である。

この章の中心問題は次である。

電場によるdrift、濃度勾配によるdiffusion、生成・再結合を、符号と保存則を壊さずにどう足し合わせるか。

第18章からはn,p,E_F,T、電子と正孔の電荷符号、平衡・非平衡の区別を受け取る。第20章では、n型とp型を接合して空乏層、内蔵電位、接触を扱う。

2　drift電流と移動度

2.1　散乱があるキャリアの平均運動

有効質量m^*を持つキャリアへ電場を掛け、散乱で速度が緩和するとする。緩和時間tauを使う最小模型は、

m^* dv/dt = q_c E - m^* v/tau                  (19.2)

である。q_cはキャリアの電荷で、電子なら-q、正孔なら+q。定常状態dv/dt=0ではv=q_c tau E/m^*となる。移動度を正値

mu = |q_c| tau/m^*                              (19.3)

と定義すれば、電子の平均速度はv_n=-mu_e E、正孔の平均速度はv_p=+mu_h Eである。移動度は「電場1 V/mあたりの速度の大きさ」で、電荷の符号を含めない。

2.2　電流の符号を二度確認する

電流密度は電荷×粒子流束である。電子は-qを持ち、電場と逆向きへ動くので、電子のdrift電流は電場と同じ向きになる。正孔は+qを持ち、電場と同じ向きへ動くので、正孔のdrift電流も電場と同じ向きになる。

J_n,drift = q mu_e n E
J_p,drift = q mu_h p E                         (19.4)
J_drift  = q(mu_e n + mu_h p)E

EとJはベクトルである。一次元でE>0なら、両式の電流は+x向き。粒子速度v_nをそのまま電子電流と呼ぶと符号が反転するので、速度、粒子流束、慣用電流を別の変数へ保存する。

式(19.4)は局所・線形・低電場の模型である。強電場で速度が飽和する場合、磁場がある場合、移動度が位置・温度・濃度で変わる場合は、mu_e,mu_hを固定値のまま使わない。

3　diffusion電流とEinstein関係

3.1　Fick則から電流へ

粒子の拡散流束は濃度勾配に逆らう。電子と正孔の粒子流束を

Gamma_n,diff = -D_n grad(n)
Gamma_p,diff = -D_p grad(p)                         (19.5)

とする。電子は-qを持つため、電子の拡散電流は+q D_n grad(n)、正孔は+qを持つため-q D_p grad(p)になる。

J_n = q mu_e n E + q D_n grad(n)
J_p = q mu_h p E - q D_p grad(p)                  (19.6)
J_total = J_n + J_p

例えばx方向に電子濃度が増える、つまりdn/dx>0なら、電子は-xへ拡散するが、電子拡散電流は+xへ向く。正孔濃度が増える方向では、正孔拡散電流はその反対方向へ向く。式を暗記する前に、粒子流束へ電荷を掛けて検算する。

3.2　Einstein関係

熱平衡近くの非縮退キャリアでは、移動度と拡散係数に

D_n/mu_e = D_p/mu_h = k_B T/q                   (19.7)

というEinstein関係がある。k_B T/qの単位はV、D/muも(m^2/s)/(m^2/(V s))=V。300 Kならk_B T/q≈0.02585 Vである。これはキャリアの種類にかかわらず同じ温度での熱エネルギーと電荷の比を表すが、縮退、高電場、強い非平衡では修正が必要になる。

3.3　driftとdiffusionが相殺する条件

電子について一方向の電流を0とすると、

E = -(D_n/mu_e) (grad(n)/n)
  = -(k_B T/q) grad(ln n)                         (19.8)

となる。正孔では、

E = +(k_B T/q) grad(ln p)                         (19.9)

となる。平衡では電場と濃度勾配がこのように釣り合うことがある。接合で生じる空乏層と内蔵電位は、この局所的な釣り合いを空間全体で解く次の問題であり、まだここで導出しない。

4　連続の式、生成、再結合

4.1　数を保存する収支

生成率と再結合率を、単位体積・単位時間あたりの正の量G_gross、R_grossで表す。単位はm^-3 s^-1。電子と正孔が対で生成・再結合する単純な場合、

∂n/∂t = (1/q) div(J_n) + G_gross - R_gross
∂p/∂t = -(1/q) div(J_p) + G_gross - R_gross             (19.10)

である。電子式のdiv(J_n)の符号が正なのは、電子の電荷が負だからである。正孔式は正電荷なので符号が反対になる。空間一様で電流が発散しなければ、∂n/∂t=∂p/∂t=G_gross-R_grossとなる。

自由キャリアの電荷密度をrho_free=q(p-n)と書く。ドナー・アクセプタの固定電荷も含めてPoisson方程式へ渡す全電荷密度は、第18章のイオン化濃度を受けて

rho_total = q(p + N_D^+ - n - N_A^-)

となる。固定したN_D^+とN_A^-は時間微分の収支では定数として相殺されるため、式(19.10)の生成・再結合の検算はrho_freeで行える。しかし第20章の接合・空乏層の空間電荷源にはrho_totalを渡し、rho_freeと混同しない。

4.2　寿命の一次模型

光や注入で平衡値からの過剰電子密度をdelta_n=n-n_0、過剰正孔密度をdelta_p=p-p_0とする。低レベル注入で、過剰キャリアが寿命tau_nで失われると近似すれば、

R_net ≈ delta_n/tau_n,
d(delta_n)/dt = -delta_n/tau_n,
delta_n(t)=delta_n(0) exp(-t/tau_n)             (19.11)

となる。tau_nの単位はs、R_netはm^-3 s^-1。delta_n(0)=1.0×10^22 m^-3、tau_n=1.0 nsなら初期再結合率は1.0×10^31 m^-3 s^-1、2 ns後の過剰密度は約1.35×10^21 m^-3という解析予測である。

この寿命は材料固有の普遍定数ではない。欠陥、表面、温度、注入レベル、試料形状によって変わる。runnerや測定で得た寿命と、式(19.11)へ与えた仮定値を分けて保存する。

4.3　Shockley–Read–Hallの最小式

バンドギャップ内の欠陥準位E_tを介した再結合を、SRH模型で

U_SRH = (n p - n_i^2)
        / [tau_p (n+n_1) + tau_n (p+p_1)]       (19.12)
n_1 = N_c exp[-(E_c-E_t)/(k_B T)]
p_1 = N_v exp[-(E_t-E_v)/(k_B T)]

と表す。U_SRH>0を正味再結合、U_SRH<0を正味生成と定義する。n,p,n_i,n_1,p_1は密度、tau_n,tau_pはsなので、分子の密度二乗を分母の密度×時間で割った単位はm^-3 s^-1になる。平衡でnp=n_i²ならU_SRH=0。非平衡でも、局所準平衡・単一trapという仮定の範囲ならこの式へ実際のn,pを入れてよい。ただしnp=n_i²を強制せず、準Fermi準位の分離を反映した正味率として扱う。仮定を外れる過渡捕獲・多準位・量子輸送は別モデルにする。

連続の式との接続を一つに決める。G_grossとR_grossを別々の正の総生成・総再結合率として使うcaseでは、式(19.10)の源をS=G_gross-R_grossとする。SRHを使うcaseでは、符号付きU_SRHを再結合率として採用し、源をS=-U_SRH（つまり式のG_gross-R_grossを-U_SRHへ置換）とする。両caseを同じ時刻へ足し合わせたり、R_grossへU_SRHをもう一度加えたりしない。artifactにはrecombination_mode="gross_pair_rates"または"srh_net_rate"と、採用した源Sを保存する。

SRHは一つの再結合模型であり、放射再結合、Auger再結合、表面再結合を自動的に含まない。複数の経路を加えるなら、各係数、単位、適用範囲を別に記録する。

5　一次元数値計算を設計する

5.1　定数係数の有限差分

一次元でE,mu_e,mu_h,Dを一定とし、式(19.6),(19.10)を格子x_j=j Delta_xへ置く。濃度勾配を中心差分で近似し、電流を面の値で計算してから発散を取る。濃度そのものを中心差分で直接更新するより、各セルの流入・流出を数える有限体積の方が、収支を追いやすい。

陽解法で拡散項を更新する場合、目安として

Delta_t <= Delta_x^2/(2 max(D_n,D_p))          (19.13)

を満たす必要がある。drift項にもDelta_t |mu E|/Delta_xのCFL条件がある。厳しい条件を避けるため陰解法を使う場合でも、時間刻みを粗くすれば過渡応答を解像できない。時間刻み、格子幅、境界条件、収束判定をartifactへ保存する。

5.2　境界条件

オーミック接触では、接触が指定する平衡濃度や準Fermi準位を境界値として与える。絶縁境界では、法線方向のJ_nとJ_pを0にする。表面再結合を扱うなら、表面速度Sと表面での過剰濃度を使い、バルク寿命と別の境界モデルとして記録する。

同じ「端の濃度を固定」と書いても、電流を固定する境界とは別である。境界条件を変えた結果を同じrunner出力へ上書きせず、boundary_kindとcase IDを付ける。

5.3　検算の順番

最初はE=0,G_gross=R_gross=0で一様濃度を入れ、J_n=J_p=0を確認する。次に一様電場・一様濃度でdrift式だけを確認する。その後、電場0で濃度勾配を与え、式(19.6)のdiffusion符号を確認する。最後に寿命模型へ過剰キャリアを入れ、指数減衰の時間定数と比較する。

各caseで、

current_unit_check
charge_continuity_residual
nonnegative_density_check
boundary_flux_residual
time_step_stability_check
analytic_relative_error

を保存する。数値結果が滑らかでも、電荷収支、負の濃度、境界流束、時間刻みを通過したとは限らない。

6　単位、符号、平衡・非平衡

qはC、n,pはm^-3、EはV/m、移動度mu_e,mu_hはm^2/(V s)、Dはm^2/s、JはA/m²、G_gross,R_gross,U_SRHはm^-3 s^-1、tauはsで統一する。例えばq mu_e n EはC·m²/(V s)·m^-3·V/m=A/m²となる。

電子の速度は-mu_e Eだが電子のdrift電流は+q mu_e n E。電子の拡散流束は-D_n grad(n)だが電子の拡散電流は+q D_n grad(n)。正孔はこの二つの符号がそれぞれ反対である。pを負の数として正孔の正電荷を表す方法は採用しない。

熱平衡なら一つのFermi準位E_Fでn,pを決め、平衡では正味再結合U=0。注入や光照射中の非平衡ならmu_n,mu_pを使い、G_gross,R_grossまたはU_SRHのどちらか一つと連続の式を時間・空間で解く。平衡のnp=n_i²を非平衡の入力へ無条件に入れない。

8　次章へ渡す設計判断

第20章「p-n接合と金属接触」へは、次の入力と境界を固定して渡す。

  • 電子電流はJ_n=q mu_e n E+q D_n grad(n)、正孔電流はJ_p=q mu_h p E-q D_p grad(p)とし、電子・正孔の粒子速度と慣用電流を別に保存する。mu_n,mu_pは準Fermi準位として別欄へ保存する。
  • n,p、電場E、移動度mu_e,mu_h、拡散係数、温度、自由キャリア電荷密度rho_free=q(p-n)の単位を揃える。第20章のPoisson源には固定イオンを含むrho_total=q(p+N_D^+-n-N_A^-)を渡す。qは正の電荷の大きさとして、電子の符号は式の構造で表す。
  • 連続の式では電子と正孔の発散符号、総生成・再結合G_gross,R_grossまたは符号付きSRH率U_SRHのどちらか一つ、境界流束を個別に検査する。過剰キャリアの寿命は仮定値と測定値を分ける。
  • 熱平衡の一つのFermi準位と、非平衡の準Fermi準位を区別し、np=n_i^2の適用条件をrunner入力へ残す。
  • n型とp型を接合すると、濃度勾配によるdiffusionと電場によるdriftが空間的に釣り合う領域が現れる。第20章ではPoisson方程式、空乏近似、内蔵電位、接触の境界条件を追加する。
  • 数値解は格子幅、時間刻み、境界条件、電荷収支残差、解析参照を持つ。未実行runnerの出力を測定と呼ばない。

9　この章で使った模型の限界

drift–diffusion模型は、局所平衡に近いキャリアを移動度mu_e,mu_hと拡散係数D_n,D_pで記述する。平均自由行程がデバイス寸法に近い場合、強電場、磁場、縮退、量子輸送、バリスティック輸送では、局所的な移動度と拡散係数だけでは足りない。

再結合も、寿命一つまたはSRH一つで全材料を表せるわけではない。放射、Auger、表面、欠陥、発熱、光生成を追加する場合は、生成・再結合の単位と符号を再確認する。第20章の接合では、電位と電荷分布をPoisson方程式で結合し、bulkの電荷中性だけではない境界問題になる。

5　模型の境界と章間の橋

この章の模型は、適用範囲を明示して初めて安全に使える。次の限界を一つずつ、本文のどの主張に効くかと一緒に読む。

  • drift–diffusionは局所平衡に近い低電場・低密度の輸送模型で、強電場、速度飽和、磁場、縮退、量子輸送を含まない。
  • 移動度と拡散係数は材料、温度、濃度、散乱、結晶欠陥で変わるため、固定値は指定caseだけの入力である。
  • Einstein関係は熱平衡近くの非縮退条件に限られ、非平衡・高密度では修正が必要になる。
  • 寿命模型とSRHは再結合の候補であり、放射、Auger、表面、トラップ分布を自動的に含まない。
  • バルクの連続の式だけでは接触、表面、接合、空乏層の電位分布は決まらない。
  • 数値解の安定性は物理的正しさを保証しない。単位、符号、収支、境界、収束を別に検査する。
  • 非平衡では第18章の単一Fermi準位を流用せず、必要なら電子・正孔の準Fermi準位を入力する。
  • 本章の固定runnerは契約を再生済みだが、図・電流・再結合率・過渡曲線の外部tool実行は未実行で、具体値は解析または数値予測である。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

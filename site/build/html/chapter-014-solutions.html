第14章 演習解答

E1　波動関数と規格化

完全解答

1=∫_0^L |A sin(πx/L)|²dx=A² L/2
A=sqrt(2/L)

従ってL=1 nm=1.0×10^-9 mならA≈4.4721×10^4 m^-1/2である。ψの単位はm^-1/2、|ψ|²の単位はm^-1で、積分すると無次元の確率になる。左右対称な基底状態の確率密度なので、

<x>=∫_0^L ψ* x ψ dx=L/2=0.5 nm

である。これは一回の測定で必ず中心が出るという意味ではない。

再挑戦

ψ=A sin(2πx/L)でもA=sqrt(2/L)である。節の位置と確率密度は変わるが、規格化係数は同じ。規格化されていない波動関数の|ψ|²をそのまま確率と呼ばない。

E2　時間依存と時間独立

完全解答

時間依存方程式をiℏ∂ψ/∂t=Hψとし、ψ=φ(x)exp(-iEt/ℏ)を代入する。時間微分は

∂ψ/∂t=(-iE/ℏ)φ exp(-iEt/ℏ)

なので、左辺はE φ exp(-iEt/ℏ)になる。共通の指数因子を両辺から除くと、

Hφ=Eφ

を得る。EはHamiltonian固有値である。指数因子の絶対値は|exp(-iEt/ℏ)|=1なので、固有状態一つでは|ψ|²=|φ|²が時間不変になる。これは波動関数の位相も不変という意味ではない。

再挑戦

二つの固有状態を足すと、二つの指数因子の相対位相が残り、確率密度の干渉項が時間変化する。時間独立方程式を解いたから時間変化を全て失ったのではなく、固有状態ごとの位相を記録している。

E3　無限井戸の境界条件

完全解答

V=0の方程式はd²φ/dx²+k²φ=0で、一般解は

φ=A sin(kx)+B cos(kx)

である。φ(0)=0からB=0、φ(L)=0からsin(kL)=0となる。零関数でない解は、

kL=nπ,
k_n=nπ/L,
n=1,2,3,...

である。n=0ならsin(0x)=0で区間全体が0になり、規格化できない。従って量子数として数えない。

再挑戦

n=2なら内部節はx=L/2に一つある。nを実数へ変えると右端の境界を満たさないため、無限井戸の固有状態ではなくなる。

E4　1 nm井戸のエネルギー

完全解答

L=1.0×10^-9 mを使うと、

E_1=π²ℏ²/(2m_eL²)≈6.02×10^-20 J
E_2=4E_1≈2.41×10^-19 J
E_3=9E_1≈5.42×10^-19 J

である。1 eV=1.602176634×10^-19 Jで割れば、

E_1≈0.3760 eV
E_2≈1.504 eV
E_3≈3.384 eV
E_n/E_1=n²

となる。Jを内部正本、eVを表示単位とし、値はanalytic_predictionである。

再挑戦

L=2 nmなら各エネルギーは1/4なので、E_1≈0.094 eVになる。長さをnmの数値1のまま式へ入れると誤差が桁違いになるため、length_mへ変換する。

E5　固有状態と重ね合わせ

完全解答

係数は|c_1|²+|c_2|²=1/2+1/2=1なので規格化を保つ。固有状態一つでは、

|φ_n exp(-iE_nt/ℏ)|²=|φ_n|²

で、確率密度は変わらない。重ね合わせではψ_1ψ_2の干渉項に

exp[-i(E_2-E_1)t/ℏ]

が現れるため、確率密度は時間変化する。固有関数の直交性を使えば、エネルギー期待値は

<E>=|c_1|²E_1+|c_2|²E_2=(E_1+E_2)/2

である。1 nm井戸の値なら<E>≈(0.3760+1.504)/2=0.9400 eVだが、これは一回のエネルギー測定値が0.9400 eVになるという意味ではない。

再挑戦

c_1=1、c_2=0へ戻すと基底状態だけになり、期待値はE_1、確率密度は時間不変になる。係数の絶対値と相対位相を別に保存する。

E6　有限障壁の指数波

完全解答

障壁内のV=V_0を時間独立方程式へ入れると、E<V_0では

-ℏ²/(2m)d²ψ/dx²+V_0ψ=Eψ
d²ψ/dx²=[2m(V_0-E)/ℏ²]ψ=κ²ψ
κ=sqrt(2m(V_0-E))/ℏ

となる。解はexp(κx)とexp(-κx)の組み合わせである。κの単位は1/m、κaは無次元。厚い障壁の漸近式はT≈[16E(V_0-E)/V_0²]exp(-2κa)であり、幅を2倍にすると指数は-2κaから-4κaへなる。エネルギー比が同じなら前因子は変わらないので、指数スケールはおよそ元の二乗になるが、裸の指数式と正確式の相対差が消えるとは限らない。

再挑戦

障壁を高くしてV_0−Eを4倍にするとκは2倍になる。幅を変えなくても指数減衰は強くなる。E>V_0では障壁内も振動解になり、E<V0の式をそのまま使わない。

E7　透過確率の解析比較

完全解答

エネルギー差はV_0−E=0.30 eVで、Jへ換算する。電子質量を使うと、

κ=sqrt(2m_e(V_0-E))/ℏ≈2.81×10^9 m^-1
κa≈2.81
T_approx=exp(-2κa)≈3.7×10^-3

正確式では、

V_0²/[4E(V_0-E)]=0.50²/[4(0.20)(0.30)]≈1.0417
sinh²(κa)≈67.9
T_exact≈[1+1.0417×67.9]^-1≈1.4×10^-2

となる。厚い障壁の前因子は16E(V_0-E)/V_0²=3.84なので、前因子付き漸近式は3.84×3.7×10^-3≈1.4×10^-2となり、正確式にほぼ一致する。裸のexp(-2κa)との差は、主に前因子を捨てたことによる。両方ともanalytic_predictionで、実測透過率ではない。

再挑戦

障壁幅を2 nmへ変えると、指数スケールはexp(-4κa)へ減り、前因子付き漸近式は同じ前因子を掛ける。正確式でもsinh(κa)が増えて透過率は大きく下がるが、裸の指数式との差はエネルギー比による前因子として残る。

E8　有限差分Hamiltonian

完全解答

中心差分は、

d²ψ_j/dx²≈(ψ_{j+1}-2ψ_j+ψ_{j-1})/(Δx)²

である。a_h=ℏ²/(2m(Δx)²)と置くと、内部3点のHamiltonianは

H=[ 2a_h  -a_h    0  ]
  [ -a_h  2a_h  -a_h ]
  [  0    -a_h  2a_h]

となる。端点を自由未知数へ入れずψ=0として固定すれば、境界値は隣接項へ既に組み込まれる。a_hはJ、行列要素と固有値もJである。固有ベクトルはΣ|ψ_j|²Δx≈1へ規格化する。

再挑戦

端点を未知数へ含める場合は、端点の行へψ_0=0、ψ_{N+1}=0という制約を追加する。内部3点だけの行列とサイズが異なるので、境界を二重に数えない。

E9　格子・時間刻み・規格化の検査

完全解答

固有値が収束しない原因として、(1)nmをmへ変換していない、(2)端点を誤って自由にした、(3)Hamiltonianの符号またはΔx²が誤っている、(4)固有値solverの残差が大きい、(5)ポテンシャルの格子化が違う、を疑う。固有値側では、

relative_error=|E_fd-E_analytic|/E_analytic
residual=||Hφ-Eφ||/||Eφ||

と境界残差、規格化残差を検査する。時間発展ではnorm=Σ|ψ_j|²Δxを各ステップで記録し、1からの差、Hermitian性、dt・dx変更時の位相誤差を調べる。ノルムが1.07なら、行列の符号、時間更新式、規格化、境界、複素数の扱いを点検し、正常値へ丸めない。

再挑戦

norm=0.999999が一定で、固有状態の確率密度が正しいなら、丸め誤差内の候補である。一方、normが単調増加するなら、Hamiltonianが非Hermitian、更新式の符号、境界からの確率流、またはdtが疑わしい。

E10　Crank–Nicolsonを実装しJSONLへ記録する

完全解答

A=I+i dt H/(2ℏ)、B=I-i dt H/(2ℏ)を作り、各ステップでA ψ_next=B ψを線形solverへ渡す。直接逆行列を作らず、境界を固定した内部自由度だけを解く。固有状態を初期値にして、各時刻のnorm=Σ|ψ_j|²Δxと解析位相exp(-iE_n t/ℏ)との差を記録し、複数dtで位相誤差が収束するかを調べる。

その上で、模型・方法・状態・単位を一行へ保存する。

{"case_id":"well-n1-cn-dt1e-18","model":"quantum_infinite_well","method":"crank_nicolson","boundary":"psi(0)=psi(L)=0","energy_j":6.03e-20,"energy_ev":0.3765,"transmission":null,"dt_s":1e-18,"norm":0.999999999999,"phase_error":2e-6,"source_kind":"numeric_prediction","status":"analytic_prediction_recorded_measurement_not_run","error_vs_analytic":0.001,"units":{"length":"m","mass":"kg","energy":"J","display_energy":"eV"}}

解析準位はmethod=analytic、障壁透過はmodel=finite_barrier、将来の分光値はsource_kind=measurementとする。解析・数値・runner・測定を同じ値へ上書きせず、case_idとsource_kindを保持する。測定には試料、温度、装置分解能、境界条件、校正情報が必要なので、解析準位を測定値へ改名してはいけない。

再挑戦

時間発展のレコードにはdt_s、norm、phase_error、initial_stateを追加する。透過率のレコードにはincident_current、reflected_current、transmitted_current、確率流残差を追加し、固有状態のnormだけで代用しない。

E12　第15章へ量子状態を渡す

完全解答

単一粒子の計算から渡す箱は、量子数n、固有エネルギーE_n、波動関数φ_n、規格化種別、境界、ポテンシャルを含む一粒子状態の集合である。単一粒子の∫|ψ|²dx=1は一個の粒子の位置確率であり、状態を何個の粒子が占めるかという占有数とは別である。スピン自由度は本章で定義していないため、第15章で新しい状態ラベルとして導入するフィールドにする。

第15章へは、temperature_K、化学ポテンシャル、粒子数または密度、占有数、統計模型（Fermi–Diracまたは古典近似）、試料境界を追加する。スピンは第15章で定義した後に状態ラベルへ加える。E_nは本章の解析・数値・runner状態を保ったまま渡し、占有確率を固有状態の確率密度へ掛けて「新しい波動関数」と呼ばない。source_kind、status、J/eV、ポテンシャル、境界、格子、残差、測定分解能も保存する。

再挑戦

第15章でスピンを定義した後、同じ空間準位に複数の内部状態ラベルがある場合は、状態識別子を(n, internal_state)のように拡張する。空間波動関数が同じでも、内部自由度と占有数の扱いを追加した別の多粒子契約になる。

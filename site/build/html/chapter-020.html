第20章　p-n接合と金属接触

1　この章の問い

電源をつないでいないp-n接合に、なぜ内部電場と電位障壁が生じるのか。本章では、第19章のdrift・diffusion・再結合と、イオン化不純物を含む全電荷密度を、一次元の接合模型へつなぐ。

最初に、p型とn型を別々に用意した直後の拡散を考える。n側の電子は濃度の低いp側へ、p側の正孔は濃度の低いn側へ移動する。接合付近から移動した電子・正孔の跡には、動けないイオン化ドナーとイオン化アクセプタが残る。この固定電荷が電場を作り、その電場によるdriftが拡散を打ち消すまで、電位が変化する。

ここでいう「電位障壁」は、個々の電子が越えられない壁という意味ではない。熱運動、濃度、電場、接触条件をまとめた平衡解の差であり、模型の仮定を外せば値も電流式も変わる。章末までに、次を自分で追跡できることを目標にする。

  • rho_total=q(p+N_D^+-n-N_A^-)からPoisson方程式を解く
  • 空乏近似で幅、内蔵電位、最大電場、接合容量を計算する
  • drift電流とdiffusion電流が平衡で相殺する理由を符号付きで説明する
  • 順方向・逆方向バイアスで空乏層がどう変わるかを、適用範囲つきで書く
  • 理想的な金属–半導体接触の障壁と、オーミック接触の条件を区別する
  • 解析予測、数値予測、SPICEまたはrunner出力、測定値を混同しない

2　接合を作ると何が残るか

2.1　接合前の電荷中性

バルクのp型では正孔が多数キャリアで、アクセプタは負にイオン化される。n型では電子が多数キャリアで、ドナーは正にイオン化される。十分離れた各領域では、近似的に

p+N_D^+≈N_A^-（p型）、n+N_A^-≈N_D^+（n型）

であり、全電荷密度はほぼ0である。これは「キャリアがない」という意味ではなく、可動キャリアと固定イオンの電荷が局所的に釣り合うという意味である。第18章で解いたn,p,N_D^+,N_A^-を、単位をそろえたまま入力にする。

2.2　拡散と空乏領域

p型とn型を接触させると、最初は濃度勾配が大きい。電子と正孔は互いに逆向きへ拡散し、接合近くの自由キャリアが減る。自由キャリアが少なく固定イオンが優勢な領域を空乏領域（depletion region）と呼ぶ。

p側の空乏幅をW_p、n側をW_n、全幅をW=W_p+W_nとする。急峻接合（abrupt junction）と、空乏領域内でキャリアを無視する近似では、接合をx=0として

rho(x) = -q N_A　（-W_p<x<0）、

rho(x) = +q N_D　（0<x<W_n）、

rho(x) = 0　（それ以外）

となる。ここでN_A,N_Dは空乏領域で実際にイオン化している密度であり、総ドーピング濃度をそのまま代入できるのは完全イオン化の範囲だけである。

空間全体の電荷を残さない条件は

q N_A W_p = q N_D W_n　　　　　　　　　　　(20.1)

である。この電荷中性条件は、左右の幅が同じという意味ではない。濃度の低い側ほど広い空乏幅を持つ。

3　Poisson方程式から内蔵電位を得る

3.1　電場の積分

一次元のPoisson方程式を

dE/dx = rho(x)/epsilon、E=-dphi/dx　　　　　　　　　　　(20.2)

と書く。epsilonは半導体の誘電率、phiは電位である。空乏領域の外側で電場が0になる境界を選び、(20.2)を左右から積分すると、電場は三角形になる。最大値の大きさは

E_max = q N_A W_p/epsilon = q N_D W_n/epsilon　　　　　(20.3)

である。電場の向きは正の固定ドナーから負の固定アクセプタへ向かう。xの向きと電位の符号を先に固定し、図やコードでは同じ規約を使う。

3.2　幅と内蔵電位

電場をさらに積分すると、平衡時の内蔵電位（built-in potential）は

V_bi = (k_B T/q) ln(N_A N_D/n_i^2)　　　　　　　　　　　(20.4)

となる。これは非縮退、完全イオン化、熱平衡、同じ材料の急峻接合という条件での式である。電圧をVで入力するrunnerではV_biをVで扱い、エネルギーをeVで表示するときはq Vとの対応を明示する。

空乏近似で、外部バイアスをV（順方向を正）とすると、空乏幅は

W = sqrt[(2 epsilon/q)(V_bi - V)(1/N_A + 1/N_D)]　　　　　　 (20.5)

である。逆方向ではV<0なのでV_bi-Vが増え、順方向では減る。VがV_biに近づく式の外側では、空乏近似だけで電流を予測してはならない。幅の分割は(20.1)から

W_p = [N_D/(N_A+N_D)]W、W_n=[N_A/(N_A+N_D)]W　　　　　　(20.6)

である。

4　平衡、バイアス、電流

4.1　平衡で電流が消える

第19章の電子電流は

J_n=q mu_e n E + q D_n grad(n)、

正孔電流は

J_p=q mu_h p E - q D_p grad(p)

である。熱平衡の接合では、電場によるdriftと濃度勾配によるdiffusionが各キャリアで相殺され、総電流は0になる。これはキャリアが停止することではない。逆向きの流れが同じ大きさで存在し、正味が0になるという局所収支である。

4.2　理想ダイオード式

低注入、一定温度、再結合・生成の単純化、直列抵抗なしという追加仮定では、接合電流密度を

J = J_s [ exp(qV/(k_B T)) - 1 ]　　　　　　　　　　　　　(20.7)

と書ける。拡散長L_n=sqrt(D_n tau_n)、L_p=sqrt(D_p tau_p)を使う一つの理想化した飽和電流密度は

J_s=q n_i^2 [D_n/(L_n N_A)+D_p/(L_p N_D)]　　　　　　　　(20.8)

である。実際の接合では、空乏層再結合、接触抵抗、直列抵抗、高注入、温度依存、リーク、ブレークダウンが補正する。(20.7)は測定値の断定ではなく、どの仮定が崩れると曲線がずれるかを調べる基準模型である。

代表caseにD_n=3.0e-3 m^2/s、D_p=1.0e-3 m^2/s、tau_n=tau_p=1.0e-6 sを追加すると、J_s=5.944075660891468e-7 A/m^2となる。V=0.1 Vでは指数因子が46.854861294181916、J=2.785088406131926e-5 A/m^2である。指数式の大きな感度を確認するcaseであり、固定runnerの解析予測であり、実測値ではない。

4.3　接合容量

小信号で空乏幅だけが変わると考えると、単位面積あたりの接合容量は

C_j/A = epsilon/W　　　　　　　　　　　　　　　(20.9)

である。面積A_deviceを掛けるとC_j=(epsilon A_device)/W。この式は空乏近似の微分容量であり、寄生容量、界面準位、周波数依存を含まない。容量測定の周波数と振幅を記録し、静電容量をそのまま真の空乏幅と同一視しない。

5　金属–半導体接触

5.1　仕事関数と理想障壁

金属を半導体へ接触させると、フェルミ準位がそろうまで電荷が移動し、表面にバンドの曲がりと障壁が生じる。理想的なn型接触で、金属仕事関数をphi_m、半導体電子親和力をchiとするSchottky–Mott模型では、電子の障壁高さを

phi_Bn = phi_m - chi　　　　　　　　　　　　　　　(20.10)

と置く。理想模型での正孔側の障壁は

phi_Bp = E_g - phi_Bn　　　　　　　　　　　　　　(20.11)

である。phiをeVで扱う場合、温度指数へ入れるときはq phi（J）に変換する。

例としてphi_m=4.70 eV、chi=4.05 eV、E_g=1.12 eVなら、phi_Bn=0.6500000000000004 eV、phi_Bp=0.46999999999999975 eVという理想予測になる。表面酸化膜、界面準位（Fermi-level pinning）、反応層、画像力、ドーピングによるトンネルを無視しているため、実測値を意味しない。

5.2　オーミック接触との違い

オーミック接触（ohmic contact）は、動作範囲で電圧と電流がほぼ比例し、必要なキャリアを低抵抗で出し入れできる接触である。障壁高さが小さい場合だけでなく、重いドーピングで空乏幅が薄くなりトンネルが可能になる場合もある。したがって「金属を置けばオーミック」「仕事関数だけで接触を決める」とは言えない。

実験・runnerの接触出力には、金属・半導体の材料、表面処理、ドーピング、温度、電極面積、電圧掃引方向、接触抵抗、測定周波数を保存する。理想障壁、熱電子放出、熱電子–拡散、トンネルのどのモデルを選んだかをcontact_modelに記録し、異なるモデルの電流を足し合わせて二重計上しない。

6　数値実験の設計

6.1　一次元Poisson solver

格子上にN_A(x),N_D(x),n(x),p(x)を置き、まず

rho_total[j]=q*(p[j]+N_D_plus[j]-n[j]-N_A_minus[j])

を計算する。二階の境界値問題なので、独立な境界条件を2個（両端Dirichlet、Dirichlet–Neumann、または両端Neumann）明示し、差分でd^2 phi/dx^2=-rho_total/epsilonを解く。純Neumannなら総電荷の整合条件integral(rho_total dx)=epsilon(E_right-E_left)と、電位のgauge（例えば左端phi=0）を別に指定する。出力はphi,E,rho_total,W_p,W_n,V_bi,E_maxとし、電荷積分、境界条件、Poisson残差を同時に保存する。rho_free=q(p-n)だけをPoisson源にしてはいけない。

次に、Poissonで得たEを第19章のdrift–diffusionへ渡す。平衡caseではJ_n,J_pが0になるかを確認し、バイアスcaseでは連続の式と接触境界を解く。Poissonだけを解いてダイオード電流を得たことにはしない。

6.2　実験と失敗テスト

予定commandはbook run 20 1からbook run 20 8である。各実験は、入力、式ID、境界、期待値、許容差、失敗理由をJSON artifactへ保存する。固定runnerは契約を再生済みだが、SPICE・実測は未実行であり、artifactのmeasurement.status=not_runを維持する。

最低限、次を順に行う。

  1. 一様中性半導体でrho_total=0、E=0を確認する。
  2. 急峻p-n接合で電荷中性、Poisson、(20.4)–(20.6)を照合する。
  3. 格子幅と境界を変え、W、V_bi、Poisson残差の収束を調べる。
  4. 順方向・逆方向バイアスで幅と理想電流式の傾向を比較する。
  5. phi_m,chi,E_gを変え、理想障壁の単位と符号を検査する。
  6. rho_freeを誤ってPoissonに渡す、N_Aを負にする、電位境界を片側しか与えない、eVをJへ変換し忘れる、という負のcaseを失敗として記録する。

7　単位、境界、モデルの限界

qはC、epsilonはF/m、rho_totalはC/m³、phi,VはV、EはV/m、N_A,N_D,n,p,n_iはm⁻³、Wはm、C_j/AはF/m²、JはA/m²で統一する。eVはエネルギー表示であり、電圧Vと同じ数値だと自動的に扱わない。数値E_eVをエネルギーへ変換する場合はE_J=E_eV×q_Cと明示し、障壁を電圧V_Bとして扱うcaseでは指数にq_C V_Bを一度だけ入れる。phi_BをeVのまま指数へ渡さない。

本章は、同じ材料、急峻接合、非縮退、完全イオン化、熱平衡または低注入、一次元、局所誘電率という範囲の最小模型である。勾配接合、縮退統計、温度勾配、界面準位、表面再結合、量子トンネル、多次元電界、ブレークダウンは別の模型として明示する。モデルを追加したときも、どのartifactのどの入力を変えたかを追跡可能にする。

8　次章への橋渡し

p-n接合では、固定イオンの電荷が作る電場を半導体内部の境界値問題として解いた。次章では、半導体と金属の間に絶縁膜を置き、ゲート電圧という外部境界から表面電位、蓄積、空乏、反転を制御するMOSキャパシタへ進む。第20章から渡す中心入力は、epsilon、rho_total、電位境界、温度、ドーピング、キャリア統計、検証ラベルである。第21章ではこれに酸化膜厚、誘電率、ゲート仕事関数、表面電荷を追加する。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

途中で予測と結果が異なったら、最後の行から修正しない。入力、仮定、更新、表現、実行環境の順に一つずつ戻り、最初に不一致になった行へ診断名を付ける。診断名を付けられない差は、未解決として後段へ渡さない。

9　逆向きに説明する

今度は出力から出発し、どの入力と規則が必要だったかを逆向きに書く。画面の文字、論理値、レジスタ値、電圧、エネルギーのように異なる表現を、途中のartifactなしで直接つないではいけない。各矢印のそばに、保証する契約と保証しない詳細を一つずつ書く。

逆向きの説明で最初に見つかる欠落は、たいてい三種類のどれかである。入力の単位または幅がない、モデルの適用条件がない、または実行と測定の境界がない。この章の本文へ戻り、欠落を埋める行を一つ追加する。

10　再現記録の最小形

再現記録には、章ID、実験ID、case、入力hash、toolまたはmodelの版、終了コード、出力artifact、source_kind、status、measuredを残す。時刻やhost名は再現性の補助情報であり、計算値や状態遷移の一部として扱わない。

この最小形を満たせないときは、実験が難しいのではなく、契約がまだ閉じていない。閉じていない契約は、成功結果を保存するより先に、未指定欄と診断欄を保存する。

11　次章の読者への引き継ぎ文

最後に、次章の読者がこの章を読み返さなくても前提を再構成できる引き継ぎ文を書く。第一文はこの章が固定した定義、第二文は代表入力と途中状態、第三文は守る不変条件、第四文は最も近い破綻条件、第五文は未実行または未照合の境界である。

引き継ぎ文の主語を『この値は』だけにしない。『この模型では』『この版のtoolでは』『このmemory領域では』『このsource spanでは』のように、値の所有者を明記する。所有者が変わるところが、章間のbridgeであり、独立レビューが最初に読む境界である。

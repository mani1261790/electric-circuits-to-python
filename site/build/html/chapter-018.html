第18章　ドーピングとFermi準位

1　少量の不純物で、キャリア数を設計する

第17章では、不純物を入れない真性半導体で、伝導帯の電子密度nと価電子帯の正孔密度pを数えた。第16章のバンド図に、結晶へごく少量の別元素を加える操作を重ねる。これをドーピングと呼ぶ。ドーピングは「電子を回路へ注入する魔法」ではなく、バンドギャップ内に追加の準位と電荷の帳簿を作り、熱平衡の化学ポテンシャル、つまりFermi準位を変える模型である。

伝導帯端をE_c、価電子帯端をE_v、ギャップをE_g=E_c-E_vとする。伝導帯の電子密度と価電子帯の正孔密度は、非縮退近似の範囲で

n = N_c exp[-(E_c-E_F)/(k_B T)]
p = N_v exp[-(E_F-E_v)/(k_B T)]                 (18.1)

と書く。熱平衡ではFermi準位E_Fは化学ポテンシャルμと同じ量として扱う。N_c,N_vは第17章の有効状態密度で、密度の単位を持つ。E_Fを上へ動かすとnは増え、pは減る。

ドナー濃度N_Dとアクセプタ濃度N_Aを指定した教材caseを考える。300 K、N_D=1.0×10^16 cm^-3、アクセプタなし、完全イオン化、前章と同じN_c=2.8×10^19 cm^-3、n_i=6.5×10^9 cm^-3なら、

n ≈ N_D = 1.0×10^16 cm^-3
p ≈ n_i^2/N_D ≈ 4.3×10^3 cm^-3               (18.2)

という解析予測になる。E_c-E_F≈k_B T ln(N_c/N_D)≈0.205 eVで、Fermi準位は伝導帯へ近づく。これはモデルからの予測であり、特定試料のHall測定値ではない。book run 18 1は固定runnerの入力由来契約モデルまで実行済みで、外部domain tool・実測は未実行（measurement.status=not_run）である。

この章の中心問題は次である。

ドナーとアクセプタの電荷状態を数え、電荷中性条件からFermi準位と多数・少数キャリアをどう決めるか。

第17章からは、バンド端、状態密度、n_i、電子・正孔の符号、温度、単位を受け取る。第19章では、ここで得たnとpをdrift、diffusion、再結合の方程式へ渡す。

2　ドナーとアクセプタを準位として数える

2.1　ドナーは伝導帯の近くに電子を渡す

純粋な結晶の原子を別の原子で置き換えると、結晶の周期性と結合の条件が局所的に変わる。ドナーは、電子を一個余分に持ちやすく、伝導帯端E_cの少し下にドナー準位E_Dを作る、と最小模型で表す。

ドナー準位の電子が束縛されていればドナーは中性、そこから電子が伝導帯へ移ればドナーは正にイオン化される。従ってN_D^+は正にイオン化したドナーの個数密度であり、N_D全体とは異なる。ドナー準位の位置、縮退因子g_D、温度、Fermi準位を使う予定式は、

N_D^+ = N_D / [1 + g_D exp((E_F-E_D)/(k_B T))]       (18.3)

である。ここでg_Dは採用する状態数の規約を明示したモデル入力で、暗記した固定値を無条件に入れない。E_Fが低いと指数が小さくなり、多くのドナーがイオン化する。E_Fが高いとドナー準位は電子で埋まり、N_D^+は小さくなる。

2.2　アクセプタは価電子帯から電子を受け取る

アクセプタは、価電子帯の電子を受け取りやすく、価電子帯端E_vの少し上にアクセプタ準位E_Aを作ると表す。アクセプタが電子を受け取ると負にイオン化される。その個数密度をN_A^-と書き、

N_A^- = N_A / [1 + g_A exp((E_A-E_F)/(k_B T))]       (18.4)

とする。E_Fが高いと指数が小さくなり、アクセプタは負にイオン化しやすい。E_Fが低いとアクセプタは空に近く、N_A^-は小さい。

式(18.3),(18.4)の縮退因子は、ドナー・アクセプタの電子状態を何通りとして数えるかに依存する。文献によって記号や因子の置き場所が違うため、g_D,g_Aの定義をartifactへ保存する。同じ縮退を、準位の列挙と因子の両方で二重に掛けない。

2.3　Fermi準位は温度平衡の帳尻を合わせる

Fermi準位E_Fは、ドナーの電荷、アクセプタの電荷、伝導帯電子、価電子帯正孔を一つの温度で同時に数えるためのエネルギー尺度である。電圧端子の「電位」と同じ単位eVを使うことはできるが、E_Fは一個の電荷あたりの電位差そのものではない。E_Fを電源電圧として回路式へ代入しない。

バンド端からの距離を比較すると、ドナーは通常E_cに近く、アクセプタはE_vに近い。ドナーが多数ならE_FはE_c側へ、アクセプタが多数ならE_v側へ寄る。これは「電子を足すとFermi準位が上がる」という直観の具体化であり、DOSと温度を無視した定性的な決め打ちではない。

3　電荷中性条件からFermi準位を解く

3.1　バルクの電荷を足し合わせる

バルク試料のある領域が巨視的に中性である最小条件は、正電荷の正孔とイオン化ドナーの合計が、負電荷の電子とイオン化アクセプタの合計に等しいという式である。

p(E_F) + N_D^+(E_F) = n(E_F) + N_A^-(E_F)       (18.5)

左辺と右辺はすべて個数密度で、単位はm^-3またはcm^-3。電荷eを両辺へ掛けた電荷密度の式からも同じ関係が得られるが、まず正の個数を数える。N_D^+を負にしたり、正孔pへ電子の符号を付けたりしない。

真性の場合N_D=N_A=0で、式(18.5)はp=nになる。ドープした場合は一般にn≠pであるが、熱平衡・非縮退の範囲なら第17章の質量作用則

n p = n_i^2                               (18.6)

も同時に使える。np=n_i²は電荷中性そのものではなく、状態密度とFermi占有から出る別の関係である。

3.2　単調な一変数方程式としての二分法

F(E_F) = p(E_F) + N_D^+(E_F)
         - n(E_F) - N_A^-(E_F)              (18.7)

と置く。E_Fを上げると、式(18.1)のpと式(18.3)のN_D^+は減り、nと式(18.4)のN_A^-は増える。従ってFは通常単調に減る。F(E_low)>0、F(E_high)<0となる探索区間を作れば、二分法でゼロを挟みながらFermi準位を求められる。

擬似コードは次のようになる。

assert T > 0 and all densities >= 0
lo, hi = choose_energy_bracket(Ev, Ec, dopant_levels)
assert F(lo) >= 0 and F(hi) <= 0
repeat up to max_iter:
    mid = (lo + hi)/2
    if abs(F(mid)) < tolerance_density: return mid
    if F(mid) > 0: lo = mid
    else: hi = mid
return mid, status="not_converged"

端点で符号が挟めなければ、Fermi準位を無理に返さない。状態密度の範囲不足、単位不一致、濃度の入力ミス、非縮退近似の破綻を診断する。二分法の探索区間、許容密度残差、反復数、g_D,g_Aをcanonical artifactへ保存する。

3.3　完全イオン化の近似と解析解

室温で浅いドナーがほぼ全てイオン化し、アクセプタがないとする。N_D^+≈N_D、p≪nなら、式(18.5)から、

n ≈ N_D,
p ≈ n_i^2/N_D                         (18.8)

を得る。浅いアクセプタだけなら、

p ≈ N_A,
n ≈ n_i^2/N_A                         (18.9)

である。これはN_D,N_Aがn_iより十分大きく、かつnやpが対応する有効状態密度より十分小さいときの予測である。N_Dを増やせば永遠にn=N_Dになるわけではなく、Fermi準位が伝導帯へ近づくと縮退と不完全イオン化を調べる。

完全イオン化・ドナーのみなら、式(18.1)から

E_F ≈ E_c - k_B T ln(N_c/N_D)            (18.10)

となる。アクセプタのみなら、

E_F ≈ E_v + k_B T ln(N_v/N_A)            (18.11)

である。これらは二分法の初期値や検算に使う解析予測で、全温度・全濃度に適用する式ではない。

4　温度で変わる三つの領域

4.1　凍結領域

低温では、ドナー準位やアクセプタ準位を熱励起できない。ドナーがあってもN_D^+がN_Dより小さく、伝導帯の電子数nも少ない。この領域を凍結領域と呼ぶ。式(18.3),(18.4)を使ってイオン化率を数え、完全イオン化の近似を使わない。

4.2　外因領域

中間の温度で浅い不純物がほぼイオン化し、真性励起がまだ小さいと、ドナーならn≈N_D、アクセプタならp≈N_Aとなる。ドーピングによって決まる多数キャリアと、質量作用則で決まる少数キャリアを分ける。多数・少数という語は個数の比較であり、電荷の符号を表す語ではない。

4.3　真性領域

高温ではバンドギャップを越える熱励起が急増し、n_iがドーピング濃度を上回る。するとnとpが再び近づき、真性半導体の挙動が支配的になる。温度ごとに、(i)不純物のイオン化率、(ii)n_i、(iii)N_D,N_Aの大小を比較する。領域の境界を固定の温度で決めず、採用した材料パラメータと許容誤差から決める。

4.4　混合ドーピング

ドナーとアクセプタが両方あると、まず完全イオン化の近似でN_D-N_Aの差を調べる。しかしN_D≈N_Aでは差だけで多数キャリアを決められず、少数キャリア、イオン化率、真性励起を含む式(18.5)を解く。ドナー濃度とアクセプタ濃度を単純に引き算してFermi準位を決めるのは、近似の成立を確認した場合に限る。

4.5　領域名を数値の閾値へ結びつける

「低温だから凍結」のように温度名だけで判定すると、材料やドーパントを変えたときに境界が動かない。そこでrunnerでは、教材の既定閾値を入力として保存し、各温度で同じ規則を適用する。既定値は、有限イオン化を使う不純物のイオン化率が0.5未満ならfreezeout、すべてが0.9以上で、n_i/max(N_D,N_A)が0.1以下、かつ多数キャリアがイオン化ドーパント濃度に対して相対誤差0.1以内ならextrinsicとする。N_DとN_Aがともに0、またはn_i/max(N_D,N_A)が10以上でnとpが相対差0.1以内ならintrinsicとする。

これらを同時に満たさない中間帯はtransition、二つ以上の規則を同時に満たす場合はboundary_overlapとして、無理に三分類へ押し込めない。閾値は物理定数ではなく教材の判定規約なので、regime_thresholdsとしてartifactへ書き出す。こうして「どの温度を凍結と呼んだか」だけでなく、「どの比と許容誤差でそう呼んだか」を再現できる。

5.3　非平衡と準Fermi準位

光照射や注入中の半導体では、電子と正孔が一つのE_Fで平衡にない場合がある。そのとき電子用の準Fermi準位μ_nと正孔用のμ_pを分ける。n=pや平衡の質量作用則を、非平衡の証拠として無条件に使わない。

runnerのequilibrium_modelがthermal_equilibriumなら一つのE_Fを計算する。non_equilibriumなら、まずμ_n,μ_pの有無と単位を入力検査し、両方そろっていても本章ではunsupported_non_equilibrium_modelを返す。本章は不純物の占有を平衡Fermi分布でしか定義しておらず、非平衡のn(μ_n)、p(μ_p)や不純物の捕獲・放出速度を計算する模型をまだ導入していないためである。準Fermi準位が欠ける場合は先にmissing_quasi_fermi_levelsとして拒否し、平衡式の数値を隠れて流用しない。

出力schemaでは、平衡・非平衡を同じ欄へ押し込めない。平衡行はequilibrium_model="thermal_equilibrium"、EFを数値、mu_n=null、mu_p=nullとし、mass_action_residualを計算する。非平衡行は入力のmu_nとmu_pを保持するが、EF=null、n=null、p=null、mass_action_residual="not_applicable"、status="unsupported_non_equilibrium_model"として境界だけを記録する。nとpが与えられていても、準Fermi準位なしで平衡solverを再利用した行はmissing_quasi_fermi_levelsとして拒否する。第19章以降で非平衡の輸送・再結合模型を定義した後に初めて、別のrunner契約を追加する。

7　次章へ渡す設計判断

第19章へは、次の値と条件を固定した入力として渡す。

  • 電子密度nと正孔密度pは正の個数密度として保存し、電子の電荷-e、正孔の有効電荷+eを電荷密度・電流式で別に掛ける。
  • N_D^+とN_A^-は総ドーパント濃度ではなく、温度・Fermi準位・縮退因子で決まるイオン化濃度である。総濃度とイオン化濃度を同じフィールドへ入れない。
  • 平衡のFermi準位は電荷中性条件を二分法で解いて求め、解析の完全イオン化式は初期値と検算に使う。F(E_F)の残差、探索区間、単位を必ず残す。
  • 凍結・外因・真性の領域は、固定温度名ではなくN_D,N_A,n_iとイオン化率の比較から判定する。
  • 第19章のdrift、diffusion、再結合へはn,p,T、ドーピングの符号、平衡・非平衡状態を渡す。散乱時間、移動度、濃度勾配、再結合係数は追加入力である。
  • 解析、数値、runner、測定を上書きせず、source_kind、status、measuredで出所を分ける。未実行のcarrier値を測定と呼ばない。

8　この章で使った模型の限界

ドーピングは、実際には結晶構造、局所歪み、補償、欠陥、イオン化エネルギー、温度依存のバンド端を持つ。本章は、バンド端近くの有効質量DOS、指定したドナー・アクセプタ準位、熱平衡のFermi占有、バルク電荷中性という最小模型である。

この模型からキャリア数の傾向は読めるが、ドーパントの空間分布、接合の電場、移動度、抵抗、再結合寿命はまだ決まらない。第19章でnとpを空間的・時間的に変化させるとき、非平衡の準Fermi準位と境界条件を追加し、平衡式をそのまま使わない。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

9　逆向きに説明する

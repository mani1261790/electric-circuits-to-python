第11章 演習解答

E1　単位と時間尺度

完全解答

まずR=2.0×10^3 Ω、C=0.50×10^-6 F、L=20×10^-3 Hとする。

τ = R C = (2.0×10^3)(0.50×10^-6) s = 1.0×10^-3 s = 1.0 ms
ω_0 = 1/sqrt(L C)
    = 1/sqrt((20×10^-3)(0.50×10^-6))
    = 1.0×10^4 rad/s
α = R/(2L) = (2.0×10^3)/(2×20×10^-3) = 5.0×10^4 s^-1

Ω·F=s、H·F=s^2なので、RCは秒、1/sqrt(LC)は1/sである。ラジアンは無次元として扱う。従ってt/τ、ω_0t、αtはいずれも無次元であり、指数や三角関数の引数にできる。これはanalytic_predictionの値である。

再挑戦

R=500 Ω、C=2 μFならτ=1.0 msである。L=5 mH、C=2 μFならLC=1.0×10^-8 s^2なので、ω_0=1.0×10^4 rad/sとなる。異なる部品値でも積が同じならこの時間尺度は同じになる。

E2　受動符号規約とエネルギー

完全解答

コンデンサでは、

C = 0.50 μF = 0.50×10^-6 F
C dv_C/dt = (0.50×10^-6)(4.0×10^3) A = 2.0×10^-3 A

となり、与えられたi_C=2.0 mAと一致する。受動符号規約では、

p_C = v_C i_C = (3.0)(2.0×10^-3) W = 6.0 mW
dU_C/dt = p_C = 6.0 mW

である。dv_C/dt>0なので、コンデンサの蓄積エネルギーが増えている。

インダクタでは、

di_L/dt = v_L/L = 2.0/(10×10^-3) A/s = 2.0×10^2 A/s
p_L = v_L i_L = (2.0)(0.50) W = 1.0 W
dU_L/dt = p_L = 1.0 W

となる。U_C=1/2Cv_C^2、U_L=1/2Li_L^2を微分すれば、いずれもviに戻る。符号が負なら、その瞬間は蓄積エネルギーを回路へ返している。

再挑戦

v_C=3 V、i_C=−2 mAならp_C=−6 mWであり、コンデンサは6 mWを供給している。dv_C/dtも−4.0×10^3 V/sになる。電力の大きさだけを表示すると、充電と放電を区別できない。

E3　RC充電の導出と解析値

完全解答

抵抗電流を電源からコンデンサへ正とする。KVLは、

5 V - R i - v_C = 0

であり、i=C dv_C/dtを代入すると、

R C dv_C/dt + v_C = 5 V
dv_C/dt = (5 V-v_C)/(R C)

となる。τ=RC=1.0 ms、V_i=0、V_f=5なので、

v_C(t) = 5[1-exp(-t/1.0 ms)] V
i(t) = 5 mA exp(-t/1.0 ms)

である。従って、

t=τ:  v_C=5(1-e^-1)=3.1606 V,  i=1.8394 mA
t=5τ: v_C=5(1-e^-5)=4.9663 V, i=0.03369 mA

となる。これらはanalytic_predictionであり、measurementではない。

再挑戦

V_f=3 V、v_C(0)=1 V、R=2 kΩ、C=0.5 μFならτ=1 msで、

v_C(t)=3+(1-3)exp(-t/1 ms) V

である。t=τではv_C=2.2642 Vとなる。最終値だけでなく初期値も式へ残す。

E4　RC放電と部品変更

完全解答

R=2.0 kΩ、C=1.0 μFなので、

τ=RC=(2000)(1.0×10^-6)=2.0 ms
v_C(t)=5 exp(-t/2.0 ms) V

である。電流の正方向を「コンデンサ上端から抵抗へ」と指定したため、

i(t)=v_C(t)/R=2.5 mA exp(-t/2.0 ms)

となる。t=τではv_C=5e^-1=1.8394 V、i=0.9197 mAである。

Rを半分の1.0 kΩにするとτ=1.0 msになる。しかし「新しい時定数の一つ後」では、exp(-1)が同じなのでv_C=1.8394 Vである。物理時間を以前の2.0 msに固定するなら、新しい回路では2τなのでv_C=0.6767 Vとなる。この二つを区別する。

再挑戦

R=2 kΩ、C=2 μFならτ=4 msである。t=4 msの電圧は初期値のe^-1倍、電流は初期電流のe^-1倍である。Rを増やしたから電圧の無次元減衰率が変わるのではなく、時間尺度が変わる。

E5　陽Euler法と安定性

完全解答

τ=1 ms、V_f=5 Vであり、Euler更新は

v[n+1]=v[n]+Δt(5-v[n])/τ

である。Δt=0.1 msならh=Δt/τ=0.1なので、v[0]=0から

v[1]=0+0.1(5-0)=0.5 V

となる。

Δt=2.1 msならh=2.1で、誤差e[n]=v[n]-V_fの更新因子は1-h=-1.1である。絶対値が1を超えるため、誤差の大きさが毎ステップ1.1倍になり、交互に符号を変えながら発散する。0<h<1なら単調収束、1<h<2なら数値的には安定でも交互振動、h≥2なら不安定となる。実装の合否は、物理的な波形の形と線形安定性を別欄へ保存する。

再挑戦

Δt=1.5 msならh=1.5、誤差因子は−0.5である。数値列は0, 7.5, 3.75, 5.625, ... Vとなり、最終的には5 Vへ近づくが、実際の理想RC充電の単調性を再現していない。したがって「発散しない」だけを合格条件にしてはいけない。

E6　解析解と数値積分の比較計画

完全解答

τ=1 msなので、

Δt=0.5 ms: h=0.5
Δt=0.1 ms: h=0.1
Δt=0.01 ms: h=0.01

t=τへ整数ステップで到達する場合、Euler値は5(1-(1-h)^n)である。

h=0.5, n=2:   v=5(1-0.5^2)=3.7500 V, error=+0.5894 V
h=0.1, n=10:  v=5(1-0.9^10)=3.2566 V, error=+0.0960 V
h=0.01,n=100: v=5(1-0.99^100)=3.1698 V, error=+0.0092 V

解析値は5(1-e^-1)=3.1606 Vである。最小のJSONLレコード例は、

{"experiment_id":11,"case_id":"rc-charge-dt-0.1ms","source_kind":"numeric_prediction","status":"analytic_prediction_recorded_measurement_not_run","dt_s":0.0001,"analytic_v":3.1606,"numeric_v":3.2566,"error":0.0960,"units":{"dt":"s","voltage":"V"}}

のようになる。実装では丸め前の値、式ID、initial_conditions、入力単位も保存する。

解析と数値の差がΔtを小さくすると体系的に減るなら、まず離散化誤差を疑う。刻みを変えても1000倍ずれるなら、msとs、μFとF、初期値、入力最終値、時刻の単位を確認する。単位や初期条件を変えた記録は同じcaseへ上書きせず、別case_idにする。

再挑戦

Δt=0.2 ms（h=0.2）を5ステップ進めると、v=5(1-0.8^5)=3.3616 Vとなる。解析値との差は0.2010 Vで、Δt=0.1 msより大きい。これをグラフにするなら横軸は秒、凡例にはsource_kindを残す。

E7　直列RLCの状態方程式

完全解答

指定された向きではKVLは、

V_in - R i - L di/dt - v_C = 0

である。i=C dv_C/dtなので、状態方程式は

dv_C/dt = i/C
di/dt   = (V_in - R i - v_C)/L

となる。i/Cの単位はA/F=V/s、分子V-Ri-v_CはV、VをHで割るとA/sである。従って状態の順を[v_C,i]とすれば、右辺も同じ順で並べる。

一定入力の区間でKVLを微分し、i=C dv_C/dtを代入すると、

L C d²v_C/dt² + R C dv_C/dt + v_C = V_in

となる。LCはs^2、RCはsなので、各項の単位はVで一致する。

再挑戦

状態順を[i,v_C]へ変更するなら、更新式も

di/dt=(V_in-Ri-v_C)/L
dv_C/dt=i/C

の順に並べる。配列だけを入れ替えて式を変えなければ、単位が合っていても別の回路を積分することになる。

E8　減衰分類と最初のピーク

完全解答

R=10 Ω、L=0.01 H、C=1e-6 Fから、

α=R/(2L)=10/(0.02)=500 s^-1
ω_0=1/sqrt(LC)=1/sqrt(1e-8)=1.0000e4 rad/s
ω_d=sqrt(ω_0^2-α^2)
    =sqrt(1.0000e8-2.5000e5)
    ≈9.9875e3 rad/s

である。α<ω_0なので不足減衰である。最初のピークは、

t_p≈π/ω_d≈3.145×10^-4 s=0.3145 ms

である。段差応答のピークは、

M_p=exp(-πα/ω_d)≈0.8544
v_C(t_p)=5(1+M_p)≈9.27 V

という解析予測になる。電源立上り、コイル抵抗、コンデンサESRがない理想模型の値であり、実測値とは書かない。

再挑戦

R=200 Ωへ変えるとα=10000 s^-1で、α=ω_0に近い臨界減衰になる。Rをさらに増やせばα>ω_0となり、ω_dを実数の振動周波数として使う式は適用できず、二つの実指数の解へ切り替える。

E9　初期条件の連続性と理想源

完全解答

(a)有限Rを通るので、有限時間に流れる電流ではCの電荷が有限量しか変わらない。従ってv_C(0+)=v_C(0−)=2 Vであり、5 Vへ指数的に近づくRCの初期値問題として解ける。(b)有限電圧ではdi/dt=v_L/Lが有限なので、i_L(0+)=i_L(0−)=0.1 Aである。初期電流を入れたRLCまたはRLの状態方程式を使う。

(c)理想Cへ理想電圧源を抵抗なしで直結すると、v_Cを瞬時に0 Vから5 Vへ変える必要がある。式i=C dv/dtはインパルス電流を要求し、有限値の単純ODEへそのまま入れられない。電源内部抵抗、スイッチのオン抵抗、配線抵抗、有限立上りの電源のいずれかを追加し、どの模型を採用したかを記録する。

再挑戦

理想電流源を理想インダクタへ直結して電流を瞬時に変えようとする場合も、v=L di/dtからインパルス電圧が必要になる。有限の直列抵抗や電源コンプライアンスを入れない限り、通常の有限値初期問題とは別の制約になる。

E10　SPICE比較の設計

完全解答

RCのnetlist断片は、例えば次のように書ける。

V1 in 0 PULSE(0 5 0 1e-9 1e-9 0.1 0.2)
R1 in c 1000
C1 c 0 1e-6 IC=0
.ic V(c)=0
.tran 1e-5 5e-3 0 1e-5
.end

RLCは同じ電源へ、R1 in n1 10、L1 n1 c 0.01、C1 c 0 1e-6 IC=0を接続する。電流の向きとコンデンサの正端子が本文の定義と一致するかを確認する。.tranの出力間隔だけでなく最大刻みを十分小さくし、RLCの振動周期も表せるようにする。

比較artifactには、

values_si: R_ohm, L_henry, C_farads
input: initial, final, delay, rise_time, polarity
initial_conditions: v_C_0minus, v_C_0plus, i_L_0minus, i_L_0plus
solver: method, t_start_s, t_stop_s, output_step_s, max_step_s
source_kind: analytic_prediction / numeric_prediction / spice_prediction / measurement
status: analytic_prediction_recorded_measurement_not_run または実際の状態

を保存する。SPICEの出力はsolverによる計算予測であり、実部品、計器、配線を経たmeasurementではない。従って解析解との差を「実測差」と呼ばず、netlist・solver設定・模型の差として記録する。

再挑戦

解析側にも1 nsの有限立上りを入れた入力を数値積分し、理想段差の解析解と、有限立上りのSPICEの二つを別caseにする。入力をそろえずに波形の最大誤差だけを比較してはいけない。

E11　故障診断と負のテスト

完全解答

ケース期待状態止める段階追加ログ
(a) 1 μFを数値1で入力invalid_unit_or_scale入力検査入力表示単位、SI変換、想定範囲
(b) L=−10 mHinvalid_input入力検査素子値、非正値の理由、case_id
(c) 状態順序と式の順序が不一致implementation_error状態方程式・単位検査状態schema、各微分の単位、初期値
(d) Euler Δt/τ=2.1unstable_numeric_prediction数値安定性検査h、誤差因子、刻み、解析との差
(e) SPICE初期条件不整合spice_not_convergedSPICE solver状態netlist、.ic、入力、solverメッセージ

(a)は数学的に計算が進む可能性があっても、1 Fであり1 μFではないため入力契約違反である。(b)は本章の受動線形Lの範囲外で、負の値を黙って通さない。(c)は物理模型でなく実装の状態schema故障である。(d)は解析解へ近づく刻みではなく、実行を続けても合格にしない。(e)は実測値でも解析解でもなく、SPICE計算が成立しなかった状態である。

全レコードへsource_kind、status、unitsを持たせ、未収束を波形の0埋めへ変換しない。単位混同は線形ソルバだけでは見つからないため、単位タグ、SI変換、値域警告、解析基準値との比較を入力境界へ置く。

再挑戦

追加の負のテストとして、(f)v_C(0+)だけを入力してv_C(0−)を欠落、(g)R=NaN、(h)SPICEの.tran最大刻みが振動周期より大きい、を設計する。(f)はmissing_initial_condition、(g)はinvalid_input、(h)はinsufficient_time_resolutionとして、解と別状態にする。

E12　第12章へ時間波形を渡す

完全解答

RCではτ=1 msなので、逆数は

1/τ=1000 s^-1

である。これは角周波数でもHzでもなく、指数が減る速さの尺度である。RLCでは、

f_d=ω_d/(2π)≈(9.9875×10^3)/(2π)≈1.589×10^3 Hz

となる。周期は約0.629 msである。波形を周波数成分として見るには、少なくともナイキスト条件としてサンプリング周波数を2f_dより大きくし、実際には波形の形を保つため一周期あたり十分多い点を取る。観測窓の長さは周波数分解能を決めるので、サンプル間隔だけでなく記録時間も保存する。

第9章のκ=t_prop/t_riseが大きくなったら、一つの集中RLCの端子電圧・電流で線路全体を同時刻に表せるという仮定を見直す。V(x,t)、I(x,t)、終端、反射、分布したR',L',G',C'を残す。第12章へは、RLCの値、入力、初期条件、時間窓、サンプリング、source_kind、statusをそのまま引き渡し、周波数変換後のピークを測定値へ改名しない。

再挑戦

RLCのf_d≈1.589 kHzを一周期10点で見るなら、サンプリング周波数は約15.9 kHz以上が目安になる。ただし、急な電源立上りや減衰包絡も見たいなら、最短の立上り時間と振動周期の両方から刻みを決める。これは設計目安であって、全回路へ普遍的な固定値ではない。

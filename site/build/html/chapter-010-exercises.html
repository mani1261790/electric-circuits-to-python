第10章 演習　Kirchhoff則の由来と限界

取り組み方

各問で、電流・電圧の正方向、ground、単位、値の状態（解析予測か、runner出力か、実測か）を先に書く。ヒントは第1段階から順に使い、完全解答を読んだ後は「再挑戦」の条件を変えてもう一度計算する。固定runnerの契約再生と、外部domain runner・実測の未実行境界を解答へ残す。

E1　制御体積の電荷収支

あるnodeを囲む制御体積から外向きに、三本の枝電流I_1=2.0 mA、I_2=-0.50 mA、I_3=1.0 mAが定義されている。dQ_n/dtを求めよ。さらに、nodeの電荷蓄積を無視できるとき、この三本の値はKCLを満たすか。

段階ヒント
  1. 外向き電流の一般式はdQ_n/dt+ΣI_b^out=0である。
  2. まずΣI_b^outをmAのまま足す。負の電流は、実際にはnodeへ入る向きである。
  3. KCLの単純形はΣI_b^out=0であり、和が0でないなら電荷蓄積を0とは置けない。

E2　枝の向きと単位

node 1の電圧をV_1=1.2 V、node 2の電圧をV_2=3.2 V、両者の間の抵抗をR=100 Ωとする。電流の正方向を1→2と定義したとき、I_12を求めよ。電流が負になった意味を説明し、R=100 Ωを100 kΩと誤入力した場合の大きさを比較せよ。

段階ヒント
  1. I_12=(V_1−V_2)/Rへ代入する。
  2. 電圧差は−2.0 Vであり、負号は定義した向きと実際の向きが逆であることを示す。
  3. 抵抗を1000倍にすると、同じ電圧差の電流の大きさは1000分の1になる。単位を最後まで書く。

E3　二つの電流源を節点解析する

node 1とgroundの間にR_1g=1 kΩ、node 2とgroundの間にR_2g=2 kΩ、node 1とnode 2の間にR_12=1 kΩを置く。groundからnode 1へ3 mA、groundからnode 2へ1 mAを注入する。V_1、V_2、I_12、I_1g、I_2gを求め、両nodeでKCLを確認せよ。

段階ヒント
  1. 抵抗値をΩ、注入電流をAへ直し、Gv=jを作る。右辺はnodeへ注入する電流である。
  2. 行列は[[0.002,-0.001],[-0.001,0.0015]]、右辺は[0.003,0.001]である。
  3. I_12=(V_1−V_2)/1 kΩ、I_1g=V_1/1 kΩ、I_2g=V_2/2 kΩを使い、注入電流と比較する。

E4　Faraday則とKVLの右辺

閉路の向きと面の法線を右手系で選び、閉路を貫く磁束をΦ_B(t)=2.0 μWb sin(1.0×10^5 t)とする。t=0でのΣv_bを求めよ。Σv_b=0と置く単純KVLを使えるか、理由とともに答えよ。

段階ヒント
  1. 一般の閉路収支はΣv_b=−dΦ_B/dtである。
  2. dΦ_B/dt=2.0×10^-6×1.0×10^5 cos(1.0×10^5t) Vである。
  3. t=0ではcosineが1なのでΣv_b=−0.20 V。磁束変化を無視できないため、右辺0のKVLは使えない。

E5　節点と独立な方程式

一つの連結した回路に、groundを含む4個のnodeと5本のbranchがある。並列枝や理想電圧源の矛盾はないものとする。(a) groundを選んだ後の基本的な独立KCLの数、(b)独立な閉路の数を求めよ。(c) groundを選ぶ理由と、全nodeへKCLを書いたときに一式が冗長になる理由を説明せよ。

段階ヒント
  1. 非基準nodeの数は、全node数からground一個を引く。
  2. 連結グラフの独立閉路数はbranch数−node数+1である。
  3. 全nodeの枝電流を足すと、各branchが一度ずつ出て一度ずつ入るため全体で相殺する。groundは電圧の基準であって、物理的に電圧を消す場所ではない。

E6　浮いた電圧源をMNAで解く

node 1とnode 2の間に、node 1を正端子とする5 Vの理想電圧源を置く。各nodeからgroundへ1 kΩの抵抗を置く。電圧源電流i_sの正方向をnode 1からnode 2とする。MNAの行列を解き、V_1、V_2、i_sを求めよ。電源と二つの抵抗の電力も求めよ。

段階ヒント
  1. 行列は[[0.001,0,1],[0,0.001,-1],[1,-1,0]] [V_1,V_2,i_s]^T=[0,0,5]^Tである。
  2. 第三行からV_1−V_2=5、上二行から0.001V_1+i_s=0、0.001V_2−i_s=0を使う。
  3. 抵抗の電力はV^2/R、電源の電力は正端子へ入る電流を使ったV_s i_sである。

E7　行列stampを手で作る

node 1とgroundの間に2 kΩ、node 1とnode 2の間に1 kΩを置く。さらに、node 2からgroundへ3 mAの電流源を置く（電流源の向きは2→0）。Gv=jのGとjを、単位を明記して作れ。node 1とnode 2が浮いているかどうかも判断せよ。

段階ヒント
  1. 抵抗のコンダクタンスは0.0005 Sと0.001 Sである。
  2. node 1-groundのstampはG[1,1]だけ、node 1-node 2のstampは四要素へ入る。
  3. 2→0の電流源はnode 2から外へ出るので、注入ベクトルのnode 2成分は−0.003 A。node 1は抵抗を通してgroundへつながるため、回路全体は浮かない。

E8　最小ソルバの入力検査

E6のようなMNAソルバへ、次の入力を渡す。(a)抵抗R=0、(b) node番号7をnode_count=3へ渡す、(c)電圧源を同じ二つのnodeへ5 Vと3 Vで並列に置く、(d)電圧源だけでgroundへつながらない二つのnodeを作る。それぞれを「有限な解」「入力エラー」「特異または矛盾した系」のどれに分類し、理由を書け。部分ピボットを行う目的も説明せよ。

段階ヒント
  1. 0Ωを1/Rへそのまま入れると、有限な導電率ではない。理想短絡は電圧制約として別扱いにする。
  2. node範囲、抵抗の正値、有限値をstamp前に検査する。
  3. 並列する異なる電圧制約は矛盾、groundのない回路は基準不足で特異になり得る。部分ピボットは小さい対角要素を避けるための行交換である。

E9　符号・単位・接地の故障診断

E3の回路を実装したところ、次の三つの報告が出た。

  1. node 1への3 mA注入を、行列右辺へ+3.0と記録した。
  2. 抵抗値1 kΩを数値1.0として入力した。
  3. node 2とgroundの接続を削除しても、ソルバはV_2=0を返した。

各報告の故障を、(a)符号、(b)単位、(c)回路の特異性、のどれとして説明し、最小の修正または追加検査を示せ。

段階ヒント
  1. E3の右辺は「注入」を表すので、電流源の向きからstampの符号を決め直す。
  2. kΩからΩへの変換、mAからAへの変換を、入力境界で一度だけ行う。
  3. 解けない行列を0埋めしてはいけない。特異として止め、ground、接続、理想制約を調べる。

E10　残差と電力のチェック

E6の解析予測V_1=2.50 V、V_2=−2.50 V、i_s=−2.50 mAを、MNAの三行へ代入せよ。(a)三つの方程式の残差、(b)各抵抗の電力、(c)電圧源の電力、(d)全電力の和を求めよ。電力の符号規約を明記する。

段階ヒント
  1. 残差は左辺から右辺を引く。電圧源の第三行はV_1−V_2−5である。
  2. 抵抗にはP=V^2/Rを使う。
  3. 電圧源電流を正端子から負端子への向きで定義しているので、P_s=5 i_s。負の電力は供給を表す。

E11　負のテストの設計

抵抗・電流源・電圧源を受け取る予定runnerに、少なくとも五つの負のテストを設計せよ。各テストについて、入力、期待する状態、解を返さない理由を表にする。NaN、負の抵抗、範囲外node、groundのない回路、矛盾する電圧源、単位混同から五つ以上を選び、どの段階（入力検査、stamp、線形解法、残差検査）で止めるかも書く。

段階ヒント
  1. 数値が有限か、抵抗が正か、nodeが範囲内かをstamp前に検査する。
  2. ground不足や矛盾する電圧源は、stamp後の特異・不整合な系として記録する。
  3. 1 kΩを1 Ωとする単位混同は、数学的には解けるため、単位付き入力または範囲検査と物理基準値の警告を別に設計する。

E12　KCL・KVLの適用範囲を引き渡す

第9章の線路で、t_prop/t_rise=5となる速い信号を一つの集中閉路へまとめた。さらにnodeに容量があり、dQ_n/dtが無視できない。(a)単純なΣI=0とΣV=0のどちらの仮定が危険か、(b)残すべき状態変数または追加の枝を挙げよ、(c)第11章へ何を引き渡すかを説明せよ。磁束変化が大きい場合も一つ加えよ。

段階ヒント
  1. κ=5は伝搬を隠しにくい条件であり、容量電流はI_C=C dV/dtとしてKCLへ残す。
  2. 分布線路ならV(x,t)とI(x,t)、集中過渡ならnode電圧とコンデンサ電圧、インダクタ電流を状態にする。
  3. 変化磁束がある閉路ではΣv_b=−dΦ_B/dtで、右辺0のKVLではなく誘導起電力を記録する。

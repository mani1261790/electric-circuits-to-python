第5章 演習解答　電荷と電場

E1　電荷と次元を確認する

完全解答

I=2.0 mA=2.0×10^-3 A、Δt=5.0 ms=5.0×10^-3 sである。一定電流なので Δq=IΔt=(2.0×10^-3 A)(5.0×10^-3 s)=1.0×10^-5 A s=1.0×10^-5 C=10 μC。A sはCと同じである。電流を時間で割らず、時間を掛ける。

再挑戦

I(t)=2.0 mA+1.0 mA/s×t、0≤t≤5.0 msなら、Δq=∫I(t)dtを区間付きで計算する。一定電流の答えとの差を、増加した電流の面積として説明する。

E2　クーロン力の向き

完全解答

符号の積は負なので引力である。q_2は右側にあるため、q_2に働く力は-x向き。大きさは k|q_1q_2|/r²=(8.9875517923×10^9)(2.0×10^-9)(3.0×10^-9)/(0.30)²≈5.99×10^-7 N。したがって F_2←1≈(-5.99×10^-7,0,0) N。

再挑戦

q_1=-2 nC、q_2=-3 nCへ符号だけを変える。同符号なので大きさは同じ、力の向きは+xとなる。ベクトル式へ符号を残して確認する。

E3　重ね合わせを成分で計算する

完全解答

原点から各電荷までの距離は0.10 mで、一つの電場の大きさは E_one=k|q|/r²=(8.9875517923×10^9)(1.0×10^-9)/(0.10)²≈898.755 N/C。左の正電荷の場は右向き、右の負電荷へ向かう場も右向き。よって E_total=(898.755+898.755,0,0)≈(1797.51,0,0) N/C。

再挑戦

右の電荷を+1.0 nCに変える。左の正電荷の場は+x、右の正電荷の場は-xなので、対称性から合成電場はゼロになる。

E4　電場と力を分ける

完全解答

正電荷では F=qE=(2.0×10^-6)(300,-400,0)=(6.0×10^-4,-8.0×10^-4,0) N。電子では F_e=(-1.602176634×10^-19)(300,-400,0)≈(-4.80653×10^-17,6.40871×10^-17,0) N。電子の力は電場と逆向きになる。電場が同じでも力が違うのはqが違うため。

再挑戦

q=-2.0 μCなら正電荷の解答の各成分が反転する。電場は試験電荷を変えても、元の電荷分布が同じなら変わらない。

E5　点電荷の電位

完全解答

無限遠をゼロとすると V=kQ/r=(8.9875517923×10^9)(1.0×10^-9)/0.10≈89.8755 V。U=q_testV=(2.0×10^-9 C)(89.8755 J/C)≈1.79751×10^-7 J。電位は単位電荷あたりのエネルギーで、電位だけはエネルギーではない。

再挑戦

q_test=-2.0 nCへ変える。Vは元の電荷と基準で決まり変わらず、U=q_testVだけが-1.79751×10^-7 Jへ反転する。

E6　電位の勾配と符号

完全解答

E_x=-dV/dx=-d(3.0x²)/dx=-6.0x V/m。x=2.0 mではE_x=-12.0 V/m。電位が+xへ増えるので、電場と正電荷の力は-x向き。係数3.0はV/m²の単位を持つものとして読む。

再挑戦

V(x)=10.0-4.0x VならE_x=+4.0 V/m。正電荷は+x、負電荷は-xへ力を受ける。電位が右へ下がると電場は右を向く。

E7　面の向きと電束

完全解答

一様場ではΦ=E·n A。 (a) E·n=500なのでΦ=+100 N m²/C。 (b) E·n=-500なのでΦ=-100 N m²/C。 (c) 内積がゼロなのでΦ=0。面の向きは電束の符号を決める。

再挑戦

E=(300,400,0) N/C、n=(3/5,4/5,0)なら内積は300×3/5+400×4/5=500 N/C。面積0.50 m²なのでΦ=+250 N m²/C。

E8　球面に対するガウスの法則

完全解答

球面上の電場は一様なので E=kQ/R²=(8.9875517923×10^9)(4.0×10^-9)/(0.50)²≈143.801 N/C。電束は Φ_E=Q/ε0=(4.0×10^-9)/(8.8541878188×10^-12)≈451.764 N m²/C。電場は1/R²で小さくなる一方、球面積がR²で増えるので、電束は変わらない。

再挑戦

R=1.0 mなら電場は元の1/4、およそ35.9502 N/C。電束は同じ451.764 N m²/C。中心をずらすと電場分布は一様でなくなるが、閉曲面が電荷を包む限り正味電束は変わらない。

E9　平面と導体表面の境界条件

完全解答

σ=2.0×10^-6 C/m²。絶縁体の無限平面では E=σ/(2ε0)≈1.12941×10^5 N/C。理想導体では内部がE_in=0で、境界条件 E_out,n-E_in,n=σ/ε0より、直外は E_out,n=σ/ε0≈2.25881×10^5 N/C。正の面電荷から外向きである。導体表面の値が二倍なのは、電束が片側へ出るため。

再挑戦

σ=-2.0 μC/m²なら大きさは同じだが、外向き法線に対するE_out,nは負。電場は負電荷へ向かう。

E10　電場コードの故障を直す

完全解答

第一に、charge_position-pointは正電荷から観測点へ向かう変位の反対なので、正の電荷では場の向きを逆にする。point-charge_positionへ直す。第二に、abs(charge_nC)は符号を消しているので、qの符号を保つ。第三に引数名はnCなので q=charge_nC*1e-9 とクーロンへ変換する。第四に、観測点が電荷位置と同じ場合はr=0なのでValueErrorで拒否する。

修正の中心は次である。

q = charge_nC * 1e-9
displacement = (point[0] - charge_position[0],
                point[1] - charge_position[1])
r = (displacement[0] ** 2 + displacement[1] ** 2) ** 0.5
if r == 0.0:
    raise ValueError("observation point equals point charge")
factor = 8.9875517923e9 * q / r ** 3
return (factor * displacement[0], factor * displacement[1])

q/r³と変位ベクトルを掛けることで、kq/r²の大きさと向きを同時に得る。

再挑戦

三次元タプルへ拡張し、(0,0,0)の正電荷に対して(0.1,0,0)で正のx成分になるテスト、負電荷で全成分が反転するテスト、nCからCへの変換テストを追加する。

E11　数値積分の結果を診断する

完全解答

理論値は Q/ε0=(1.0×10^-9)/(8.8541878188×10^-12)≈+112.9 N m²/C。通常の外向き法線なら正になるため、提示された結果は外向きと内向きの法線ラベルが入れ替わった可能性が高い。ただし値だけで式の誤りとは断定しない。

確認すべき点は、(1) 各法線が本当に外向き単位ベクトルか、(2) E·nを使っているか、(3) 面積重みが球面全体を正しく分割しているか、(4) 電荷が球の内側か、(5) Qの符号と距離の単位が正しいか、である。外向きと内向きの計算で符号が反転し、大きさが理論値へ近づくかも記録する。

再挑戦

球面の一部だけを積分するよう変更する。中心電荷を囲まない開いた面では、電束はQ/ε0ではない。境界の向きと面積重みを実験記録へ残す。

E12　モデルの境界を説明する

完全解答

「スイッチを閉じた直後、電子の平均ドリフト速度が電池から電球まで移動する時間を、そのまま信号伝達時間とは呼ばない。電池と導線の電荷分布が変化し、周囲を含む電磁場の変化が回路に沿って伝わる。その場と境界条件が電球の端子電圧と電流を決める。回路の寸法が信号の波長より十分小さく、周波数が低く、導体と接続が指定範囲なら、場の詳細を集中定数回路の電圧・電流へまとめられる。長い配線、高周波、反射、分布定数効果を扱うなら、伝送線路など別の模型を使う。」

電子の局所的な移動、電磁場の変化、端子の集中定数という記述を分けた。正確な伝達時間には、配線、境界、初期状態、周波数範囲を指定する必要がある。

再挑戦

数センチの低周波回路と、数メートルの高速デジタル配線を別々に説明する。前者では寸法が波長より十分小さいかを確認して集中定数近似を使い、後者では反射・伝送線路を調べる必要がある、と条件を書き分ける。

第25章 演習解答

E1

V_OHは出力高の保証最小値、V_OLは出力低の保証最大値である。V_IHは入力高として保証できる最小値、V_ILは入力低として保証できる最大値である。Oはoutput、Iはinput、Hはhigh、Lはlowを表す。典型値ではなく、指定条件下の保証境界か、解析上の境界かを別途記録する。

E2

V_ILとV_IHの間は、低入力とも高入力とも保証されない遷移領域だからである。VTCは連続なV_inとV_outを結ぶが、論理契約はその全ての電圧に一意の論理値を与える必要はない。遷移領域の扱いを0または1と断定するには、別の判定規約や回路条件が必要である。

E3

低出力に正の雑音が加わる最悪条件はV_OL+n_Lである。低入力として保証するにはV_OL+n_L <= V_ILが必要なので、許容上限はn_L <= V_IL-V_OL、従ってNML=V_IL-V_OLとなる。高出力では負の雑音が危険なので、V_OH-n_H >= V_IHからn_H <= V_OH-V_IH、従ってNMH=V_OH-V_IHとなる。

E4

独立例noise_margin_numeric_exampleでは、NML=0.35-0.20=0.15 V、NMH=0.80-0.65=0.15 Vである。低い信号では電圧を上げる雑音、高い信号では電圧を下げる雑音が危険で、両方の許容振幅はこの予定条件では0.15 Vである。数値は解析予測であり、測定値ではない。第25章代表CMOS caseの予測値（NML=NMH=0.40 V）とは別caseである。

E5

V_inが上がるとnMOSのゲート・ソース間電圧が増えてpull-down側が強くなり、pMOSのソース・ゲート間電圧は減ってpull-up側が弱くなる。そのため出力ノードはGND側へ動き、dV_out/dV_inは負になる。負の傾きを反転利得の大きさとしてA_v=-dV_out/dV_inと定義するので、通常の単調減少VTCではA_vが正になる。

E6

VTC上で傾きが-1になる点を二つ探し、低入力側の点をV_IL、高入力側の点をV_IHとする。第一に、これは出力勾配を入力判定境界へ対応付ける設計・測定規約であり、物質が一意に決める法則ではない。第二に、データシートや別の論理規格が別の保証試験、負荷、温度、周波数を定めることがある。したがってthreshold_ruleと条件を保存する。

E7

F(V_in,V_out)=0をV_inで微分すると、∂F/∂V_in + (∂F/∂V_out)(dV_out/dV_in)=0である。従って

dV_out/dV_in = -(∂F/∂V_in)/(∂F/∂V_out)。

分母が0に近いと傾きが非常に大きくなるか、暗黙関数として局所的に解けない。領域の境界や複数根もあり得るため、残差、領域、rail制約とともに診断し、単純な割り算で値を作らない。

E8

NMLは静的な電圧差であり、入力がある電圧範囲に留まった場合の契約である。C_loadが出力電圧の変化を遅らせると、雑音パルスが消える前に出力がほとんど変わらないことも、長く続いて判定時刻に遷移領域にいることもある。従って雑音振幅に加え、パルス幅、入力波形、C_load、初期状態、判定時刻を調べ、静的余裕と過渡の成否を別に判定する。

E9

低出力ではV_OL+n_L <= V_IL、またはn_L <= NMLなら、次段の入力は低入力の保証範囲に入る。高出力ではV_OH-n_H >= V_IH、またはn_H <= NMHなら、次段の入力は高入力の保証範囲に入る。後段の負荷や電源が前段のV_OH、V_OLを変える場合は、同じ数値をそのまま再利用できない。

E10

解析式の結果はsource_kind: analytic_prediction、SPICEの数値解はsource_kind: spice_predictionであり、どちらもmeasured: falseである。実機と計器から取得した波形だけが、条件と取得記録を伴ってsource_kind: measurement、measured: trueになり得る。本章の測定artifactは未取得なので、現在ここで測定値と呼べるものはない。

E11

V_OH < V_OLは出力保証範囲の反転またはinvalid_output_order、V_IH < V_ILは入力境界の反転またはinvalid_input_orderである。NMLとNMHの交換はnoise_margin_polarity_error、+1の採用はインバータの傾き符号を落としたvtc_slope_sign_errorである。未取得SPICE出力を測定と表示するのはsource_kind_mismatchまたはunmeasured_claimである。いずれも0や典型値へ黙って置換せず、入力と失敗契約を記録する。

E12

(a)はV_OH,V_OL,V_IH,V_ILと、保証条件、判定規約である。(b)はNML,NMH、雑音の符号、正負の許容振幅である。(c)はV_DD,V_tn,V_tp,beta_n,beta_p,C_load、body・負荷・初期条件である。(d)は解析、SPICE、測定ごとのsource_kind、tool/model version、status、measured、条件、残差である。(e)は未定義入力領域、VTCの非単調性、過渡未検証、測定未取得、模型の適用範囲である。

追加演習の完全解答

変更課題の解答: 最大・最小電圧の向きを取り違えていないか、同じVDD条件かを確認する。まず入力、単位、境界条件、実装の中間値を順に比較し、最初にずれた値を故障箇所とする。

条件変更の解答: 負の余裕は許容領域が重ならず、ノイズで誤判定し得ることを示す。

再挑戦の解答: VDD低下で余裕が狭くなる場合があるため、境界値を同じ条件で再計算する。変更前後の入力・期待値・実測値を表にし、実装・入力・期待値のどれに属するかを明記する。

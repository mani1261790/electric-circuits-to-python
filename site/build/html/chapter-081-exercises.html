第81章 演習

E1 address space

virtual addressとphysical addressの違いを、processが同じVAを使える例で説明せよ。

E2 page offset

4 KiB pageのVA 0x00401234について、page offsetを求めよ。

E3 PTE

PTEのvalid、read、write、execute、user permissionがそれぞれ何を制限するか。

E4 page table walk

三段page tableでrootからleafまでをたどる表に必要な列を挙げよ。

E5 identity mapping

MMUなしのminiosでidentity mappingを採る場合の利点と限界を書け。

E6 TLB切替

ASIDなしでprocessを切り替えるとき、TLB invalidateが必要な理由を示せ。

E7 guard page

user stackの隣をinvalid pageにすることで何を検出できるか。

E8 作成と破棄

process終了時にleaf、page-table page、TLBをどの順で扱うか。

E9 負のテスト

VA範囲外、非整列PA、user permission不足、overlap mappingをどう拒否するか。

E10 第82章へのbridge

valid=0のPTEに対して、OSが次に受けるべきイベントを説明せよ。

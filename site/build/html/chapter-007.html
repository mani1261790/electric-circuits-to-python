第7章　電流、連続の式、電力

電荷はどのように「流れる」のか

第6章では、電位差を単位電荷あたりのエネルギー差として定義した。ここでは、その電荷が時間あたりにどれだけ移動したかを数える。回路図で導線を一本の線として描いても、実際には断面をもつ空間の中に電荷密度と電荷の速度が分布している。まず全体の流れを電流Iで数え、次に局所的な流れを電流密度Jで記述する。その二つを電荷保存の式で結び、最後に電場が単位時間にした仕事として電力を定義する。

本章の数値例は、すべて「解析的に予測した値」「固定runnerを実行して得た契約検査値」「外部測定値」を分離して記録する。book run 7 1 は解析・契約adapterで再生済みだが、本文に実測結果があるという意味ではない。

今回の到達点

本文を読み、章末課題を終えた時点で、次を式と条件付きで説明できることを目標にする。

  • 電流をI=dq/dtとして定義し、向きと符号を明記する。
  • 電流密度Jを断面を貫く流れとして定義し、I=∫ J·n dAを使う。
  • 局所的な電荷保存を∂ρ/∂t+∇·J=0として導き、節点・有限体積の式へ移す。
  • 定常電流では電荷が消えたのではなく、各制御体積の出入りが釣り合っていると説明する。
  • 電力P=VI、局所の発熱密度p=J·E、抵抗の式を符号付きで使う。
  • 電子のドリフト速度と、電磁場によるエネルギー輸送を区別する。Poyntingベクトルは発展事項として位置付ける。
  • 断面変化、境界、向き、単位、電荷保存を含む数値モデルの故障を診断する。

1　時間あたりの電荷として電流を定義する

1.1　電流は電荷の個数ではなく通過率である

ある断面を選び、その断面を時間Δtの間に通過した符号付き電荷をΔqとする。平均電流を

I_avg = Δq / Δt                                      (7.1)

で定義する。時間幅を0へ縮めた極限が瞬時電流である。

I(t) = dq/dt                                         (7.2)

電荷の単位はC、時間の単位はsなので、電流の単位はC/s、すなわちアンペアAである。1 A=1 C/sである。ここで数えているのは断面を通る電荷の正味の量であり、金属中でランダムに動いている全電子の総移動距離ではない。

断面に向きを指定し、その向きへ正電荷が通過する量を正とする。これは「正の電流の向き」であり、電子の運動方向と一致するとは限らない。電流の符号を決めるには、次の三つを毎回書く。

  1. どの断面を選んだか。
  2. 断面の法線をどちらへ向けたか。
  3. その法線向きへ運ばれる正電荷を正としたか。

1.2　電流と電子の向き

電子一個の電荷はq_e=-eである。電子が-x方向へ動けば、負の電荷が負方向へ運ばれるので、正電荷の流れとしては+x向きの電流になる。したがって「電子の速度」と「慣用電流の向き」を同じ矢印で描いてはいけない。

ただし、電流は特定の粒子の流れだけを意味しない。正孔、イオン、電子など、符号の異なる担体の寄与を合計した量である。後で物質の導電性を扱うとき、担体の密度、電荷、平均速度を別々に記録する。

1.3　電流の測定は断面を切り開く操作ではない

電流計は、回路のある枝を通過する流れを自分の入力端子へ通すように接続される。理想電流計の内部抵抗を0とみなすのは、測定器を回路の直列枝へ入れても流れを変えないという近似である。現実の測定器には抵抗、帯域、サンプリング、保護回路があり、測定値には条件が付く。

電流を見たからといって、その断面の両側の電荷密度が同じとは限らない。局所的に電荷が蓄積しているなら、入る電流と出る電流の差はdQ/dtになる。この差を扱うのが連続の式である。

2　電流密度と断面積

2.1　局所の流れをベクトルで置く

場所rと時刻tで、単位面積・単位時間あたりに運ばれる符号付き電荷を電流密度J(r,t)とする。電流密度はベクトルであり、向きは正電荷の流れの向き、単位は

[J] = A/m^2 = C/(s m^2)                              (7.3)

である。断面Sに面素ベクトルdA=n dAを置くと、断面を貫く電流は

I = ∫_S J · dA = ∫_S J · n dA                       (7.4)

となる。nは指定した単位法線である。Jが法線と同じ向きなら寄与は正、接線方向なら0、逆向きなら負になる。電流密度の大きさだけを面積に掛ける式I=JAは、Jが断面上一様で法線と平行な場合に限った短縮形である。

2.2　断面が変わる導体

導体が定常状態にあり、途中に電荷を蓄積せず、枝分かれもないとする。断面積がA_1からA_2へ変わるなら、同じ電流Iを運ぶため

J_1 = I/A_1,
J_2 = I/A_2                                  (7.5)

となる。細い部分では電流密度が大きく、太い部分では小さい。これは「細い部分で電荷が消費された」という意味ではない。電流が保存される条件では、密度や平均速度のどれかが変化して、面積積分が同じになる。

例として、I=10 mA=1.0×10^-2 A、A_1=2.0 mm^2=2.0×10^-6 m^2、A_2=0.50 mm^2=5.0×10^-7 m^2とする。

J_1 = 5.0×10^3 A/m^2
J_2 = 2.0×10^4 A/m^2                             (7.6)

面積をmm^2のまま代入すると、10^6倍の誤差になる。単位をそろえることは、計算後の飾りではなく、式が何を数えているかを保つ操作である。

2.3　複数の担体を合計する

担体の種類をαとし、数密度をn_α、電荷をq_α、平均速度をv_αとする。十分小さい体積で速度が一方向にそろう近似なら、

J = Σ_α n_α q_α v_α                             (7.7)

である。n_αの単位は1/m^3、q_αはC、v_αはm/sなので、Jの単位はC/(s m^2)になる。式(7.7)は、熱運動のすべてをそのまま足したものではなく、平均速度で表した連続体近似である。互いに逆向きの粒子運動でも、電荷の符号を含めれば電流への寄与を正しく合計できる。

3　連続の式：電荷保存を局所化する

3.1　まず有限の領域で数える

任意の固定された体積Ωに含まれる電荷を

Q_Ω(t) = ∫_Ω ρ(r,t) dV                               (7.8)

とする。ρは電荷密度で、単位はC/m^3である。領域の境界∂Ωには外向き法線nを選ぶ。外へ出ていく電流は∂Ωを貫く面積分

I_out = ∮_∂Ω J · n dA                              (7.9)

である。電荷保存は、領域内の電荷の増加率が外へ出る流れの負になることを表す。

dQ_Ω/dt = -∮_∂Ω J · n dA                           (7.10)

式(7.10)は「電荷が消えない」という言葉を、境界を指定した計算式へ変換したものだ。外から入る電流が出る電流より多ければ、右辺は正で領域内の電荷が増える。

3.2　発散定理で局所式にする

発散定理

∮_∂Ω J · n dA = ∫_Ω ∇·J dV                 (7.11)

を式(7.8)と式(7.10)へ代入する。

∫_Ω ∂ρ/∂t dV = -∫_Ω ∇·J dV
∫_Ω (∂ρ/∂t + ∇·J) dV = 0                  (7.12)

任意の領域Ωで成立するなら、十分滑らかな場について被積分関数も0でなければならない。これが連続の式である。

∂ρ/∂t + ∇·J = 0                              (7.13)

∇·Jは、その点の小さな体積から正味で流れ出す電流密度を表す。発散が正なら、その場所から出る方が多く、電荷密度は減る。発散が負なら、入る方が多く、電荷密度は増える。

3.3　一次元の有限体積式

計算で扱いやすいように、x_iからx_i+Δxまでの細長いセルを考える。断面積Aが一定で、左から右を正とする。左面から入る電流をI_in、右面から出る電流をI_outとすれば、セル内電荷Q_i=ρ_i AΔxは

dQ_i/dt = I_in - I_out
dρ_i/dt = (I_in - I_out)/(AΔx)            (7.14)

となる。I=JAなら、

dρ_i/dt = -(J_out-J_in)/Δx                 (7.15)

である。数値実装では、この順序を守ると符号を追いやすい。

rho_next = rho + dt * (I_in - I_out) / (area * dx)

左面の法線を勝手に外向きと読んでI_inへそのまま代入すると、符号を二重に反転しやすい。有限体積法では「流入」「流出」を言葉で固定してから式へ写す。

3.4　境界条件と源の扱い

絶縁境界なら、境界を横切る法線電流を0とする。

J · n = 0                                        (7.16)

外部回路から電荷を注入する電極では、J·nを与える境界条件として記録する。電荷を生成・消滅させる人工的な体積源を入れるなら、保存則は

∂ρ/∂t + ∇·J = s_ρ                              (7.17)

のようになる。ただし、電荷の源s_ρを導入したら、何が電荷を供給するのか、単位がC/(m^3 s)か、閉じた系の保存を破っていないかを明記する。単に計算を安定させるためにρを毎ステップ消す操作を、物理的な電荷保存と呼んではならない。

4　定常電流と回路の節点

4.1　定常とは「どこにも変化がない」の一部だけを意味する

定常状態では、電荷密度が時間によらないので∂ρ/∂t=0である。連続の式は

∇·J = 0                                        (7.18)

となる。Jが0という意味ではない。電流が流れていても、微小領域へ入る流れと出る流れが釣り合えば、密度は変化しない。

一様な直線導体なら、式(7.18)は同じ断面を通る電流が一定であることへ縮約される。枝分かれする節点では、制御体積を節点の周りに取り、定常なら

Σ I_in = Σ I_out                              (7.19)

となる。これは後の回路理論でいう節点電流則の物理的な出発点である。回路図の点で電荷が永遠に積み上がっていると仮定しているのではなく、節点周辺の小さな電荷蓄積が定常近似で無視できるという条件を置いている。

4.2　定常近似が破れるとき

スイッチを閉じた直後、コンデンサを充電している途中、電極へ電荷を注入している途中では、ある場所のρが変化し得る。このとき入出力電流が一致しないこと自体は、バグではなく蓄積の記録かもしれない。逆に、定常だと宣言した計算でdρ/dtが大きいなら、境界条件、向き、単位、離散化のいずれかを再確認する。

「電流が流れると電荷が導線の中で消える」という説明は誤りである。抵抗体で電気エネルギーが熱へ変換されても、連続の式に源を入れない限り電荷は保存される。消費されるのは電力として数えたエネルギーであって、電荷そのものではない。

5　電流密度を担体の運動へ戻す

5.1　平均ドリフト速度

一種類の担体が数密度n、電荷q、平均速度v_dで動くとする。式(7.7)は

J = n q v_d                                       (7.20)

となる。金属中の電子ではq=-eである。電場による電子の平均ドリフトは電場と逆向きになりやすいので、Jは電場と同じ向きになり得る。速度v_dを絶対値だけで入力すると、この符号関係を失う。

数密度が一定で、断面が一様なら、電流は

I = n q v_d A                                      (7.21)

となる。断面が細くなったとき、同じIを保つためにv_dが増える模型もあれば、密度が変わる模型もある。どの量を固定したかを決めずに「細いほど電子が速い」と一般化してはいけない。

5.2　ドリフト速度は信号速度ではない

金属中の電子は熱運動をしながら、非常に小さな平均ドリフトを持つ。回路のスイッチを操作したとき遠端へ変化が伝わる時間は、電子一個がその距離をドリフトする時間だけでは決まらない。電磁場の変化、導体と周囲の境界、分布容量・インダクタンス、測定器の帯域が関係する。

したがって、

  • 電子の平均速度は電荷担体の運動の模型。
  • 電流Iと電流密度Jは断面を通る正味の電荷の流れ。
  • 信号の伝搬は電磁場と境界の時間変化の問題。

を別々に記録する。第8章では、Jが同じ電場に対して物質ごとに異なる理由を、移動度や抵抗率の古典模型から調べる。

6　電場がする仕事と電力

6.1　電荷一個の仕事を流れ全体へ足す

電位差V_ab=V_a-V_bを、端子aから端子bへ進む電荷が失うエネルギーとして使う。正電荷dqが電位降下V_abを通過すると、電場がした仕事は

dW_field = V_ab dq                                (7.22)

である。時間あたりに通過する電荷がI=dq/dtなら、吸収される電力は

P_abs = dW_abs/dt = V_ab I                         (7.23)

となる。ここでV_abは「電流の正方向に進んだときの電位降下」と定義した。受動符号規約、つまり電流が素子の高電位端へ入り低電位端から出る向きを採るなら、P_abs=VI>0は素子がエネルギーを吸収していることを意味する。

電源側では、同じ端子極性へ電流が入るとP=VI>0は電源が内部へ吸収する電力であり、外部へ供給する電力は負になる。VIの数値だけを見て「消費」と決めず、端子の極性と電流矢印を書く。

6.2　局所の電力密度

微小な体積dVで担体種αの数密度をn_α、電荷をq_α、平均速度をv_αとする。担体種ごとの力密度を足すと、単位時間あたりの仕事密度は

p = Σ_α (n_α q_α E) · v_α
  = E · Σ_α (n_α q_α v_α)                 (7.24)

となる。第2章で定義した電流密度の担体和J=Σ_α n_α q_α v_αを使えば、

p(r,t) = J(r,t) · E(r,t)                          (7.25)

を得る。単位は(A/m^2)(V/m)=W/m^3である。体積で積分すると総電力になる。

P = ∫_Ω J · E dV                                  (7.26)

式(7.25)が正なら、その場所の担体が電場からエネルギーを受け取る向き、負なら場へエネルギーを返す向きである。電荷の流れがあっても、JがEと直交すればこの局所の仕事率は0になる。電流があることと発熱があることは、同じ意味ではない。

6.3　抵抗のJoule熱

物質が局所的に線形で等方的な応答を示し、

J = σ E                                            (7.27)

と書ける範囲では、σは導電率で単位はS/mである。抵抗率ρ_e=1/σを使うと、

p = J·E = σ|E|^2 = |J|^2/σ ≥ 0                     (7.28)

となる。長さL、断面積Aが一様な棒では、V=EL、I=JAと近似できるので

P = VI = I^2 R = V^2/R,
R = ρ_e L/A                                        (7.29)

を得る。ただし、式(7.29)は静かに成立する自然法則の定義ではなく、局所応答、形状、一様場、定常または準静的近似から導いた集中定数の結果である。第8章で導電率を物質模型から検査する。

6.4　電源、抵抗、蓄積を分ける

抵抗でのP=I^2Rは、その場所で電磁気的なエネルギーが熱などへ変換される割合である。電源が供給したエネルギー、コンデンサやインダクタへ一時的に蓄えたエネルギー、抵抗で不可逆に変換されたエネルギーは、別のartifact欄へ保存する。Pを積分してエネルギーにするには、積分区間、符号、端子または体積、状態を明記する。

7　発展：場からエネルギーが入るという見方

電力をVIだけで表せると、エネルギーが電線の内部を電荷に乗って運ばれ、抵抗で降ろされるように感じやすい。分布した電磁場では、エネルギー流束を

S = E × H                                           (7.30)

で表す。SはPoyntingベクトルと呼ばれ、単位はW/m^2である。電磁場のエネルギー密度と合わせた局所エネルギー収支は、概念的には

∂u_em/∂t + ∇·S = -J·E                              (7.31)

と書ける。右辺の-J·Eは、場が物質へ渡した電力の反対符号である。

ここで扱うのは発展欄であり、H、磁性体、時間変化する場の厳密な境界条件を本章の必修到達点にはしない。式(7.30)を導線内の電子の速度ベクトルと同一視してはいけない。また、低周波の集中定数模型でP=VIを使えることと、分布場のエネルギー流を詳細に解くことは、異なる解像度の記述である。後の伝送線路と信号完全性で再び扱う。

8　断面変化と電荷保存を数値で検査する

8.1　実験契約

必修の実装・実験は一つのrunner入口にまとめる。

book run 7 1

現在のtools/bookでは、この実験は固定runnerの解析・契約adapterで実行され、入力hashと検査結果が保存される。外部domainの実行結果や測定値はまだない。以下は固定する入力と期待される解析予測である。

#### 問題A：断面変化

+x方向を正とし、定常電流I=10 mAが枝分かれしない導体を流れる。二つの断面を

A_1 = 2.0 mm^2 = 2.0×10^-6 m^2
A_2 = 0.50 mm^2 = 5.0×10^-7 m^2
I   = 1.0×10^-2 A

とする。式(7.4)の一様近似からJ_1=5.0×10^3 A/m^2、J_2=2.0×10^4 A/m^2を予測する。各断面でJ·nの符号、面積の単位、面積積分の値をartifactへ残す。

#### 問題B：連続の式を守るセル列と壊すセル列

断面積A=1.0×10^-4 m^2、セル幅Δx=0.10 m、初期密度ρ=0 C/m^3、時間刻みΔt=1.0×10^-4 sとする。左からJ_in=100 A/m^2を流す。

正しいモデルでは各セルでJ_out=J_inとし、

dρ/dt = -(J_out-J_in)/Δx = 0

となる。比較用の故障モデルでは意図的にJ_out=0.90 J_inとする。このモデルは電荷保存を破るため、

dρ/dt = (100 - 90)/0.10 = 100 C/(m^3 s)       (7.32)

となる予測である。100ステップ（経過時間0.010 s）なら、一定流束を仮定した解析予測はρ=1.0 C/m^3となる。これは物理的な測定値ではなく、故障モデルを見つけるための予測値である。セル端の境界では、流入・流出をどの面の法線で定義したかを記録する。

8.2　最小の更新式とartifact

各セルの状態を少なくとも次の項目で保存する。

step, time_s, cell, area_m2, dx_m,
J_in_A_per_m2, J_out_A_per_m2,
I_in_A, I_out_A, rho_C_per_m3,
drho_dt_C_per_m3_s, model, status

statusにはanalytic_prediction_recorded_measurement_not_run、executed、failedなどを置く。modelにはconservingまたはintentional_leakと書き、保存則を破る比較モデルを本来の結果として混ぜない。Jを入力したのかIを入力したのかも実装の設定欄へ残す。I=JAを二度適用すると、単位は合っていても面積を二重に掛ける誤りになる。

中心となる検査は次である。

def update_density(rho, dt, area, dx, I_in, I_out):
    return rho + dt * (I_in - I_out) / (area * dx)

保存モデルではI_in=I_outの全ステップでrhoが初期値にとどまる。故障モデルでは式(7.14)と同じ増加率になる。数値出力がこの解析予測から外れたとき、まずAとdxの単位、次にI_in-I_outの符号、最後にセル境界の条件を確認する。

8.3　変更課題と故障診断

次の順で一つずつ変更する。

  1. A_1とA_2を交換し、同じIでJが逆比になることを確認する。
  2. J_inを-100 A/m^2へ変え、指定法線に対する電流と密度の符号を反転する。
  3. 左端を絶縁境界にしてJ·n=0とし、外部から電荷が流れ込まない条件を確認する。
  4. J_out=0.90J_inの故障を保存モデルの成功ログへ混ぜず、別のmodelとして記録する。

よくある故障は次の通りである。

  • mm^2をm^2へ直さず、Jが10^6倍ずれる。
  • 面積を半径や直径として入力し、A=πr^2を適用し忘れる。
  • 外向き法線の面積分と「流入」を同じ符号で足し、入出力差を反転する。
  • 電子速度をそのままJの向きにし、q=-eの符号を落とす。
  • ρを毎ステップ0へ戻して、保存則の故障を隠す。
  • VIの符号を端子極性なしで「消費電力」と呼ぶ。

8.4　この数値実験で言えることと言えないこと

この実験で言えるのは、指定した断面、流束、セル幅、境界条件のもとで、面積積分と有限体積更新が電荷保存の式に合うかどうかである。金属の導電率、電子散乱、温度上昇、電磁波の伝搬、実際の電力計の誤差を測定したことにはならない。J·Eを電力密度として追加する場合は、Eの単位、領域、局所応答の模型を新たな入力とartifactへ加える。

9　模型の境界と次章への接続

本章の中心は、電流を電荷の通過率、電流密度を局所の流束として置き、電荷保存を連続の式へ落とすことだった。定常状態の∇·J=0は、電流がないという意味ではなく、局所的な蓄積がないという意味である。断面が変わっても電流が保存されるなら、Jは断面積に応じて変わる。

P=VIとp=J·Eは、電場が電荷へした仕事を時間あたりに数えた式である。抵抗のJoule熱はその特殊な応答の結果であり、電源の供給、蓄積、熱への変換を分けて記録する。Poyntingベクトルは分布場のエネルギー流を示す発展記述で、ドリフト速度や集中定数の電流と同一視しない。

第8章では、同じ電場を与えても物質によってJが異なる理由を、キャリア密度、移動度、導電率、抵抗率の古典模型で調べる。J=σEを万能な定義として使わず、どの材料・温度・周波数・電場範囲で成り立つかを確認する。

10　章の確認

次を、符号・単位・仮定付きで説明できるか確認する。

  • I=dq/dtは、選んだ断面と法線に対する符号付きの電荷通過率である。
  • I=∫J·n dAであり、I=JAは一様で法線方向の特別な場合である。
  • ∂ρ/∂t+∇·J=0は、有限領域の入出力収支から導ける。
  • 定常電流では∂ρ/∂t=0だが、Jは0とは限らない。
  • 電子の速度、慣用電流、信号の伝搬速度は異なる量である。
  • P=VIとp=J·Eは、端子極性・方向・領域を指定して初めて符号を解釈できる。
  • P=I^2Rは局所的な線形応答と集中定数近似の結果で、物質の導電性を次章で検査する。
  • 解析予測、runner実行結果、測定値、故障モデルの結果を同じ欄へ保存しない。

5　模型の境界と章間の橋

この章の模型は、適用範囲を明示して初めて安全に使える。次の限界を一つずつ、本文のどの主張に効くかと一緒に読む。

  • 電流の正方向は正電荷の流れであり、電子の速度方向と一般には逆である。
  • I=JAは一様で法線方向の特別な場合で、非一様なJは面積分する。
  • 連続の式は電荷保存の収支であり、数値密度を強制的に消す操作を正当化しない。
  • 定常電流は電荷密度が時間不変という条件であり、電流が0という意味ではない。
  • I=ΣIの節点式は節点の蓄積を無視できる近似または定常条件に依存する。
  • ドリフト速度は信号の伝搬速度ではない。場、境界、分布効果を含まない。
  • P=VIは端子極性と電流矢印を指定しないと、吸収・供給の符号を解釈できない。
  • p=J·EとJoule熱は、局所応答と領域を指定した式で、すべての電流が発熱するとは限らない。
  • J=σEとP=I^2Rは線形・等方的・定常または準静的な材料と形状の近似である。
  • Poyntingベクトルは発展概念で、電子速度や集中定数電流のベクトルとは別物である。
  • domain adapter未導入時の数値は解析予測であり、実測値や再現ログを意味しない。

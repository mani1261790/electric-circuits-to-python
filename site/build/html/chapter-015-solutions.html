第15章 演習解答

E1

完全解答

交換反対称な状態は、規格化因子を除けば

|a,b>_A = |a>_1|b>_2 - |b>_1|a>_2

である。a=bなら、右辺は|a>_1|a>_2-|a>_1|a>_2=0となる。したがって二つのフェルミ粒子を同じ一粒子状態へ入れた状態は存在しない。これは粒子間に新しい反発力があるという意味ではなく、交換に対して反対称でなければならない波動関数のために、許される状態の数え上げが制限されるという意味である。電子では空間ラベルが同じでもスピンが違えば一粒子状態のラベルが違うため、空間軌道に↑と↓を一個ずつ置くことはできる。

再挑戦

aとbが同じ場合だけでなく、空間部分が同じでスピンも同じ場合にゼロになることを、スピンを含むラベルで書き直せ。空間部分が同じでもスピンが違う場合との差も一行で示せ。

E2

完全解答

状態は(1,↑),(1,↓),(2,↑),(2,↓),(3,↑),(3,↓)の6個である。電子6個なら全状態を一個ずつ占有し、空間軌道の占有数はn=1:2, n=2:2, n=3:2となる。n=1に3個と書くと、↑と↓の二つの状態を使い切った後に、同じスピン・同じ空間状態をもう一度使うことになるのでPauli原理に反する。縮退度g=2を使う表記なら、n=1の最大平均占有数はg f=2であって3ではない。

再挑戦

空間軌道が4個、スピンが3種類ある仮想模型なら、ラベル付き一粒子状態は何個になるか。ただし、これは電子の実際のスピンではないと明記せよ。

E3

完全解答

E=μなので指数の引数は0であり、f=1/(1+1)=0.5である。E−μ=+kBTなら引数は+1で、f=1/(e+1)≈0.26894。E−μ=−kBTなら引数は−1で、f=1/(e^-1+1)≈0.73106となる。温度T=300 Kを使う場合も、kBTは約0.02585 eVであり、EとμをeVでそろえれば引数は無次元になる。f(x)+f(-x)=1が数値の検算になる。

再挑戦

E−μ=2kBTと−2kBTについて、それぞれのfを計算し、温度が変わっても「差をkBTで割った値」が同じなら同じfになることを確認せよ。

E4

完全解答

kBT=8.617333262e-5*300≈0.025852 eV。E0−μ=−0.050 eV、E1−μ=+0.050 eVなので、x0≈−1.934、x1≈+1.934である。したがって

f0=1/(exp(-1.934)+1)≈0.8737

f1=1/(exp(1.934)+1)≈0.1263。

平均粒子数はg0 f0≈1.7472、g1 f1≈0.2528、合計は約2.0000である。x1=−x0なのでf0+f1=1、g0=g1=2より合計は2(f0+f1)=2となる。共通runnerでも入力由来の契約モデルを実行済みだが、これは実在試料の測定ではない。記録はstatus="executed_analytic"、source_kind="runner_analytic_contract"、measurement.status="not_run"とし、解析予測とrunner出力を区別する。

再挑戦

同じ準位と温度でμを0.00 eVにしたとき、全粒子数の解析予測を求めよ。指定した準位だけでN_target=2を満たせるかも判定せよ。

E5

完全解答

T→0では、E<μなら指数の引数が負の無限大へ行きf→1、E>μなら正の無限大へ行きf→0となる。E=μは極限の取り方やT=0の定義を別に指定する必要があり、有限温度式へT=0を直接代入してはいけない。有限温度では|E−μ|がkBTの数倍以内でfが0.5から0または1へ移るため、μ付近がなだらかになる。Tを上げるほどkBTが広がり、同じエネルギー差でもfは0.5に近づく。

再挑戦

μ=0.05 eV、E=0.00 eVについてT=30 Kと300 Kの符号付き指数を比較し、低温で占有がより1に近づくことを数値で確認せよ。

E6

完全解答

x=5ならe^-5≈0.00673795。Fermi–Dirac値は1/(e^5+1)≈0.00669285、Boltzmann値はe^-5≈0.00673795で、相対差は約0.67%である。式をf=e^-x/(1+e^-x)と書けば、e^-xが小さいと分母の1+e^-xを1と近似できることが分かる。x=0ではFD値0.5に対してBoltzmann値1、x<0ではBoltzmann値が1を超えることさえあるので、低占有率の正のxという条件が必要である。

再挑戦

x=8とx=2で同じ比較を行い、「何桁小さければ近似を採用するか」は目的の許容誤差で決める、という結論を数値とともに書け。

E7

完全解答

「空間軌道一つに二個」は、スピン↑とスピン↓という二つの異なる一粒子状態を合わせた最大数である。一つの空間準位を代表する占有率fだけを計算するならn_i=g_i f_iとしてg=2を掛ける。一方、状態を(n,spin)まで列挙して各状態のfを計算するなら、すでに↑↓を別々に数えているのでさらに2を掛けない。空間軌道3個ならラベル付き状態は6個、全て満たせば粒子数6である。二重にgを掛けると同じ6状態を12状態と数える誤りになる。

再挑戦

縮退度g=4を持つ準位を、(i)代表準位として一回計算する場合、(ii)4個のラベル付き状態を列挙する場合で、Nの式を二通り書け。

E8

完全解答

各反復で

assert T > 0
G = sum(g)
assert 0 < N_target < G
N(mu) = sum(g[i] * fermi_dirac(E[i], mu, T) for i)
lo = min(E) - 50*kB*T
hi = max(E) + 50*kB*T
assert N(lo) <= N_target <= N(hi)
repeat up to max_iter:
    mid = (lo + hi)/2
    residual = N(mid) - N_target
    if abs(residual) < tol: return mid, residual
    if residual < 0: lo = mid
    else: hi = mid
return mid, residual, status="not_converged"

μを増やすと各f_iが増えるのでNも単調増加する。したがってNが目標より小さい側をlo、大きい側をhiに置く。初期区間は準位の外側まで十分広くし、端点で目標を挟めなければ「準位打ち切りまたはN_target不可能」と診断する。N_target=0とN_target=Gは有限μの解ではなく、それぞれmu_boundary_minus_infinity、mu_boundary_plus_infinityとして扱う。T=0で準位間にあるμは非一意なので、採用方針（区間中央など）をstatusとともに保存する。実装では単位をそろえ、探索範囲、tol、反復数、statusをartifactに保存する。

再挑戦

E=[0,0.1] eV、g=[2,2]、T=300 K、N_target=2で、μ=0.05 eVが解になることをN(μ)の式に代入して確認し、その周りのlo/hi更新を2回だけ手計算せよ。

E9

完全解答

(a) T=−1 Kは熱力学的な入力範囲外なのでinvalid_temperature。T=0を扱うなら専用の極限分岐にする。(b) g=0は本章の準位表では状態の縮退がないためinvalid_degeneracyとし、空の状態は行自体を除外する。負なら必ず拒否する。(c) JとeVを混ぜると指数が次元を持ち、unit_mismatch。全てJまたは全てeVに換算する。(d) exp(10^6)はoverflowするのでexponent_overflow。x>0ではexp(-x)/(1+exp(-x))、x<0では1/(1+exp(x))のように小さい指数を使う。(e) N_targetがsum(g)を超えるならparticle_count_out_of_range。準位追加、粒子数修正、または模型の不足を報告する。(f) T>0でN_target=0は有限μの解がなく、mu_boundary_minus_infinityとして境界状態を保存する。N_target=sum(g)はmu_boundary_plus_infinityとする。NaNもnonfinite_inputとして拒否する。

再挑戦

E=1 J, μ=0 eV, T=300 Kをそのまま計算したとき何が壊れるかを指数の単位で説明し、1 JをeVへ換算した後の入力例を書け。

E10

完全解答

(i) |ψ(x)|²は一粒子が位置xで見つかる確率密度であり、領域積分が1になるよう規格化する。f(E)は、熱平衡でエネルギーEの一粒子状態が占有される平均で、各状態について0から1の値を取る。(ii) |ψ|²の入力は波動関数と位置、fの入力はE、μ、T、kBである。(iii) |ψ|²は位置の関数で局所的には1を超えることもあり得るが、積分全体が1。fはPauli制約により一状態あたり0から1。量子井戸のn=1とn=2では、それぞれの|ψ_n(x)|²の節や形を決める固有関数と、何個の電子が各準位にいるかを決めるf_nは別物である。n=1の波動関数が大きいから電子が必ず多い、とは言えない。

再挑戦

同じn=1について、|ψ_1(x)|²を2倍して規格化を壊す例と、g=2を掛けて平均粒子数を計算する例を並べ、なぜ前者だけが誤りかを説明せよ。

E11

完全解答

最低限、artifact_id、status、source_kind、measured、inputs（E_i, g_i, T, μまたはN_target, 単位）、equation_ids、predicted（f_i, N, residual）、diagnostics、runner_versionまたはrunner_commit、created_atを持たせる。解析式から先に得た値はsource_kind="analytic_prediction"、runnerが実行した値はsource_kind="runner_output"とする。実測をしていない段階でmeasured:trueにすると、計算予測を装置の測定値と誤認させ、誤差・校正・再現性の確認を飛ばしてしまう。共通runnerでは入力由来の契約モデルを実行済みだが、Fermi分布の完全な外部計算・実在試料の測定は行っていない。したがってレコードはstatus="executed_analytic"、source_kind="runner_analytic_contract"、measurement.status="not_run"として保存する。

再挑戦

同じレコードへmeasuredを追加し、(i)解析予測のみ、(ii)runner出力あり、(iii)実測あり、の3例でどの値と注記が変わるべきかを表にせよ。

E12

完全解答

第16章では、結晶の周期性によって一粒子準位が波数kで並び、離散的な準位の集まりがバンドとして扱われる。そこで各kの状態数と縮退を数え、Fermi–Dirac占有率とμから電子数を求める。本章から渡せるのは、一粒子準位、状態数、μ、占有率、そして占有が低いときの古典極限という枠組みである。第17章では伝導帯・価電子帯を電子と正孔の状態として数え、電荷中性やドーピングを含む粒子数条件を解く。ただしバンド構造、相互作用、有効質量、非平衡輸送は追加モデルであり、本章の二準位式から自動的には決まらない。

再挑戦

同じ橋渡しを100字以内に圧縮し、逆に「本章の結果だけでは決められないもの」を二つ含めよ。短くしても五つの重要語の関係が崩れていないか確認する。

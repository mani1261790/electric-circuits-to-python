第8章 演習解答　物質の導電性と古典モデル

E1　電流密度と面積

完全解答

面に垂直なら、面積ベクトルとJの内積はJAなので、

I = JA
  = (3.0×10^4 A/m²)(2.0×10^-6 m²)
  = 6.0×10^-2 A

である。単位は(A/m²)m²=Aとなる。法線との角度が60°なら、

I = JA cos 60° = (6.0×10^-2)(0.5) = 3.0×10^-2 A

となる。面を反対向きに指定すれば面積ベクトルが反転し、電流の符号も反転する。電流の大きさだけを求める場合でも、法線の向きは記録する。

再挑戦

J=8.0×10^3 A/m²、A=5.0×10^-6 m²、角度120°へ変える。I=8.0×10^3×5.0×10^-6×cos120°=-2.0×10^-2 A。負号は、指定した法線に対して流れが反対向きであることを表す。

E2　電子の向きと慣用電流

完全解答

電子の電荷は-eなので、正の電場+xに対するドリフト速度は

v_d,e = -μ_e E

であり、-x方向である。電子による電流密度は

J_e = n_e(-e)v_d,e = n_e e μ_e E

となるので、+x方向である。負電荷が負方向へ運ばれるため、慣用電流は正方向へ流れる。電場を-xへ反転すると、電子の速度は+x、電流密度は-xへ反転する。この結果は、正の導電率を使うJ=σEとも一致する。電子の矢印と電流の矢印を同じ向きに描くのが故障の典型である。

再挑戦

正孔だけを担体とする模型へ変更する。正孔ではv_d,h=+μ_hE、J_h=p e μ_hEなので、速度も電流も電場と同じ向きになる。電子の場合と同じJの向きでも、担体速度の説明は反対になる。

E3　二種類の担体から導電率を計算する

完全解答

電子項と正孔項を分けると、

n_e μ_e = (2.0×10^25)(4.0×10^-3) = 8.0×10^22
p μ_h   = (1.0×10^21)(2.0×10^-4) = 2.0×10^17

である。したがって、

σ = e(n_e μ_e+p μ_h)
  = (1.602176634×10^-19)(8.00002×10^22)
  ≈ 1.2817×10^4 S/m

となる。E=0.50 V/mでは、

J = σE ≈ (1.2817×10^4)(0.50)
  ≈ 6.4087×10^3 A/m²

である。電子項は正孔項の8.0×10^22/(2.0×10^17)=4.0×10^5倍なので、この指定値では電子が支配的である。支配的という判断は、密度と移動度を指定したこの状態に限る。

再挑戦

n_e=1.0×10^20 m^-3、p=2.0×10^22 m^-3へ変える。電子項は4.0×10^17、正孔項は4.0×10^18なので、正孔項が10倍大きい。σ=e(4.4×10^18)≈0.705 S/m、E=0.50 V/mではJ≈0.353 A/m²となる。

E4　緩和時間と移動度

完全解答

移動度の大きさは、

μ = eτ/m*
  = (1.602176634×10^-19 C)(2.0×10^-14 s)/(9.11×10^-31 kg)
  ≈ 3.52×10^-3 m²/(V s)

である。電子は電場と逆向きへ動くので、E=100 V/mでは、

v_d,e = -μE ≈ -(3.52×10^-3)(100)
       ≈ -0.352 m/s

（-x方向）となる。緩和時間以外を固定してτを2倍にすれば、μとドリフト速度の大きさが2倍になり、式(8.7)の導電率も2倍になる。実材料では散乱機構や分布が変わるため、τを独立に2倍できるとは限らない。

再挑戦

m*を2倍、τを半分にする。τ/m*は元の1/4なので、移動度、速度の大きさ、単一担体の導電率は元の1/4になる。数値だけでなく比を先に見ると、計算ミスを検出できる。

E5　同じ電場で材料を比べる

完全解答

J=σE、I=JAを各行へ適用する。

試料JI
銅(5.8×10^7)(2.0)=1.16×10^8 A/m²1.16×10^8×5.0×10^-9=5.8×10^-1 A
ガラス模型2.0×10^-12 A/m²1.0×10^-20 A
シリコン模型5.8×10^-4 A/m²2.9×10^-12 A

銅とガラス模型の比は5.8×10^7/1.0×10^-12=5.8×10^19、シリコン模型とガラス模型の比は2.9×10^-4/1.0×10^-12=2.9×10^8である。同じ電場、同じ断面積だから、電流の比は導電率の比に等しい。三つのσはこの問で指定された代表値・計算用模型であり、runnerや装置で測った値ではない。ガラスとシリコンは条件を明記しない一つの普遍値にできない。

再挑戦

電場を-2.0 V/mへ反転する。三つのJとIはすべて符号反転し、大きさは同じである。試料内部の抵抗をR_bulk=L/(σA)で定義するなら、正のσに対するR_bulkは正のまま変わらない。

E6　導電率から線材抵抗へ

完全解答

電場は、

E = ΔV/L = 0.020/0.20 = 0.10 V/m

である。抵抗は、

R_bulk = L/(σA)
  = 0.20 / ((5.0×10^6)(2.0×10^-6))
  = 0.020 Ω

となる。したがって、

I = ΔV/R_bulk = 0.020/0.020 = 1.0 A

である。L'=2L、A'=A/2では、

R'_bulk = (2L)/(σ(A/2)) = 4R_bulk = 0.080 Ω

となる。長さの効果で2倍、断面積を半分にした効果でさらに2倍である。σAの単位を単独でS/mと決めず、R全体の単位がΩになることを確認する。

再挑戦

L=0.10 m、A=4.0×10^-6 m²、σ=5.0×10^6 S/mへ変える。R=0.005 Ω、ΔV=0.020 VならI=4.0 A。元の線材と比べて長さ半分、面積2倍なので抵抗は1/4である。

E7　抵抗率、電力、温度

完全解答

まず、

R_bulk = ρL/A
  = (2.0×10^-8)(0.50)/(1.0×10^-6)
  = 1.0×10^-2 Ω

である。よって、

I = ΔV/R_bulk = 0.10/0.010 = 10 A
P = ΔV I = 0.10×10 = 1.0 W

となる。抵抗率が20%増えてρ'=1.2ρになり、寸法を固定するならR'_bulk=1.2R_bulk=0.012 Ω。電圧を固定したとき、

I' = 0.10/0.012 ≈ 8.33 A
P' = (0.10)^2/0.012 ≈ 0.833 W

である。これは温度を外から指定し、温度上昇によるさらなる変化を無視した比較である。実際には発熱Pが温度を変え、その温度がρを変えるため、熱の方程式を加える必要がある。

再挑戦

電流を10 Aに固定する条件へ変える。R'_bulk=0.012 Ωなら電圧はV'=I R'_bulk=0.12 V、電力はP'=I²R'_bulk=1.2 Wとなる。電圧固定と電流固定では、抵抗変化に対する電力の変化が異なる。

E8　金属・絶縁体・半導体を条件付きで説明する

完全解答

銅は金属なので、主な担体を移動可能な電子として扱う。担体密度が大きく、移動度は格子振動、欠陥、温度で変わる。通常の範囲ではJ=σEが便利だが、発熱による温度上昇、強電場、高周波、接触支配を含めると一定σは崩れ得る。

乾燥したガラスは、指定した直流・温度・時間では自由に試料を通過する担体が少ない絶縁体の模型である。組成、アルカリイオン、水分、表面汚染、温度、印加時間、周波数で見かけの導電率は変わる。したがって「ガラスには電荷がない」は誤りで、電荷は存在し、分極やイオン移動も起こり得るが、金属と同じ担体模型を使えないという意味である。

ドープしたシリコンでは、電子と正孔の密度、移動度、温度、不純物濃度、光を指定する。少量の不純物でも担体密度が大きく変わるため、シリコンの導電率は広い範囲を取り得る。「シリコンは常に銅より低い」も条件なしには正しくない。強くドープしたシリコン、薄膜、温度や周波数を変えた測定では、比較の結果が変わり得る。

再挑戦

湿ったガラス表面を電極で測るケースを追加する。バルクの乾燥ガラスのσだけでなく、表面の薄い水分層、電極接触、時間依存のイオン移動を別の経路として記録する。単一のR_bulk=L/(σA)へすぐ縮約できない理由を三つ挙げられればよい。

E9　予定コードへ入力検査を追加する

完全解答

仕様は、length_m>0、area_m2>0、conductivity_s_per_m>=0を受理条件とする。σ=0ではJ=0、I=0、抵抗は無限大という状態にし、有限値の計算結果と分ける。例えば次の表を作る。

ケース入力期待状態理由
正常L=.1,A=1e-8,V=.1,σ=1e6ok、E=1、J=1e6単位と正値が成立
長さゼロL=0error電場と抵抗の分母が0
面積ゼロA=0error電流断面が定義できず、抵抗式の分母が0
負の導電率σ=-1error受動的な今回の導電率の範囲外
絶縁極限σ=0okだがresistance=inf有限浮動小数点の抵抗と区別
単位故障A=2（cm²のつもり）unit_errorまたは警告m²へ変換されていない

コードでは、長さと面積を最初に検査し、導電率の負値を拒否する。0の場合は通常のL/(σA)を評価せず、状態をinfinite_resistanceなどと記録する。入力を黙って絶対値へ直すと、符号や入力ミスを隠すので避ける。

再挑戦

移動度からσ=e(n_eμ_e+pμ_h)を計算する経路を追加する。n_e、p、μ_e、μ_hが負ならエラー、全て0ならσ=0、Eの負値は正常な極性変更とする。導電率計算のエラーと電圧極性の変更を同じエラーコードにしない。

E10　単位混同と符号の故障を診断する

完全解答

面積は、

2.0 cm² = 2.0×10^-4 m²

である。E=ΔV/L=1.0 V/m、J=σE=1.0×10^6 A/m²なので、正しい電流は

I_correct = (1.0×10^6)(2.0×10^-4) = 2.0×10^2 A

である。コードが2.0 m²と解釈すると、

I_bug = (1.0×10^6)(2.0) = 2.0×10^6 A

となり、正しい値の10^4倍である。cm²からm²へは長さの換算を二乗する必要があるため、10^2倍ではなく10^4倍の差になる。

ΔV=-0.10 VならE=-1.0 V/m、J=-1.0×10^6 A/m²、I=-2.0×10^2 Aとなる。一方、抵抗は

R_bulk = 0.10 / ((1.0×10^6)(2.0×10^-4)) = 5.0×10^-4 Ω

であり、導電率と寸法を変えない限り正のままである。ここではV=RIも(-0.10)=(5.0×10^-4)(-200)として成立する。

再挑戦

バグがA=2.0×10^-8 m²（2.0 mm²をcm²と誤認）だった場合を調べる。正しい2.0 cm²に対して面積が10^-4倍なので、計算電流は正しい値の10^-4倍、すなわち0.020 Aになる。単位名だけでなく、変換後の数値と基準面積をartifactへ保存する。

E11　予測・資料値・実測値を分けるartifact

完全解答

最小のCSVなら、例えば次の列を置く。

material,source_kind,sigma_S_per_m,L_m,A_m2,deltaV_V,E_V_per_m,J_A_per_m2,I_A,R_ohm,status,measured,environment,equation_ids

銅の計算用代表値の行は、

copper,calculation_assumption,5.8e7,0.10,1.0e-8,0.10,1.0,5.8e7,5.8e-1,1.724e-1,predicted,false,fixed-linux-planned,"conductivity_constitutive;resistance_geometry;ohms_law"

のようになる。実測を追加する場合は、source_kind=measurement、status=measured、計器、温度、校正、日時、許容誤差などを追加し、予測行を上書きしない。資料値、モデルの仮定、runnerが算出した予測、装置の実測は、不確かさと再現手順が違うからである。一つの値欄を更新すると、後から「表の値はいつ、どの経路で得たか」を判別できなくなる。

図のデータにもmeasured:falseとstatus:predictedを付け、domain adapter未導入の空欄を0と解釈しない。equation_idsは式レジストリとの機械的な照合に使う。

再挑戦

JSONLへ変更するなら、数値単位をキーに埋め込むか、valuesとunitsを分離する。例えば{"material":"copper","values":{"sigma":5.8e7,"L":0.1},"units":{"sigma":"S/m","L":"m"},"status":"predicted","measured":false}のようにし、温度を未指定のまま「室温」と書かない。条件がない値はmissingとして扱う。

E12　次章へ引き渡す条件を説明する

完全解答

R_bulk=L/(σA)を回路図の抵抗へ置く条件として、次を挙げられる。

  1. 物質と温度が区間内でほぼ一様で、σを一つの値にできる。
  2. 断面積が電流方向に急変せず、断面内のJを一様と近似できる。
  3. 端面・接点の電場の乱れと接触抵抗を、別の抵抗または誤差として分離できる。
  4. 定常または準静的で、容量性電流や誘導を今回の抵抗電流から分けられる。
  5. 電場が線材全体でほぼ同時に定まるほど、寸法と波形の時間尺度が小さい。
  6. 発熱、担体の生成・再結合、強電場による非線形性が無視できる。

(a)では、信号の立上り時間が長さ方向の電磁的な伝搬時間と同程度なら、線材を一つのRだけへ置けない。分布したインダクタンス・容量、反射、伝送を第9章で調べる。(b)では、細い部分と接続部でJと電場が偏るため、区間別の抵抗や二次元・三次元の場を検討する。(c)では、P=I²Rが温度を上げ、σ(T)と抵抗が変わるので、電気と熱を連成させる。(d)では、ガラスの表面水分、イオン移動、電極接触、周波数依存、容量性応答を疑い、乾燥バルクのσをそのまま使わない。

したがって、抵抗近似の可否は名前ではなく、隠した変数が観測へ影響しないかで判断する。まずL、A、σ、温度、周波数、接触、波形を記録し、次に一つの集中定数で許容誤差に収まるかを検査する。

再挑戦

長さL=1 cmの銅線に、立上り時間1 nsの信号を加えるケースを追加する。自由空間の光速だけで断定せず、伝搬速度、線材の誘電環境、立上り時間、許容誤差を指定する。伝搬遅延が許容誤差に対して無視できないなら、第9章の分布定数模型へ引き渡す。

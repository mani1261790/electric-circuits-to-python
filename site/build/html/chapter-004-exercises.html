第4章　演習

数値を出すだけでなく、どのモデル、どの時間軸、どの単位、どの観測経路を使ったかを書く。実験問題では、domain adapterが未導入または実行できない場合、その状態を成功に置き換えない。変更課題と故障診断には、段階的ヒント、完全解答、別条件の再挑戦を用意した。

E1　四つの結果を分類する

次の記述を「解析解」「数値解」「SPICE」「測定」のいずれかに分類し、根拠を一つ書け。

  1. V_s + (V_0-V_s) exp(-t/(RC))を連続時刻で評価した。
  2. V_(n+1)=V_n+Δt(V_s-V_n)/(RC)を配列へ保存した。
  3. 部品モデルとnetlistを回路ソルバへ渡し、節点電圧を得た。
  4. プローブを回路へ接続し、オシロスコープのサンプル列をCSVへ保存した。
ヒント
  • ヒント1: 式を解いたもの、有限刻みの更新、回路モデルを解くもの、計器を通るものを分ける。
  • ヒント2: 数値解とSPICEはいずれも計算だが、入力表現と隠れたソルバ設定が異なる。
  • ヒント3: 測定ではプローブとADC/オシロスコープが対象へ接続される。

E2　理想RCの解析解を導く

R=1 kΩ、C=1 μF、V_s=5 V、V_C(0)=0 Vの理想RC充電について、

  1. 抵抗電流とコンデンサ電流から微分方程式を導け。
  2. 時定数τを求め、単位を確認せよ。
  3. t=τの電圧を小数第2位程度まで求めよ。
  4. この解を使えない条件を二つ挙げよ。
ヒント
  • ヒント1: (V_s-V_C)/R=C dV_C/dt。
  • ヒント2: 1 kΩ×1 μF=1 ms。
  • ヒント3: 1-exp(-1)≈0.632。

E3　変更課題：Euler法の一歩

E2と同じ回路でV_0=0 V、Δt=0.2 msとする。

  1. Euler法でV_1を求めよ。
  2. Δt=2 msへ変えたときのV_1を求め、理想解の範囲0≤V_C≤V_sを確認せよ。
  3. Pythonコードへ入力する場合、秒とミリ秒をどのように統一するか書け。
ヒント
  • ヒント1: V_1=V_0+(Δt/τ)(V_s-V_0)。
  • ヒント2: 0.2 ms/1 ms=0.2、2 ms/1 ms=2。
  • ヒント3: 数値の変換だけでなく、変数名へ単位を含める。

E4　Euler法とRK4を比較する

V_s=1 V、τ=1 s、V_0=0 Vの一次方程式を、0≤t≤1 sで計算する。

  1. Euler法とRK4をΔt=0.2 sで実装する。
  2. t=1 sで解析解との差を表にせよ。
  3. Δt=0.1 s、0.05 sでも繰り返し、誤差の減り方を比較せよ。
  4. 誤差が減ったことから、測定値の誤差も同じ割合で減ったと結論してよいか。
ヒント
  • ヒント1: f(t,V)=(1 V - V)/(1 s)を使う。fの単位はV/sである。
  • ヒント2: RK4ではk1からk4を同じ単位V/sで計算する。
  • ヒント3: 最後の問いでは、計算誤差と測定・モデル誤差を分ける。

E5　故障診断：Euler法の安定性

e_(n+1)=(1-Δt/τ)e_nを使う。

  1. Δt/τ=0.5, 1.5, 2.0, 2.5について倍率を求めよ。
  2. どの条件で絶対値が増えるか。
  3. Δtを小さくし続ける計算が、丸め誤差や計算時間の点で不利になり得る理由を書け。
ヒント
  • ヒント1: 安定性の目安は倍率の絶対値が1未満。
  • ヒント2: 1-Δt/τの符号は、単調か交互かを示す。
  • ヒント3: 安定性、打切り誤差、丸め誤差は違う欄へ書く。

E6　変更課題：入力抵抗による測定器負荷

回路の抵抗をR=1 MΩ、容量をC=1 μFとし、測定器の入力抵抗をR_in=10 MΩとする。信号源抵抗は無視する。

  1. RとR_inの並列合成抵抗を求めよ。
  2. 負荷を接続した時定数と、無負荷の時定数を比較せよ。
  3. R_inが「十分大きい」と呼べるかどうかを、許容する時定数変化を決めて判断せよ。
ヒント
  • ヒント1: R||R_in=RR_in/(R+R_in)。
  • ヒント2: コンデンサから見た抵抗が変わる。
  • ヒント3: 十分大きいかは絶対値ではなく、対象抵抗との比と許容幅で決める。

E7　帯域とサンプリングを分類する

次の記述を「正しい」「条件付き」「誤り」に分類し、必要な条件を書く。

  1. サンプリング周波数が最高周波数の2倍なら、どんな信号でも復元できる。
  2. 測定器の帯域が対象の立上り時間より十分速ければ、帯域の影響は小さくできる。
  3. 立上りの急なステップは有限帯域・有限サンプリングで完全に記録できる。
  4. 測定窓を短くすると、時間分解能と周波数分解能が同時に無限によくなる。
ヒント
  • ヒント1: 帯域制限、aliasing、窓長を思い出す。
  • ヒント2: ステップには高周波成分が含まれる。
  • ヒント3: 時間と周波数の分解能にはトレードオフがある。

E8　量子化誤差と飽和

測定レンジを-1 Vから+1 V、ADCを8 bitとする。

  1. 量子化幅の目安を求めよ。
  2. 入力が1.2 Vのとき、量子化誤差だけで説明できるか。
  3. 量子化誤差を一様ノイズと近似できない状況を二つ挙げよ。
ヒント
  • ヒント1: レンジ幅は2 V、コード数は2^8。
  • ヒント2: 表示範囲を超える入力は飽和または範囲外である。
  • ヒント3: 飽和、強い相関、コード境界への固定、低信号を考える。

E9　パラメータ不確かさを伝える

R=1 kΩの相対不確かさが2%、C=1 μFが5%、独立と仮定する。

  1. 式(4.9)でτの相対不確かさを見積もれ。
  2. τ=1 msなら絶対不確かさの目安はいくらか。
  3. 温度でRとCが同じ方向に変化する場合、この計算をそのまま使えるか。
ヒント
  • ヒント1: sqrt(0.02^2+0.05^2)。
  • ヒント2: 相対値へ1 msを掛ける。
  • ヒント3: 式は独立性と小さな変化を仮定している。

E10　artifactを設計する

章本文のrc-comparison/v1を参考に、次の条件を満たすYAMLまたはJSONの設計を作れ。

  1. 入力条件と単位がある。
  2. 解析、Euler、RK4、SPICE、測定を区別する。
  3. 予測、実測、失敗、未実装を区別する。
  4. コマンド、環境、版、成果物の場所が残る。
ヒント
  • ヒント1: run、input、methods、outputs、provenanceを分ける。
  • ヒント2: ファイルが存在するだけで実測済みとは限らないのでstatusを置く。
  • ヒント3: 単位付きキーか、単位を別フィールドで必ず保存する。

E11　故障診断：入力波形を取り違える

実測した電圧源は0 Vから5 Vまで0.2 msで上がっている。しかし解析側では時刻0で瞬時に5 Vになる理想ステップを使っている。

  1. どの差を数値誤差と呼んではいけないか。
  2. 解析側を実測入力へ近づける方法を一つ書け。
  3. それでも差が残る場合の仮説を二つ挙げよ。
ヒント
  • ヒント1: 入力条件が違えば、同じ微分方程式でも別の問題になる。
  • ヒント2: 測定入力を時刻軸へ補間し、その入力をモデルへ与える。
  • ヒント3: 部品値、出力抵抗、プローブ負荷、帯域、ノイズを分ける。

E12　統合判断

Euler法、RK4、SPICE、測定の4本の波形があり、RK4とSPICEは重なるが測定値だけ時定数が10%大きい。次の問いに答えよ。

  1. 直ちに「測定が間違い」と断定できるか。
  2. 調べる順番を三段階で提案せよ。
  3. どの追加artifactがあれば、他の人が判断を再現しやすいか。
ヒント
  • ヒント1: 計算解の一致は、理想モデル内の整合性を示すだけ。
  • ヒント2: 入力波形、部品値・温度、プローブ負荷・帯域を候補にする。
  • ヒント3: raw input、probe settings、netlist、versions、failure logを挙げる。

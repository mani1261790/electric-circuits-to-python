第6章 演習解答　電位、電圧、エネルギー

E1　仕事と電位差の単位

完全解答

q=3.0 μC=3.0×10^-6 C、E=200 N/C、d=0.40 mである。電気力はF=qE=6.0×10^-4 N。力と移動が同じ向きなので、電場がした仕事は

W_field = qEd
         = (3.0×10^-6 C)(200 N/C)(0.40 m)
         = 2.4×10^-4 J

位置エネルギーの変化はΔU=-W_field=-2.4×10^-4 J、電位差は

V(b)-V(a) = ΔU/q = -Ed = -80 V

である。W_fieldとΔUはJ、電位差はJ/C=V。正電荷が電場の向きへ進むと、電場が正の仕事をし、位置エネルギーと電位が下がる。

再挑戦

q=-3.0 μCを同じ向きへ運ぶ。電場の仕事は-2.4×10^-4 J、位置エネルギーの変化は+2.4×10^-4 Jになるが、電位差そのものは経路と電場で決まり-80 Vのままである。電荷の符号が、力とエネルギーの変化を反転させることを確認する。

E2　一様電場の積分と経路の向き

完全解答

z_a=0.20 m、z_b=0.80 m、E_z=1.5×10^3 V/mである。aからbへはdℓ=(0,0,dz)なので、

V(b)-V(a) = -∫_0.20^0.80 1.5×10^3 dz
           = -(1.5×10^3)(0.60)
           = -9.0×10^2 V

である。bからaへ戻る積分ではV(a)-V(b)=+900 V。電場が+zを向くので、+zへ移動した正電荷は電場から正の仕事を受け、電位は下がる。

再挑戦

電場をE_z=-800 V/m、同じ始点・終点に変更する。今度はV(b)-V(a)=+480 V。電場が-zを向くので、上へ進むと電位が増える。場の矢印と積分の向きを図にして確認する。

E3　点電荷の電位と基準

完全解答

無限遠基準では

V(r) = kQ/r
     = (8.9875517923×10^9)(-2.0×10^-9)/0.25
     ≈ -71.9004 V

である。基準を一律に+10 V移すと、観測点の電位は-61.9004 V、無限遠の電位は+10 Vになる。二点間の差は

(-61.9004) - (+10) = -71.9004 V

で変わらない。基準移動は電位へ同じ定数を足す操作であり、電場の勾配と電位差を変えない。

再挑戦

基準をr=0.50 mの点で0 Vとする。点電荷からr=0.25 mとr=1.0 mの二点の電位差を、無限遠基準へ戻さずに計算する。共通定数が消え、差はkQ(1/0.25-1/1.0)≈-53.9253 Vとなる。

E4　電位・電場・位置エネルギーを区別する

完全解答

電位はV=12 Vなので、

U_1 = (+2.0×10^-6 C)(12 V) = +2.4×10^-5 J
U_2 = (-2.0×10^-6 C)(12 V) = -2.4×10^-5 J

である。電場E=(0,-300,0) N/Cから、

F_1 = q_1 E = (0,-6.0×10^-4,0) N
F_2 = q_2 E = (0,+6.0×10^-4,0) N

となる。電位は単位電荷あたりの位置エネルギーを表すスカラーで、基準を変えると一律に変わる。電場は単位電荷あたりの力を表すベクトルで、位置ごとの向きを持ち、電位の勾配から得る。電位と電場、電位と電荷の積を同じ量として扱わない。

再挑戦

同じ点の電位基準を+5 V移す。U_1は3.4×10^-5 J、U_2は-3.4×10^-5 Jへ変わるが、電場と各電荷の力は変わらない。単一粒子のU=qVは基準に依存し得る一方、同じ電荷を二点間で運ぶエネルギー差は不変であることを説明する。

E5　等電位面を読む

完全解答

∇V = (∂V/∂x, ∂V/∂y, ∂V/∂z) = (4.0,-3.0,0) V/m
E = -∇V = (-4.0,+3.0,0) V/m

である。V=6.0 Vの等電位線は

4.0x - 3.0y = 6.0

となる。線に沿う移動ではdV=0なので、静電場がした仕事はW_field=q∫E·dℓ=0。また、等電位線の接線方向(3,4)と電場(-4,3)の内積は-12+12=0で、直交も確認できる。

再挑戦

V(x,y)=2x²+yへ変更する。電場はE=(-4x,-1)、V=3 Vの等電位線は2x²+y=3。任意の点で、等電位線の接線ベクトルと電場の内積が0になることを、暗黙微分で確認する。

E6　導体表面の境界条件

完全解答

静電平衡の理想導体内部では

E_in,n = 0

である。境界条件より

E_out,n = σ/ε0
         = (5.0×10^-9 C/m²)/(8.8541878188×10^-12 F/m)
         ≈ 5.65×10^2 N/C

で、正の外向き法線を取れば正の値となる。内部に電場があれば自由電荷へqEの力が働き続け、静電平衡にならない。したがって内部E=0、E=-∇Vから連結した導体の電位は一定になる。表面の接線方向電場も0でなければ表面電荷が動くので、外側の場は法線方向になる。

再挑戦

σ=-5.0 nC/m²へ変える。外側法線成分は-5.65×10^2 N/C、大きさは同じで、電場は導体表面へ向かう。導体内部は依然として0だが、これは静電平衡という条件を保った場合だけである。

E7　平行板の静電容量と適用範囲

完全解答

A=2.0×10^-2 m²、d=5.0×10^-4 mなので、

C = ε0 A/d
  = (8.8541878188×10^-12)(2.0×10^-2)/(5.0×10^-4)
  ≈ 3.54168×10^-10 F

である。ΔV=10 Vを加えた極板電荷の大きさは

|Q| = C|ΔV| ≈ 3.54168×10^-9 C

となる。式の成立には、板が十分広い、板間隔が板の寸法より小さい、真空が一様、線形応答、漏れと端効果を無視する、といった条件がある。有限板の端ではフリンジ電場が生じる。誘電体が不均一または非線形、電圧が絶縁破壊を起こす、周波数が高く分布効果が無視できない、といった場合も同じ式をそのまま使えない。

再挑戦

板間を相対誘電率ε_r=4の一様な線形材料で満たす。理想模型ではCとQは4倍になるが、材料の損失、分極の周波数依存、空隙、破壊電界を無視した予測であると明記する。

E8　充電仕事と三つのエネルギー式

完全解答

C=4.0 μF=4.0×10^-6 F、V=6.0 Vより、

Q = CV = (4.0×10^-6)(6.0) = 2.4×10^-5 C

である。線形コンデンサの途中の電圧はV(q)=q/Cだから、

U = ∫_0^Q (q/C)dq = Q²/(2C) = 7.2×10^-5 J

また、

1/2 CV² = 1/2(4.0×10^-6)(6.0)² = 7.2×10^-5 J

で一致する。QV=1.44×10^-4 Jは最終電圧6 Vを、最初の電荷から最後まで一定とみなした値である。実際の充電では電圧が0から6 Vへ変化するため、平均電圧は3 Vとなり、積分結果はQV/2。

再挑戦

初期電圧V_i=2 VのコンデンサをV_f=6 Vまで充電する。線形コンデンサで増えた蓄積エネルギーは1/2 C(V_f²-V_i²)=6.4×10^-5 J。電源の供給エネルギーは経路が指定されなければ同じとは言えず、抵抗と電源の模型を別に記録する。

E9　電圧計の基準端子と負荷

完全解答

接続前は開放端子なのでR_sに電流が流れず、出力端子電圧は5.0 V。電圧計を接続すると、R_s=100 kΩとR_in=1.0 MΩの分圧になる。

V_out = V_s R_in/(R_s+R_in)
      = 5.0×(1.0 MΩ)/(0.10 MΩ+1.0 MΩ)
      ≈ 4.545 V

赤リードを出力、黒リードを基準へつないだ表示を+4.545 Vとする規約なら、赤黒を逆にした場合の表示は-4.545 V。計器の入力抵抗が有限なので、測定器をつないだことで対象の出力電圧が5 Vから下がった。

再挑戦

R_in=10 MΩへ変更するとV_out=5.0×10/10.1≈4.9505 V。入力抵抗を大きくするほど理想電圧計に近づくが、高速波形では入力容量と帯域を別に確認する必要がある。

E10　平行板の数値差分を実装する

完全解答

提示コードは、区間数Nに対してdz=d/Nを置き、V(z)を境界値の一次補間で作り、内部点に中心差分を使っている。中心差分の式は

E_i = -(V_{i+1}-V_{i-1})/(2 dz)

で、解析値は

E_exact = -(V_top-V_bottom)/d

である。V(z)が厳密な一次関数なので、十分な浮動小数点精度では内部点の差分は解析値とほぼ一致する。N=10,100,1000を試し、例えば次の検査を追加する。

expected = -(V_top - V_bottom) / d
error = max(abs(value - expected) for value in Ez)
print(N, error)

端点では片側差分または境界条件の扱いが必要で、中心差分はi-1とi+1の両方を要求するため内部点だけを計算した。dzがm、VがVなのでEzはV/mとなる。

再挑戦

電位をV(z)=V_bottom+(V_top-V_bottom)(z/d)^2へ変更し、中心差分を解析電場-2(V_top-V_bottom)z/d²と比較する。Nを増やすと誤差が減るが、端点では誤差の次数が変わり得る。関数の入力がN<=0、d<=0を拒否するテストも追加する。

E11　符号反転の故障を診断する

完全解答

下板z=0が0 V、上板z=dが5 Vなら、板間の解析電場は

E_z = -(V_top-V_bottom)/d = -5000 V/m

である。+5000 V/mが出た原因として、(1)E=-dV/dzの負号を落とした、(2)座標を上板から下板へ定義しているのに表示軸を反転していない、(3)V_topとV_bottomをコード内で逆にした、が考えられる。

さらに、Q_topの負号は、上板の内側面に対する外向き法線を間違えた可能性がある。板間の電場は-z向きだが、上板の板間側の外向き法線も-zなので、E·nは正であり、上板は正電荷になる。単に+zの面法線でQ=εA E_nを計算すると、下向き電場を負として表示してしまう。

切り分けでは、まずV(z)を表に出して境界が0→5 Vかを確認する。次に-(V[i+1]-V[i-1])/(2dz)と+(...)を同じ入力で比較し、負号のテストを行う。最後に上板・下板それぞれの局所法線を明示し、法線を反転したときだけ電束の符号が反転することを確認する。値が正負だけ反転し、大きさが解析値なら規約のバグ、傾きの大きさまで違えば単位・d・格子のバグを疑う。

再挑戦

V_top=-5 V、V_bottom=0 Vに変更し、電場と極板電荷の物理的な符号が反転することをテストする。ただし、板面の法線は電位とは独立に固定し、法線反転による符号反転と、電源極性反転による物理場の反転を別のテストとして記録する。

E13　電圧から電流へ橋をかける

完全解答

「電池の5 Vが導線の中を流れる」のではない。5 Vは電池の二端子間で、単位電荷あたり5 J/Cのエネルギー差を表す。電池と導線、負荷の境界条件に応じて電場が生じ、導体中の電荷担体へF=qEの力が働く。単位時間あたりに断面を通過する電荷を電流I、局所的な面積あたりを電流密度Jとして数える。IとJの厳密な定義、連続の式、電力は次章で導出する未習の量である。

低周波で回路の寸法が信号の波長と伝搬時間に比べて十分小さく、配線を理想導線に近似できる場合は、空間の電磁場を節点電圧と枝電流へ縮約する集中定数回路を使える。長い配線、高速な立上り、反射、分布容量を無視できない場合は伝送線路など別の模型が必要である。電池の化学的な起電力、電場、電荷の平均移動、回路の電流を一つの「流れる電圧」にまとめない。

再挑戦

低速なLED回路と、数mの高速デジタル配線を比較して書く。前者では負荷の端子電圧と電流を集中定数で近似する条件を列挙し、後者では配線長、立上り時間、反射、入力容量を追加の変数として記録する。まだ測っていない時間を、電子のドリフト速度だけから断定しない。

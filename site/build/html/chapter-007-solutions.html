第7章 演習解答　電流、連続の式、電力

E1　電流の定義と単位

完全解答

Δq=+6.0 μC=6.0×10^-6 C、Δt=2.0 ms=2.0×10^-3 sなので、

I_avg = Δq/Δt
      = (6.0×10^-6)/(2.0×10^-3)
      = +3.0×10^-3 A
      = +3.0 mA

である。+x向きの法線を正に選んだので、正味の電荷はその向きへ流れた。途中に逆向きの電荷移動があっても、平均電流は正味のΔqだけを数える。往復する電荷の総移動距離を数える量ではない。

再挑戦

4.0 msで-8.0 μCなら、I_avg=-2.0 mAとなる。法線を逆向きに取り直すと、同じ物理過程を+2.0 mAと表せる。数値だけでなく法線規約を一緒に保存する。

E2　電子の運動と慣用電流

完全解答

n=8.0×10^28 m^-3、q_e=-1.602176634×10^-19 C、v_e=-2.0×10^-4 m/sを符号付きで代入する。

J_x = n q_e v_e
    = (8.0×10^28)(-1.602176634×10^-19)(-2.0×10^-4)
    ≈ +2.56×10^6 A/m^2

q_eとv_eがともに負なので積は正である。電子は-xへ動くが、負電荷の流れとしての慣用電流は+x向きになる。単位は(1/m^3)C(m/s)=C/(s m^2)=A/m^2である。

再挑戦

v_e=+2.0×10^-4 m/sへ変えるとJ_x=-2.56×10^6 A/m^2。電荷の符号を落としてJ=nevとすると向きを誤るので、q_eを式に残す。

E3　断面積の変化

完全解答

定常で枝分かれがないため、どちらの断面でもI=1.0×10^-2 A。面積をSI単位へ変えると、

A_1=2.0×10^-6 m^2,   A_2=5.0×10^-7 m^2
J_1=I/A_1=5.0×10^3 A/m^2
J_2=I/A_2=2.0×10^4 A/m^2

である。細い部分で大きくなるのは単位面積あたりの流束Jであり、電荷が消費されたのではない。定常の制御体積では入る電流と出る電流が一致する。

再挑戦

I=4.0 mA、A_1=1.0 mm^2、A_2=4.0 mm^2なら、J_1=4.0×10^3 A/m^2、J_2=1.0×10^3 A/m^2。面積が4倍なら、同じ電流を運ぶ一様近似の密度は1/4になる。

E4　電流密度の面積積分

完全解答

断面の法線はn=+x。y_*=2.0×10^-3 m、z_*=1.0×10^-3 mと置くと、

I = ∫_0^z* ∫_0^y* J_0(1+y/y_*) dy dz
  = J_0 z_* [y_* + y_* / 2]
  = (1.0×10^3)(1.0×10^-3)(3.0×10^-3)
  = 3.0×10^-3 A

である。断面上の平均電流密度は1.5×10^3 A/m^2、面積は2.0×10^-6 m^2なので、平均値を使えば同じ3.0 mAになる。J=JAを点の値でそのまま使えないのは、J_xがyに依存するからである。

再挑戦

J_x=J_0(1-y/y_*)へ変えると平均値は0.5J_0、電流は1.0 mA。断面の端で密度が0になっても、積分の範囲と法線を明示すれば流れを計算できる。

E5　連続の式を有限領域から導く

完全解答

領域内の電荷はQ_Ω=∫_ΩρdV。外向き法線を採ると、外へ出る電流は∮_∂ΩJ·n dAである。保存則より、

dQ_Ω/dt = -∮_∂Ω J·n dA

となる。左辺を体積積分の時間微分、右辺を発散定理で置き換えると、

∫_Ω ∂ρ/∂t dV
 = -∫_Ω ∇·J dV
∫_Ω (∂ρ/∂t+∇·J)dV=0

を得る。任意の領域で成立するなら、

∂ρ/∂t+∇·J=0

である。外へ出る流束が大きいほど密度の時間変化は負になる。

再挑戦

体積源s_ρがある場合は、∂ρ/∂t+∇·J=s_ρ。源の単位はC/(m^3 s)で、何が供給源かをartifactに記録する。密度をコードで強制的に増減させるだけでは、源の物理的説明にならない。

E6　一様流束と定常状態

完全解答

一次元の連続の式は∂ρ/∂t=-dJ_x/dx。最初の流束は一定なので微分が0であり、

∂ρ/∂t=0

である。初期密度2.0 C/m^3は変わらず、電流が0という意味ではない。二つ目ではdJ_x/dx=50 A/m^3なので、x=0.20 mを含めどこでも

∂ρ/∂t=-50 C/(m^3 s)

となる。右へ行くほど外へ出る流束が増えるため、局所密度が減少する。

再挑戦

J_x=300-80x A/m^2なら、∂ρ/∂t=+80 C/(m^3 s)。位置によらず入る方が多い流束勾配なので、密度は増える。

E7　節点の電流収支

完全解答

定常なので、

I_1+I_2=I_3+I_4
4.0+1.5=2.0+I_4
I_4=3.5 mA

である。I_4=0とすると、流入が5.5 mA、流出が2.0 mAで、差の3.5 mAが節点へ蓄積する。節点の制御体積についてdQ/dt=+3.5 mAとなり、定常条件と矛盾する。

再挑戦

I_1=2.0 mAが入り、I_2=5.0 mA、I_3=1.0 mAが出るなら、残りの流出はI_4=6.0 mA。流れの矢印を先に固定し、符号をつけた総和で確認してもよい。

E8　ドリフト速度の見積もり

完全解答

A=1.0×10^-6 m^2。I=nq_ev_dAより、

v_d = I/(nq_eA)
    = 1.0 / [(8.0×10^28)(-1.602176634×10^-19)(1.0×10^-6)]
    ≈ -7.80×10^-5 m/s

である。電子の平均速度は-x向き、大きさは7.80×10^-5 m/s。負電荷を含むため電流は+x向きになる。これは担体の平均ドリフト速度であり、回路の変化が電磁場として伝わる速度ではない。信号伝搬には場、境界、分布容量・インダクタンスなどが関係する。

再挑戦

同じ材料で断面積を4.0 mm^2、電流を2.0 Aへ変えると、v_dは元の1/2、つまり-3.90×10^-5 m/s。密度や平均速度を固定したのか、電流を固定したのかを明示する。

E9　端子電力の符号

完全解答

電流は高電位端へ入り、電位降下を正にV=5.0 Vと定義しているので、受動符号規約で抵抗の吸収電力は

P_abs=VI=(5.0 V)(0.20 A)=1.0 W

である。電源側で同じ端子極性へ電流が入り、電源が外部へ1.0 Wを渡しているなら、電源の端子吸収電力はP=−1.0 Wと記録する。供給電力を正と定義する別の規約もあるので、artifactでは端子極性・電流矢印・符号の定義を保存する。

再挑戦

電流が抵抗の低電位端へ入る向きなら、同じV=5.0 Vの端子定義でP=-1.0 W。その場合、抵抗を受動素子として接続したという前提か、電圧降下の向きを取り違えたかを調べる。

E10　局所Joule熱

完全解答

J=σEなので、

J=(5.0×10^6)(2.0)=1.0×10^7 A/m^2
p=J·E=σE^2=(5.0×10^6)(2.0)^2=2.0×10^7 W/m^3
P=pV_volume=(2.0×10^7)(1.0×10^-9)=2.0×10^-2 W

である。JとEが直交するならJ·E=0で、その領域のこの模型による電力密度は0になる。電流があることだけでは、Joule熱が正だとは言えない。

再挑戦

E=−3.0 V/m、σ=2.0×10^6 S/m、体積2.0×10^-9 m^3なら、J=-6.0×10^6 A/m^2、p=1.8×10^7 W/m^3、P=3.6×10^-2 W。符号が反転しても線形・等方的な同じ材料ではpは正になる。

E11　保存則を破るセル列の診断

完全解答

電流へ直すと、

I_in=J_in A=100×1.0×10^-4=1.0×10^-2 A
I_out=J_out A=90×1.0×10^-4=9.0×10^-3 A

である。1ステップの密度増分は、

Δρ=Δt(I_in-I_out)/(AΔx)
   =(1.0×10^-4)(1.0×10^-3)/(1.0×10^-4×0.10)
   =1.0×10^-2 C/m^3

。100ステップでは一定流束を仮定した予測が1.0 C/m^3。同じ結果をdρ/dt=-(J_out-J_in)/Δx=100 C/(m^3 s)からも得る。

保存則を守るモデルではJ_out=J_in、したがってI_out=I_inにする。もし実際に注入・蓄積・消滅を表したいなら、体積源または境界源を単位付きで導入し、intentional_leakを通常の保存モデルとは別状態で記録する。

再挑戦

J_in=80 A/m^2、J_out=100 A/m^2なら、dρ/dt=+200 C/(m^3 s)。100ステップ後は2.0 C/m^3。出る流束の方が大きい場合の符号を、式とセル図の両方で確認する。

E12　runner結果と模型限界のartifact

完全解答

最小仕様の一例は次のようになる。

{
  "chapter_id": 7,
  "experiment_id": 1,
  "status": "analytic_prediction_recorded_measurement_not_run",
  "environment": {"kind": "fixed-linux", "version": "pinned"},
  "orientation": {"axis": "x", "positive_normal": "+x"},
  "sections": [
    {"area_m2": 2.0e-6, "current_A": 1.0e-2,
     "current_density_A_per_m2": 5.0e3},
    {"area_m2": 5.0e-7, "current_A": 1.0e-2,
     "current_density_A_per_m2": 2.0e4}
  ],
  "cells": [
    {"step": 0, "time_s": 0.0, "J_in_A_per_m2": 100,
     "J_out_A_per_m2": 100, "rho_C_per_m3": 0,
     "model": "conserving"}
  ],
  "power": {"V_drop_V": 5.0, "I_A": 0.2,
            "P_abs_W": 1.0, "sign_convention": "passive"},
  "limits": ["uniform_cross_section", "no_measurement", "no_runner_log"]
}

断面とセルの単位、法線、model、status、電力の符号規約を分けている点が重要である。解析adapterを実行しても、measured: falseを保ったまま記録し、executedを実測済みという意味へ拡張してはいけない。

再挑戦

保存モデル、intentional_leak、実測値を同じ配列へ入れる設計を一つ作り、検索だけで三者を区別できるキーを示す。少なくともsource_kind（analytic prediction, runner result, measurement）、model、status、environmentを分ければ、状態の混同を避けやすい。

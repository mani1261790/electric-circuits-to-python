第10章　Kirchhoff則の由来と限界

1　まず、二つの節点の電圧を決める

次の回路を紙に描く。ground（基準節点）から測ったnode 1とnode 2があり、node 1とgroundの間に1 kΩ、node 2とgroundの間に2 kΩ、node 1とnode 2の間に1 kΩの抵抗を置く。さらに、groundからnode 1へ3 mA、groundからnode 2へ1 mAの電流源を接続する。

node 1とnode 2の電圧はいくらか。node 1からnode 2へ流れる電流はどちら向きで、何mAか。

抵抗の端子関係だけなら、第8章のオーム則から、node 1からnode 2へ流れる電流は

I_12 = (V_1 - V_2)/(1 kΩ)

である。しかし、V_1とV_2を決めるには、各nodeで電流の出入りを数えなければならない。これは「電流はnodeで消える」という規則ではない。第7章の連続の式を、nodeの周りの小さな体積へ適用した収支である。

この章で扱う数値は、指定した抵抗・電流源・電圧源から求めた解析予測である。book run 10 1の解析adapterは固定入力を再生済みだが、SPICEや実回路の測定は実行していない。回路を実際に測った結果と、式から計算した値とを同じ表へ上書きしてはならない。

本章の問いは次である。

KCLとKVLは暗記規則ではなく、どの保存則と近似から出てくるのか。

第9章では、電磁場を節点電圧と枝電流へ縮約できる時間・空間の条件を調べた。その縮約を採用すると、回路はnode（節点）、branch（枝）、loop（閉路）の組として表せる。本章では、節点の電流収支をKCL、閉路の電圧収支をKVLへ変換し、行列として解く。最後に、電荷を蓄えるコンデンサや磁気エネルギーを蓄えるインダクタを加えたとき、何が変わるかを次章へ渡す。

2　連続の式からKCLを作る

2.1　小さな制御体積の収支

第7章の連続の式を、nodeを包む制御体積Ω_nへ積分する。

∂ρ/∂t + div(J) = 0

体積積分と発散定理から、

dQ_n/dt + ∮_(∂Ω_n) J · n dA = 0                 (10.1)

を得る。ここでQ_n=∫_(Ω_n)ρ dVは制御体積内の電荷、nは制御体積の外向き法線である。境界を枝の断面で切ると、面積分は各枝を制御体積の外へ出る電流の和になる。枝bの電流を「nodeから外へ」を正としてI_b^outと書けば、

dQ_n/dt + Σ_b I_b^out = 0

である。したがって、一般のnode収支は

Σ_b I_b^out = -dQ_n/dt                       (10.2)

となる。式(10.2)がKCLの出発点である。左辺が0なのは、右辺を捨てても誤差が小さいときだけである。

枝電流を「nodeへ入る」を正に統一する場合は、符号が変わり、

Σ_b I_b^in = dQ_n/dt

となる。二つの書き方は同じ物理を表す。重要なのは、一つの計算の中で外向きと内向きを混ぜないことである。

2.2　蓄積を無視する近似としてのKCL

節点にたまる電荷が、観測する時間尺度でほぼ一定なら、dQ_n/dt≈0と置ける。このとき、式(10.2)は

Σ_b I_b^out = 0                               (10.3)

になる。これがKirchhoff電流則（Kirchhoff's current law, KCL）の集中定数版である。内向きを正にした場合はΣ I_b^in=0となる。KCLは電荷保存を弱めた規則ではなく、電荷保存へ「節点内の蓄積をこの解像度では残さない」という近似を加えた結果である。

nodeへ容量をつないだときは、容量へ流れる枝電流を収支へ残す。例えば容量の上端nodeの電圧をV_n、groundを基準にすれば、

I_C = C dV_n/dt

である。容量を隠したままΣ I=0とするのではなく、容量枝を含めたKCLを書く。容量電流をさらに捨てるのは、ゆっくりした観測や小さな容量など、別に確認した条件である。この扱いは第11章で時間発展として詳しく行う。

2.3　節点、枝、閉路をグラフとして固定する

回路図の交差した線が同じnodeであるかは、線が交差しているかではなく、接続点の契約で決める。次の記録を先に作る。

記録例役割
node番号0=ground, 1, 2電位を割り当てる名前
branch1→2の1 kΩ二つのnodeを結ぶ素子と向き
電流の正方向I_12は1→2KCLへ入れる符号
電圧の極性V_12=V_1−V_2オーム則とKVLへ入れる符号
groundnode 0電圧の基準、未知数から除くnode

nodeの番号は物理量ではない。番号を入れ替えても電圧差と枝電流が同じなら、同じ回路を表す。groundも「そこは電圧が存在しない」という意味ではなく、全ての電圧を比較する基準である。groundを一つ選んでも、回路の電圧差と電流の物理は変わらない。

図10-01では、連続の式の制御体積、外向きの枝電流、蓄積電荷を同じ図へ置く。矢印の向きは計算上の正方向であり、解が負になることを禁止しない。

2.4　電流源と抵抗の向き

以下では、抵抗Rをnodeaとnodebの間に置き、抵抗の電流をa→b向きに定義する。

I_ab = (V_a - V_b)/R                         (10.4)

これは第8章のオーム則V=RIを、node間の電圧差へ適用したものだ。V_a<V_bならI_abは負となり、実際の電流がb→a向きであることを表す。

電流源I_sをa→b向きに置くと、nodeaから見た外向き電流へ+I_s、nodebから見た外向き電流へ-I_sが加わる。反対に、行列の右辺を「nodeへ注入する電流」と定義すれば、nodeaへ-I_s、nodebへ+I_sを加える。この符号反転は誤りではないが、右辺の定義を途中で変えてはいけない。

3　Faraday則からKVLを作る

3.1　閉路の電圧は電場の線積分から来る

第6章では、静電場で電位差を

φ(b) - φ(a) = -∫_a^b E · dℓ

と表した。この式から、電場の線積分を枝の電圧降下へ対応付ける。閉路Cを一周する向きを選び、その向きに沿った枝の電圧降下をv_bとする。

しかし、時間変化する磁場があると電場は一般に保存場ではない。Faradayの積分則は、

∮_C E · dℓ = -dΦ_B/dt                         (10.5)

である。Φ_B=∫_S B·dAは閉路が囲む面を通る磁束で、面の法線は閉路の向きと右手系で対応させる。枝電圧をこの閉路の線積分に対応させれば、一般の閉路収支は

Σ_b v_b = -dΦ_B/dt                            (10.6)

となる。式(10.6)では、右辺が誘導電場による起電力である。

3.2　磁束変化を捨てた条件付きのKVL

閉路を貫く磁束の変化が、測定した電圧の許容誤差に比べて小さいなら、dΦ_B/dt≈0と置ける。さらに第9章で確認した伝搬遅延を、同じ時刻の端子電圧へまとめられる条件に限る。このとき式(10.6)は

Σ_b v_b = 0                                  (10.7)

となる。これがKirchhoff電圧則（Kirchhoff's voltage law, KVL）の集中定数・準静的版である。閉路の向きを逆にすれば、全てのv_bの符号と磁束の符号が同時に反転し、物理的な予測は変わらない。

KVLを「一周すると電圧が必ず0へ戻る」と暗記すると、式(10.5)の右辺を見落とす。例えば、閉路の面を貫く磁束がΦ_B(t)=Φ_0 sin(ωt)なら、

-dΦ_B/dt = -ω Φ_0 cos(ωt)

であり、閉路の電圧和は一般に0ではない。これは抵抗の値を間違えた故障ではなく、単純KVLの適用範囲を外れた現象である。

3.3　KVLが破れる三つの境界

第一は、外部磁場または別のコイルの電流による磁束変化である。閉路の面を小さく描けばよいとは限らない。実際の導体配置が囲む面、近くの導体との結合、周波数を確認する。

第二は、配線の長さに対して信号の立上りが速い場合である。第9章のκ=t_prop/t_riseが大きいと、閉路の各枝を同じ時刻の端子電圧で代表できない。反射や放射を、単純な枝電圧の和へ隠すことはできない。

第三は、分布した素子や測定器が作る経路である。測定プローブの接地リードも閉路の一部になり、追加の面積とインダクタンスを作る。KVLの残差を見たら、まず式の符号だけでなく、実際に積分している閉路と観測帯域を確認する。

4　節点解析を行列へ変換する

4.1　未知数を節点電圧へそろえる

groundをnode0とし、非基準nodeの電圧を未知数にする。抵抗だけの回路では、各抵抗の電流を式(10.4)で表してKCLへ代入する。電流源は「nodeへ注入する電流」を右辺jへ集める。

すると、

G v = j                                      (10.8)

という連立一次方程式になる。vの単位はV、jの単位はA、行列Gの単位はS=1/Ωである。Gはコンダクタンス行列と呼ぶ。

抵抗Rをnodeaとnodebの間へ刻印する（stamp）規則は次である。g=1/Rとし、groundでないnodeだけを行列へ入れる。

G[a,a] += g
G[b,b] += g
G[a,b] -= g
G[b,a] -= g

aまたはbがgroundなら、そのnodeの行・列を追加しない。例えばaとgroundの抵抗なら、G[a,a]+=gだけが残る。電流源がa→b向きなら、注入ベクトルは

j[a] -= I_s
j[b] += I_s

である。ここでjをnodeへ注入する向きと定義したため、外向き電流のKCLから符号が反転している。

4.2　具体例：二つの電流源を解く

冒頭の回路を、V_1,V_2を未知数として書く。抵抗値をΩ、電流値をAで表す。

R_1g = 1000 Ω
R_2g = 2000 Ω
R_12 = 1000 Ω
j_1 = 0.003 A
j_2 = 0.001 A

各nodeのKCLから、

(1/1000 + 1/1000)V_1 - (1/1000)V_2 = 0.003
-(1/1000)V_1 + (1/2000 + 1/1000)V_2 = 0.001

したがって、

[ 0.0020  -0.0010 ] [V_1] = [0.003]
[−0.0010   0.0015 ] [V_2]   [0.001]

である。単位をmAとkΩへそろえて計算するなら、行列の数値をmS、右辺をmAとしてよい。

2 V_1 - V_2 = 3
-V_1 + 1.5 V_2 = 1

より、解析予測は

V_1 = 2.75 V
V_2 = 2.50 V

となる。枝電流の予測は、

I_1g = V_1/1 kΩ = 2.75 mA
I_2g = V_2/2 kΩ = 1.25 mA
I_12 = (V_1−V_2)/1 kΩ = 0.25 mA

である。node 1では、抵抗へ出る2.75+0.25=3.00 mAと、電流源が注入する3.00 mAがつり合う。node 2では、抵抗からgroundへ出る1.25 mAが、電流源の注入1.00 mAとnode 1から入る0.25 mAの和に等しい。

この計算は、電流がnode 1でnode 2へ「分割された」という言葉を、電荷保存の式へ戻している。負の枝電流が出ても、定義した向きと逆に流れるだけであり、解を失敗扱いしない。

4.3　閉路の式との対応

同じ回路をKVLで書くこともできる。例えばnode 1とnode 2の間の抵抗、node 2とgroundの抵抗、node 1とgroundの抵抗を含む閉路を選ぶと、電圧降下を同じ向きに定義して式(10.7)を立てられる。ただし、閉路の向きと枝電流の向きが異なるとRIの符号が変わる。

節点解析はnode電圧を未知数にするので、閉路を大量に選んで冗長な式を増やさずに済む。反対に、電圧源が多く、枝電流を直接知りたい場合には、次節の修正節点解析で電圧源電流を未知数へ追加する。どちらの方法を選ぶかは計算上の表現の違いであり、KCL・KVLの物理的出所が変わるわけではない。

5　理想電圧源を含む修正節点解析

5.1　なぜ電圧源を普通の抵抗のように刻印できないか

抵抗なら、端子電圧を決めれば電流がI=V/Rで決まる。理想電圧源は、端子電圧をV_a−V_b=V_sへ固定するが、電流を決める抵抗値を持たない。したがって、電圧源の電流を未知数として追加する。

電圧源kの電流を、正端子aから負端子bへ向かうi_kと定義する。非基準nodeの電圧ベクトルをv、電圧源電流ベクトルをi_sとすると、MNA（modified nodal analysis、修正節点解析）は、

[ G  B ] [ v   ] = [ j ]
[ C  0 ] [ i_s ]   [ e ]                         (10.9)

と書ける。Gは抵抗の刻印、jは電流源の注入、eは電圧源の値である。理想電圧源の正端子と負端子が同じnode番号順に並ぶとき、Bには+1と-1を刻印する。受動素子だけを扱う標準的なMNAではCはBの転置に対応するが、実装では電圧制約の向きが一致しているかを行ごとに確認する。

行列の電圧行はV_a−V_b=V_sを表し、電流列はKCLへ+i_k（正端子）と-i_k（負端子）を加える。これにより、抵抗・電流源・電圧源を別々の方程式へ分けず、同じ線形系を解ける。

5.2　具体例：浮いた電圧源

node 1とnode 2の間に、正端子をnode 1、負端子をnode 2とする5 Vの理想電圧源を置く。さらに各nodeからgroundへ1 kΩの抵抗を置く。電圧源の電流i_sの正方向をnode 1からnode 2とする。

抵抗のコンダクタンスをg=0.001 Sとすると、MNAの予測式は、

[ 0.001   0       1 ] [V_1 ]   [0]
[ 0       0.001  -1 ] [V_2 ] = [0]
[ 1      -1       0 ] [i_s ]   [5]

である。第三行はV_1−V_2=5 Vという制約である。解は、

V_1 =  2.50 V
V_2 = -2.50 V
i_s = -2.50 mA

という解析予測になる。i_sが負なのは、実際にはnode 2からnode 1へ2.50 mA流れることを表す。電圧源はnode 1へ電流を押し込んでいる。

この例では、各抵抗の消費電力が

P_1 = V_1^2/(1 kΩ) = 6.25 mW
P_2 = V_2^2/(1 kΩ) = 6.25 mW

である。受動符号規約で電圧源の電圧を+5 V、電流を正端子へ入る向きとして読むと、電圧源の電力はP_s=5 V×(-2.50 mA)=-12.5 mWとなる。負号は供給を表し、三つの枝の電力の和は0になる。この符号を捨てて「全ての電力が消費」と呼ぶと、電源がエネルギーを供給する事実を失う。

図10-05では、浮いた電圧源を抵抗へ置き換えず、電圧源電流を追加した未知数と、電圧制約の行として描く。node 2の電圧が負になることは、groundが最低電位であるという意味ではない。groundは比較の基準にすぎない。

5.3　接地と方程式の独立性

抵抗網を全て同じ電位へ持ち上げても、抵抗の電圧差は変わらない。groundのない回路では、絶対的な電圧を決める方程式が不足し、行列が特異になる。これは「電圧が全部0」という解ではない。

非基準nodeがN個ある抵抗網では、基本的にN個の独立なKCLが必要である。KCLを全nodeへ書いても、その和は枝電流が相殺されるため、groundを含む全nodeの式には一つの冗長な関係がある。groundの電圧を0へ固定し、残りのN式を使うのは、冗長性を除き基準を選ぶ操作である。

閉路解析でも、全ての閉路を無制限に選んではいけない。ある閉路が他の閉路の式の和になっているなら独立ではない。独立な閉路の数は、接続グラフの枝数とnode数の関係から数えられるが、電圧源や理想短絡が同じ制約を重ねていないかを別に検査する。

6　Pythonで作る最小MNAソルバ

6.1　入力の契約を先に決める

実装予定のartifactでは、数値と向きを次のように固定する。

Resistor(a, b, ohm)       : a-b間の抵抗、ohm > 0
CurrentSource(a, b, A)    : aからbへ流れる電流源、単位A
VoltageSource(a, b, V)    : a-b間をV_a-V_b=Vとする電圧源、単位V
node 0                    : ground
node 1..N                 : 非基準node

入力値はSI単位へ変換してから渡す。1 kΩを1000、3 mAを0.003と保存する。入力が資料値なのか、計算用の仮定なのか、runnerの予測なのか、測定値なのかは、数値フィールドと別のstatus・source_kind列へ保存する。

以下は、Python標準機能だけを用いる予定コードの骨格である。ここに示したコードは、執筆時点でrunnerへ投入した実行結果ではない。

from dataclasses import dataclass
from math import isfinite


@dataclass(frozen=True)
class Resistor:
    a: int
    b: int
    ohm: float


@dataclass(frozen=True)
class CurrentSource:
    a: int
    b: int
    ampere: float


@dataclass(frozen=True)
class VoltageSource:
    a: int
    b: int
    volt: float


def solve_mna(node_count, resistors, current_sources, voltage_sources):
    if not isinstance(node_count, int) or node_count < 1:
        raise ValueError("node_count must be a positive integer")

    def check_node(node):
        if not isinstance(node, int) or not 0 <= node <= node_count:
            raise ValueError("node is outside 0..node_count")

    def index(node):
        return None if node == 0 else node - 1

    for item in resistors:
        check_node(item.a)
        check_node(item.b)
        if item.a == item.b or not isfinite(item.ohm) or item.ohm <= 0:
            raise ValueError("a resistor needs two nodes and positive finite ohms")
    for item in current_sources:
        check_node(item.a)
        check_node(item.b)
        if item.a == item.b or not isfinite(item.ampere):
            raise ValueError("current source has invalid nodes or value")
    for item in voltage_sources:
        check_node(item.a)
        check_node(item.b)
        if item.a == item.b or not isfinite(item.volt):
            raise ValueError("voltage source has invalid nodes or value")

    n = node_count
    m = len(voltage_sources)
    size = n + m
    matrix = [[0.0 for _ in range(size)] for _ in range(size)]
    rhs = [0.0 for _ in range(size)]

    def add(row, col, value):
        if row is not None and col is not None:
            matrix[row][col] += value

    for item in resistors:
        g = 1.0 / item.ohm
        a, b = index(item.a), index(item.b)
        add(a, a, g)
        add(b, b, g)
        add(a, b, -g)
        add(b, a, -g)

    for item in current_sources:
        a, b = index(item.a), index(item.b)
        if a is not None:
            rhs[a] -= item.ampere
        if b is not None:
            rhs[b] += item.ampere

    for k, item in enumerate(voltage_sources):
        a, b = index(item.a), index(item.b)
        col = n + k
        if a is not None:
            matrix[a][col] += 1.0
            matrix[col][a] += 1.0
        if b is not None:
            matrix[b][col] -= 1.0
            matrix[col][b] -= 1.0
        rhs[col] = item.volt

    scale = max(1.0, *(abs(value) for row in matrix for value in row))
    tolerance = 1.0e-12 * scale
    for col in range(size):
        pivot = max(range(col, size), key=lambda row: abs(matrix[row][col]))
        if abs(matrix[pivot][col]) <= tolerance:
            raise ValueError("singular or floating circuit")
        if pivot != col:
            matrix[col], matrix[pivot] = matrix[pivot], matrix[col]
            rhs[col], rhs[pivot] = rhs[pivot], rhs[col]
        for row in range(col + 1, size):
            factor = matrix[row][col] / matrix[col][col]
            for k in range(col, size):
                matrix[row][k] -= factor * matrix[col][k]
            rhs[row] -= factor * rhs[col]

    answer = [0.0 for _ in range(size)]
    for row in range(size - 1, -1, -1):
        tail = sum(matrix[row][col] * answer[col]
                   for col in range(row + 1, size))
        answer[row] = (rhs[row] - tail) / matrix[row][row]
    return answer[:n], answer[n:]

この実装では、matrixの行列単位が混ざらないよう、抵抗を必ず導電率へ変換してから刻印する。部分ピボットは、行列の対角成分が小さいときに、同じ列の大きな要素を選んで行を交換する。ピボットが許容値以下なら、浮いた回路、矛盾した理想電圧源、接続欠落などを含む「解けない入力」として止める。

6.2　答えの後に残差を計算する

線形消去が終わっただけでは、回路の実装が正しいとは言えない。元のstampを使って、次の残差を計算する。

r_node = G v + B i_s - j
r_source = C v - e

理想的な二重精度計算なら、r_nodeとr_sourceは丸め誤差の範囲で0になる。出力には絶対残差だけでなく、行の右辺と係数で規格化した残差、使用した単位、ピボット許容値、入力の状態を保存する。小さな残差は行列と解の整合性を示すが、1 kΩを1 Ωと入力した物理的な誤りを発見するとは限らない。

7　故障を物理・符号・数値に分ける

7.1　KCL残差が大きいとき

まず、同じnodeへつながる枝を全て列挙し、各枝の正方向を図へ書き直す。電流源のa→bを、右辺へ+Iとしてnodeaへ加えたなら、注入ベクトルの定義が混ざっている。a→bはnodeaから外へ出るので、nodeaの注入は-Iである。

次に、抵抗電流の電圧差を確認する。I_ab=(V_a−V_b)/Rであり、V_b−V_aへ変えるなら枝の向きも変えなければならない。電圧源の電流をMNAへ追加したか、容量などの蓄積枝を誤って消していないかも確認する。

最後に、mAとA、kΩとΩを確認する。数値を1000倍する故障は、収支式を解けても、実回路との比較を壊す。値、単位、状態を別の列へ保存すると、表示の丸めと入力単位を追跡できる。

7.2　KVL残差が大きいとき

閉路を同じ向きにたどり、枝の電圧極性が閉路の向きと一致するかを一つずつ記録する。抵抗の枝を逆に読むとRIの符号が反転する。電圧源は正端子から負端子へ進むと+V_sの降下、負端子から正端子へ進むと-V_sの降下として扱う。

符号を直しても残差が大きいなら、Faradayの式(10.6)の右辺を調べる。変化磁束が無視できないとき、KVLを0へ固定する方が故障である。さらに第9章のκ、観測点、終端、測定器の接地リードを確認する。速い信号で枝電圧が位置依存になるなら、集中定数の一つの閉路へ押し込めず、分布線路や寄生インダクタンスを残す。

7.3　行列が特異なとき

「解が0だった」と表示して終わらせない。候補は次の通りである。

  1. groundへつながらない浮いた部分回路がある。
  2. 同じnode間へ、異なる値の理想電圧源を並列に置いている。
  3. 同じ電圧制約を同じ向きで重複して刻印している。
  4. node番号の誤りで、意図した抵抗や電圧源が別のnodeへつながっている。
  5. 抵抗0を、無限導電率の抵抗として未定義のまま渡している。

groundを追加すれば必ず正しい回路になるとは限らない。浮いた回路が物理的に意図したものなら、基準を置く理由や測定器の入力抵抗をモデルへ含める。理想短絡を扱うなら、0Ω抵抗として除算するのではなく、電圧制約として別途設計する。

7.4　電力で最後の整合性を確認する

受動符号規約では、枝の電圧の正端子へ電流が入る向きを正とし、

P_b = V_b I_b

とする。抵抗はP_b≥0、独立電源は供給時にP_b<0になる。静的な線形回路で理想素子以外の蓄積を無視するなら、全枝の電力和が0になることを検査できる。

ただし、この検査は単位と極性を確認する補助であって、回路が実在の電磁場を完全に表す証明ではない。誘導、放射、測定器負荷、温度変化、周波数依存を捨てた模型なら、捨てたエネルギー経路を別に記録する。

そのときもKCLは連続の式の節点版、KVLはFaraday則の閉路版である。変わるのは、蓄積と磁束を隠さず、微分方程式の状態として残すことだ。第11章では、抵抗・コンデンサ・インダクタの端子方程式、初期条件、RCとRLCの時間応答を扱う。本章のcapacitor_current、power、kcl_node_balance、kvl_quasistatic_loopを、時間依存の式へ接続する。

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

途中で予測と結果が異なったら、最後の行から修正しない。入力、仮定、更新、表現、実行環境の順に一つずつ戻り、最初に不一致になった行へ診断名を付ける。診断名を付けられない差は、未解決として後段へ渡さない。

9　逆向きに説明する

今度は出力から出発し、どの入力と規則が必要だったかを逆向きに書く。画面の文字、論理値、レジスタ値、電圧、エネルギーのように異なる表現を、途中のartifactなしで直接つないではいけない。各矢印のそばに、保証する契約と保証しない詳細を一つずつ書く。

逆向きの説明で最初に見つかる欠落は、たいてい三種類のどれかである。入力の単位または幅がない、モデルの適用条件がない、または実行と測定の境界がない。この章の本文へ戻り、欠落を埋める行を一つ追加する。

10　再現記録の最小形

再現記録には、章ID、実験ID、case、入力hash、toolまたはmodelの版、終了コード、出力artifact、source_kind、status、measuredを残す。時刻やhost名は再現性の補助情報であり、計算値や状態遷移の一部として扱わない。

この最小形を満たせないときは、実験が難しいのではなく、契約がまだ閉じていない。閉じていない契約は、成功結果を保存するより先に、未指定欄と診断欄を保存する。

11　次章の読者への引き継ぎ文

最後に、次章の読者がこの章を読み返さなくても前提を再構成できる引き継ぎ文を書く。第一文はこの章が固定した定義、第二文は代表入力と途中状態、第三文は守る不変条件、第四文は最も近い破綻条件、第五文は未実行または未照合の境界である。

引き継ぎ文の主語を『この値は』だけにしない。『この模型では』『この版のtoolでは』『このmemory領域では』『このsource spanでは』のように、値の所有者を明記する。所有者が変わるところが、章間のbridgeであり、独立レビューが最初に読む境界である。

引き継ぎ文を書いたら、manifestの bridge_in と bridge_out、handoffのopen question、required artifactを照合する。本文に書いた橋と台帳の橋が異なる場合は、どちらかを勝手に合わせず、差分を未解決として残す。

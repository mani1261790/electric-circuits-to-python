第4章　観測、測定、数値計算

この章の中心問題

同じRC回路の電圧を描いたグラフが三つあるとする。一つは式から計算した線、一つはSPICEが計算した線、もう一つはオシロスコープで観測した点である。見た目がよく重なっていても、三つは同じものではない。

  • 解析解は、仮定した方程式を連続時間で解いた結果である。
  • 数値解は、その方程式を有限個の時刻と有限精度の数で近似した結果である。
  • SPICEの波形は、回路素子のモデル、数値解法、収束判定、刻み幅の選択を含むシミュレータの結果である。
  • 測定値は、対象回路、プローブ、入力抵抗、帯域、サンプリング、量子化、環境ノイズを通った観測結果である。

この違いを曖昧にすると、「線が一致したからモデルは正しい」「刻み幅を半分にしたから誤差は半分」「シミュレーションが動いたから実機も動く」という誤った結論に進む。本章では、同じ理想RC過渡応答を題材に、観測、測定、解析、数値計算、回路シミュレーションを分けて記録する。

本章で作るものは、後の章でも利用できる比較の型である。入力条件、初期条件、モデル、計算方法、観測方法、単位、誤差、版、成果物を一つの記録へまとめる。値が一致するかだけではなく、何が一致し、何が比較できないかを説明できることが到達点である。

1　前提と今回の到達点

第3章で、物理量には数値と単位があり、微分方程式には初期値と区間が必要であることを確認した。本章では、それをRC回路の時間応答へ適用する。高校数学の指数関数、微分、積分、Pythonの関数・配列・ファイル操作を使う。Cのポインタや動的メモリは、測定バッファを扱う後続章で必要になるが、本章の理想RC計算には必須ではない。

章末までに、次をできるようにする。

  1. 同じ現象について、解析解、数値解、シミュレーション、測定を別の層として説明する。
  2. 理想RC回路の時定数とステップ応答を導出し、入力と初期値を記録する。
  3. Euler法と4次Runge--Kutta法を同じ時刻軸で計算し、刻み幅、打切り誤差、丸め誤差、安定性を区別する。
  4. 測定器の入力抵抗と帯域が、測定対象そのものを変える仕組みを説明する。
  5. サンプリングと量子化が、連続時間・連続振幅の信号をどのようなデータへ変えるかを説明する。
  6. 解析解・数値解・SPICE・測定の結果を、予測値、実測値、環境情報付きの成果物として保存する。
  7. book run 4 1 のような共通入口を使い、解析・契約の再生済み、domain未実行、外部測定未実施を混同しない。

2　四つの「結果」を分ける

2.1　解析解は仮定を解いたもの

理想的な直列RC回路へ、時刻0でV_sのステップ電圧を加える。抵抗Rとコンデンサ容量Cは一定、配線は理想導線、測定器は接続しない、と仮定する。コンデンサの電圧をV_C(t)と書く。

抵抗を流れる電流とコンデンサへ流れ込む電流を同じと置くと、

(V_s - V_C)/R = C dV_C/dt

である。整理して、

dV_C/dt = (V_s - V_C)/(R C)                    (4.1)

を得る。R Cは秒の単位を持つので、

τ = R C                                           (4.2)

を時定数と呼ぶ。初期値をV_C(0)=V_0、入力を時刻0以降一定のV_sとすると、解は

V_C(t) = V_s + (V_0 - V_s) exp(-t/τ)              (4.3)

である。V_0=0ならV_C(t)=V_s(1-exp(-t/τ))となる。

この式の数値を計算できることと、現実の回路がこの式どおりに振る舞うことは別である。解析解が保証するのは、明示した理想化と初期条件の範囲で式が微分方程式を満たすことである。部品の許容差、コンデンサの漏れ、信号源の出力抵抗、プローブの負荷、有限の立上り時間は式の外にある。

2.2　数値解は連続方程式の近似

解析解を使えない、または後で同じ更新器を非線形モデルへ適用したい場合、時刻をΔt刻みに区切る。Euler法は、時刻t_nでの傾きを次の区間全体に使う。

V_(n+1) = V_n + Δt f(t_n,V_n)
f(t,V)   = (V_s - V)/(R C)                       (4.4)

Δtは秒、fはV/sなので、増分Δt fはVである。単位が合っていることは必要だが、近似誤差が小さいことを示さない。Euler法の局所誤差は一般にO(Δt^2)、区間全体での大域誤差はO(Δt)である。ただし、実際の誤差には浮動小数点の丸め、入力値の誤差、モデル化誤差も重なる。

4次Runge--Kutta法（RK4）は、一つの区間の始点、中点、終点で傾きを評価して重み付けする。

k1 = f(t_n,         V_n)
k2 = f(t_n+Δt/2,    V_n+Δt k1/2)
k3 = f(t_n+Δt/2,    V_n+Δt k2/2)
k4 = f(t_n+Δt,      V_n+Δt k3)
V_(n+1) = V_n + Δt (k1 + 2k2 + 2k3 + k4)/6          (4.5)

理想RCのような滑らかな線形問題では、同じ刻み幅ならRK4の打切り誤差はEuler法より急速に小さくなる。しかし、刻み幅を大きくしてよいという意味ではない。入力が急に変わる点、非線形素子の境界、測定ノイズ、桁落ちが支配的なら、方法の次数だけでは結果を保証できない。

2.3　数値安定性と精度

e_n=V_n-V_sと置くと、Euler法のRC更新は

e_(n+1) = (1 - Δt/τ) e_n                            (4.6)

になる。誤差が発散しないための目安は|1-Δt/τ|<1、すなわち0<Δt/τ<2である。Δt/τが1を超えると符号が交互に変わる振動的な近似になり得る。2以上では理想解が単調に近づく場合でもEulerの値が発散し得る。

これは「刻み幅が小さいほど常に良い」という単純な話ではない。非常に小さいΔtでは、隣り合う値の差が浮動小数点の分解能や測定ノイズより小さくなり、計算量だけが増えることがある。刻み幅を変えるときは、次の三つを別々に記録する。

  • 安定性: 更新が発散または非物理的振動を起こさないか。
  • 打切り誤差: 連続方程式を離散化したことによる誤差。
  • 丸め誤差: 有限桁の数で演算したことによる誤差。

2.4　SPICEは別の計算経路

SPICEは回路図をそのまま「現実」にする装置ではない。抵抗、コンデンサ、電圧源などのモデルから方程式を作り、時間刻みを選んで数値的に解く。解析の設定、初期条件、相対・絶対許容誤差、素子モデル、収束のための処理が結果へ影響する。

同じR=1 kΩ、C=1 μF、V_s=5 Vを書いても、理想部品のSPICE結果と、寄生抵抗・漏れを持つ部品モデルの結果は別である。SPICEの波形が解析解と一致したときに言えるのは、選んだモデルと条件の範囲で数値解がその解に近いということまでだ。実測値との一致には、部品値、信号源、プローブ、配線、温度などの別の検証が必要である。

3　測定は信号を写すだけではない

3.1　測定のブロック図

観測対象の電圧x(t)が、次の過程を通って記録値y[n]になると考える。

対象 x(t)
  → 接続（プローブ、入力抵抗、容量）
  → アナログ帯域（増幅器、フィルタ）
  → サンプラー（時刻 nT_s）
  → 量子化器（有限ビット）
  → ファイル y[n]

このブロックのどこかを省略して「測った電圧はx(t)そのもの」と扱うと、誤差の原因を診断できない。記録には、測定位置、基準電位、プローブ設定、入力抵抗、入力容量、帯域、サンプリング周波数、分解能、レンジ、時刻の基準を含める。

3.2　入力抵抗は回路を変える

理想電圧計は入力抵抗が無限大で、回路から電流を取らない。しかし現実の測定器には有限の入力抵抗R_inがある。ここでは、信号源、出力抵抗R_s、回路の抵抗R、コンデンサの上端という順に直列接続し、コンデンサの上端からR_inを基準電位へ接続するトポロジーを固定する。すると、信号源を零にしたときにコンデンサから見える簡略模型の抵抗は

R_eff = (R + R_s) || R_in                           (4.7)

となり、時定数はτ_eff=R_eff Cになる。充電時の最終電圧はR_inによる分圧でも変わるため、時定数だけを比べてはいけない。これは接続点と回路構成を固定した模型であり、プローブ容量を無視している。プローブ容量C_inも無視できない場合は、負荷の極を追加する必要がある。

入力抵抗が十分大きいかは、抵抗値だけで決めない。R_in/Rの比、許容する時定数変化、プローブ容量と信号の立上り時間を比較する。測定器を接続する前後で波形が変わったら、測定器が「見るだけの窓」ではなく回路の一部になった可能性がある。

3.3　帯域と立上り時間

測定器の帯域が有限なら、急なステップはそのまま記録されない。一次遅れの測定系を時定数τ_mのローパスとして近似すれば、対象の波形と測定器の応答が重なった二次の応答になる。測定器の立上り時間と対象の立上り時間が同程度なら、観測波形から対象の時定数を直接読んではいけない。

「帯域が高いほど正しい」とも限らない。高帯域ではノイズを多く通す場合がある。測定目的に応じて、対象の最短時間尺度、必要な振幅精度、許容ノイズを先に決める。

3.4　サンプリングと量子化

サンプリング周期をT_s、サンプリング周波数をf_s=1/T_sとする。信号が有限帯域で、最高周波数f_maxを持ち、理想的な帯域制限フィルタがあるとき、f_s>2f_maxが元の連続信号を再構成する条件の入口になる。条件を満たさない信号成分はaliasingとして別の周波数に見える。RCのステップは理想的には無限の高周波成分を含むため、有限サンプリングだけで「完全なステップ」を記録できない。

量子化では、振幅を有限個の段階へ丸める。Nビット、測定レンジ幅V_rangeなら、量子化幅の目安はΔV=V_range/2^Nである。量子化誤差を一様に独立なノイズとして扱えるのは、信号が十分に変化し、飽和やコード境界の偏りがないなどの条件付きである。測定データを解析解へ合わせる前に、サンプリング間隔、量子化幅、飽和の有無を確認する。

4　誤差と不確かさを別の欄へ書く

4.1　誤差という言葉の分解

基準となる値x_refと計算または観測値xについて、差x-x_refを誤差と呼べる。しかし、何を基準にした差かを記録しなければ意味がない。次の欄を分ける。

  • 解析解との差: 同じ理想モデル内での数値近似の誤差。
  • SPICEとの差: 回路モデル、ソルバ設定、収束許容誤差の差。
  • 測定値との差: 部品、接続、測定器、環境、モデルの差を含む。
  • 不確かさ: 値がどの範囲にあると考えるか。既知の真値との差を断定するとは限らない。

相対誤差は基準値が0でない場合に

relative_error = |x - x_ref| / |x_ref|              (4.8)

と書ける。x_refが小さい箇所や波形の開始点では、相対誤差が不安定になるため、絶対誤差、フルスケールに対する誤差、時定数推定値の誤差など、目的に合う指標を選ぶ。

4.2　パラメータの不確かさ

τ=RCでは、抵抗と容量の許容差が時定数へ伝わる。小さな相対変化なら、独立な不確かさu_R、u_Cに対して

u_τ/τ ≈ sqrt((u_R/R)^2 + (u_C/C)^2)                 (4.9)

と近似できる。これは線形化した近似であり、許容差の分布、温度係数、相関を無視している。部品のデータシート値を測定値の代わりに書かず、「仕様上の不確かさ」と「今回の個体を測った結果」を別に保存する。

4.3　収束を見る方法

刻み幅をΔt、Δt/2、Δt/4と減らし、同じ評価時刻で数値解を比較する。値の変化が許容幅内へ入ることは収束の証拠になるが、解析解が正しいことやモデルが現実を表すことの証明ではない。評価時刻が刻みの端にない場合は、補間方法も記録する。

測定値には同じ意味の「刻み幅半減」はない。サンプリング周波数を上げても入力抵抗、帯域、ノイズ、部品のばらつきは自動的に消えない。計算の収束と実験の再現性を混同しない。

5　同じRCを四つの方法で記録する

5.1　固定する入力

比較の基準例を次のように固定する。

R   = 1_000 ohm
C   = 1e-6 farad
V_s = 5 V
V_0 = 0 V
τ   = 1e-3 s

ここで使うのは教育用の理想値である。book run 4 1の実験が実装されるまでは、以下の数値を実測結果として扱わない。計算例の期待値と、実行して得られたログは別ファイルにする。

5.2　共通の時刻軸

四つの結果を比較するには、入力の定義と時刻軸をそろえる。

方法入力時間出力隠れているもの
解析解理想ステップ連続t式(4.3)解法の仮定、理想部品
Euler/RK4同じステップnΔt離散配列刻み幅、丸め、更新式
SPICE電圧源モデル適応刻みを含む節点電圧素子モデル、ソルバ設定
測定実際の源波形サンプル時刻ADC/オシロ値負荷、帯域、ノイズ、量子化

SPICEが自動的に選んだ時刻を比較に使うなら、解析解をその時刻へ評価する。測定波形を比較するなら、実際に測定した入力波形を使ったシミュレーションも別に行う。理想ステップで計算した線を、有限立上りの実測入力へそのまま重ねない。

6　実験1：RC過渡応答の比較

6.1　実験の問い

同じ理想RCの条件について、解析解、Euler法、RK4、SPICEがどの程度一致するか。刻み幅を変えたときの差は数値誤差か、測定器の入力抵抗を加えたときの差はモデル変更か。これらを一つのグラフで隠さず、表とログへ分けて記録する。

6.2　手順

  1. R、C、V_s、V_0、計算区間、単位を入力manifestへ保存する。
  2. 式(4.3)を共通時刻軸で評価し、解析解の列を作る。
  3. Δt/τ=0.2、0.05など複数のEuler条件で更新し、同じ時刻の解析解との差を計算する。
  4. RK4を同じ刻み幅で実行し、Eulerとの差だけでなく解析解との差を計算する。
  5. 同じ部品値と入力定義のSPICE netlistを実行する。ソルバが採用した時間点と設定を保存する。
  6. 測定を行える場合だけ、実際の入力波形、プローブ設定、計器情報、校正状態を記録する。物理測定ができない場合は、その列を「未測定」とする。
  7. 時定数、t=τでの電圧、最大絶対誤差、最大相対誤差、収束表を方法ごとに保存する。
  8. 解析解、数値解、SPICE、測定の凡例と状態をHTMLへ表示する。実測していない系列を測定色で描かない。

6.3　期待値と観測値の境界

固定値から、τ=0.001 s、理想ステップのt=τでV_C≈3.16 Vという期待値は計算できる。これはこの本文から導いた予測値であり、現在のワークスペースでbook run 4 1を実行して得た観測値ではない。SPICEや実機で異なる値が出たときは、まず単位、入力波形、初期値、部品値、ソルバ設定、測定負荷を確認する。

7　変更課題と故障診断

7.1　変更課題：測定器を接続する

理想RCにR_in=10 MΩ、C_in=10 pFのプローブを追加する。R_inを並列抵抗、C_inを入力容量とする簡略模型で、どの極が追加されるかを図と式で記録する。抵抗値の比だけを見て「影響なし」と結論せず、対象のτと測定器の時間尺度を比較する。

7.2　故障診断：単位は合うが波形が壊れる

次の更新は、単位を秒へ換算せずにdt_msを使っている。

tau_s = R_ohm * C_farad
dt_ms = 0.2
v = v + dt_ms * (Vs - v) / tau_s

dt_msがミリ秒の数値、tau_sが秒の数値なので、数式に書かれた物理単位は一致していない。dt_s=dt_ms*1e-3とするか、すべてを秒で入力する必要がある。修正後も、dt_s/tau_sが安定性の範囲にあること、Vsとvが同じ電圧単位であることを確認する。

7.3　故障診断：解析解へ測定値を無理に合わせる

有限立上りの入力、出力抵抗、プローブ負荷を持つ実測波形を、理想ステップの式へ直接フィットしている場合、ずれを「ノイズ」とだけ呼んではいけない。入力波形を記録し、回路と測定器を含むモデルを作る。フィットしない理由が部品値の誤差なのか、モデルの不足なのか、測定器の帯域なのかを別の仮説として試す。

8　次章への引き渡し

次章では、RCという回路素子をいったん離れ、電荷と電荷の周囲にある電場を定義する。本章から次を引き渡す。

  • 観測値は、対象そのものではなく測定経路を通った記録である。
  • 解析解、数値解、SPICE、測定は、同じグラフへ描いても出所と仮定が異なる。
  • R、C、V、tには単位を付け、入力、初期条件、時間軸を保存する。
  • 収束、丸め、測定ノイズ、パラメータ不確かさ、モデル不足は別の欄で診断する。
  • book run 4 1の実行結果を得るまでは、artifactの予測欄を実測欄へ移さない。

電場はベクトルであり、プローブの先端が測る電圧は基準との差である。後の章では、向き、境界、基準、積分面を明示しながら、観測と模型の境界をさらに押し広げる。

用語の短いまとめ

  • 解析解: 仮定した連続方程式を、式として解いた結果。
  • 数値解: 方程式を有限刻み・有限精度で近似した結果。
  • 測定: 対象と計器の相互作用を含む観測結果。
  • サンプリング: 連続時間の信号を一定または選択した時刻で取り出すこと。
  • 量子化: 連続振幅を有限個の数値へ丸めること。
  • 打切り誤差: 近似式で有限の項・刻みを使ったことによる誤差。
  • 丸め誤差: 有限桁の表現と演算による誤差。
  • 不確かさ: 値のばらつきや知識の限界を、根拠と範囲付きで表すもの。
  • artifact: 入力、方法、出力、版、状態を再現可能な形で保存した成果物。

4.実践ケースブック　宣言から観測へ

このケースブックは、観測、測定、数値計算の中心問題「現実の回路とシミュレータの波形が同じに見えても、何が異なるのか。」を、manifestに宣言された入力から追い直すための作業欄である。本文の結論を写すのではなく、入力、途中状態、出力、境界、出所の順に自分で埋める。ここにない値を補ってはいけない。

  1. case名と入力を最初に固定する。数値には単位、bit列には幅、状態には初期条件、sourceには版を付ける。
  2. 途中状態を一つだけ更新し、更新前後を表にする。式の左辺と右辺の次元、レジスタの幅、stackの深さ、回路端子の向きを照合する。

反例は、正常例を否定するためではなく、契約の範囲を見つけるために作る。次の各項目は、入力、最初に破綻する層、期待する診断、後段を止める理由を一組で書く。

5　模型の境界と章間の橋

この章の模型は、適用範囲を明示して初めて安全に使える。次の限界を一つずつ、本文のどの主張に効くかと一緒に読む。

  • 解析解は理想部品、線形性、集中定数、入力、初期値の仮定に限る。
  • Euler法やRK4の次数は、丸め、ノイズ、モデル誤差、急変入力を消さない。
  • Eulerの安定性条件は、この一次線形RC更新の目安であり、任意の回路や非線形系へそのまま適用しない。
  • SPICEの波形は選んだ素子モデルとソルバ設定の結果であり、実測の代替ではない。
  • 有限帯域、入力抵抗、入力容量、サンプリング、量子化を無視した値は、観測対象そのものと同一視しない。
  • ナイキスト条件は帯域制限などの前提を含み、急峻なステップや非帯域信号を無条件に復元しない。
  • パラメータ不確かさの線形伝播式は、相関、非線形、温度変化、分布の裾を含まない。
  • 解析adapterのRC契約出力は生成済みだが、SPICE比較と実測は未実行であり、本文の期待値を観測値として扱わない。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

途中で予測と結果が異なったら、最後の行から修正しない。入力、仮定、更新、表現、実行環境の順に一つずつ戻り、最初に不一致になった行へ診断名を付ける。診断名を付けられない差は、未解決として後段へ渡さない。

9　逆向きに説明する

今度は出力から出発し、どの入力と規則が必要だったかを逆向きに書く。画面の文字、論理値、レジスタ値、電圧、エネルギーのように異なる表現を、途中のartifactなしで直接つないではいけない。各矢印のそばに、保証する契約と保証しない詳細を一つずつ書く。

逆向きの説明で最初に見つかる欠落は、たいてい三種類のどれかである。入力の単位または幅がない、モデルの適用条件がない、または実行と測定の境界がない。この章の本文へ戻り、欠落を埋める行を一つ追加する。

10　再現記録の最小形

再現記録には、章ID、実験ID、case、入力hash、toolまたはmodelの版、終了コード、出力artifact、source_kind、status、measuredを残す。時刻やhost名は再現性の補助情報であり、計算値や状態遷移の一部として扱わない。

この最小形を満たせないときは、実験が難しいのではなく、契約がまだ閉じていない。閉じていない契約は、成功結果を保存するより先に、未指定欄と診断欄を保存する。

11　次章の読者への引き継ぎ文

最後に、次章の読者がこの章を読み返さなくても前提を再構成できる引き継ぎ文を書く。第一文はこの章が固定した定義、第二文は代表入力と途中状態、第三文は守る不変条件、第四文は最も近い破綻条件、第五文は未実行または未照合の境界である。

引き継ぎ文の主語を『この値は』だけにしない。『この模型では』『この版のtoolでは』『このmemory領域では』『このsource spanでは』のように、値の所有者を明記する。所有者が変わるところが、章間のbridgeであり、独立レビューが最初に読む境界である。

引き継ぎ文を書いたら、manifestの bridge_in と bridge_out、handoffのopen question、required artifactを照合する。本文に書いた橋と台帳の橋が異なる場合は、どちらかを勝手に合わせず、差分を未解決として残す。

第9章　回路という近似

1　同じ配線を二つの模型で見る

1 mの配線に、立上り時間1 nsの電圧変化を加える場面を考える。配線中の電磁場が伝わる速さを、計算用にv_p=2.0×10^8 m/sと置くと、端から端までの伝搬時間は

t_prop = ℓ/v_p = (1 m)/(2.0×10^8 m/s) = 5.0 ns

となる。この5.0 nsは、入力の1 nsより長い。配線の全点が同じ瞬間に同じ電圧になると仮定する集中定数模型は、この設定では慎重に使わなければならない。

一方、長さを1 cmにすればt_prop=50 psであり、1 nsに比べて十分短い。配線を同じ一本の線として描いても、線の長さと信号の時間尺度が変わると、隠してよい空間の情報が変わる。

ここで示した数値は、章の予定計算に使う入力から得た解析予測であり、実際の配線を測った結果ではない。目的は「何nsなら必ず集中定数」と暗記することではない。空間に分布した電場・磁場・電荷を、抵抗R、コンデンサCなどの少数の値へ置き換える前に、隠す情報が応答時間へ影響するかを検査することである。

本章の中心問題は次である。

空間に広がる電磁場を、回路図の線と素子へ置き換えてよいのはいつか。

第8章では、局所の導電率σと電場EからJ=σEを作り、均一な線材をR=L/(σA)へ縮約した。本章では、その縮約を時間変化する信号へ広げる。短い配線を一つの抵抗・容量へまとめる場合と、配線を多数の小区間に分ける分布定数線路（distributed-parameter line）を比較し、長さまたは立上り時間を変えたときの差を予測する。

今回の到達点

読み終えた時点で、次をできるようにする。

  • 集中定数模型と分布定数模型で、空間の変数をどこまで残すか説明する。
  • 単位長さあたりのR'、L'、G'、C'を、電圧・電流の局所収支へつなぐ。
  • 伝搬時間と立上り時間の比から、集中定数近似を疑う条件を作る。
  • 同じ入力を集中RCと分布線路へ与えたとき、出力の遅れ・丸まり・反射を「予測」として比較する。
  • 測定器、終端、境界条件、配線の寄生要素を、物性値や回路素子と別の原因として診断する。

数式の値は、解析値、数値予測、測定値を混ぜない。runnerの解析・契約結果が実測でないことも、実験結果の一部として記録する。

2　線を消す模型、線を残す模型

2.1　電磁場を回路図へ要約する

本当の配線には、各位置xと時刻tで異なる電場E(x,t)、磁場B(x,t)、電荷密度、電流密度がある。第6章の

E = -grad(phi)

という関係は、電位を空間の関数として読む入口だった。第7章の電流密度Jも、断面や位置によって変わり得る。配線を回路図の一本の線へ描くときは、この空間依存性を省略し、端子の電圧V(t)と電流I(t)の関係へ要約する。

この要約には少なくとも二つの段階がある。

模型状態として残すもの隠すもの使う場面
集中定数端子電圧、枝電流、素子のR,C,L素子内部と配線上の位置依存伝搬時間が応答時間より十分短いとき
分布定数V(x,t),I(x,t)、単位長さ定数原子スケールの細部、三次元場の一部配線の場所ごとの遅れ・反射が効くとき

集中定数という言葉は、電磁場が存在しないという意味ではない。回路の選んだ状態変数へ、場の効果を積分して集めたという意味である。逆に、分布定数線路を使えばすべての電磁現象を説明できるわけでもない。断面形状、誘電体、損失、放射、モードの情報を、線路の係数へさらに平均している。

2.2　集中定数のRC模型

入力電圧V_s(t)、抵抗R、コンデンサCを直列につないだRC回路では、集中定数の仮定により、抵抗の端子電圧とコンデンサの端子電圧を同じ時刻の少数の値で表す。抵抗の電流とコンデンサの電流が等しいと置けば、第6章・第7章の関係から

I_R = (V_s - V_C)/R
I_C = C dV_C/dt
I_R = I_C

となる。ステップ入力、一定のRとC、指定した初期値のもとでは、時定数τ=RCと、レジストリのrc_responseで管理する解

V_C(t) = V_final + (V_initial - V_final) exp(-t/(R C))

を使える。Rの単位はΩ、Cの単位はFなので、RCは秒である。C dV/dtは、レジストリのcapacitor_currentに対応し、単位はAになる。

この式は、信号が配線のすべての場所へ瞬時に届くという規則ではない。入力とコンデンサの端子が一つの状態変数で表せるほど、配線の伝搬・反射・寄生容量を無視できる場合の模型である。Rへ配線抵抗を含めるのか、別の素子として残すのかも、回路の契約で決める。

2.3　集中定数近似の判定を先に置く

配線の長さをℓ、信号の変化が進む速さをv_p、入力の立上り時間をt_riseとする。伝搬時間の定義は

t_prop = ℓ/v_p                                      (9.1)

である。判定に使う比を

κ = t_prop/t_rise                                   (9.2)

と置く。κが十分小さいなら、線の端から端までの遅れを一つの回路状態へまとめる候補になる。κが1に近い、またはそれより大きいなら、線の途中の電圧・電流を残した分布模型を試す。

ここで「十分小さい」を普遍的な定数としない。許容する時間誤差、出力の場所、反射の大きさ、測定帯域によって境界は変わる。教育用の予定実験では、κ≤0.1を集中定数候補、κ=0.5を境界、κ≥1を分布効果を明示する条件としてラベル付けする。このラベルは設計契約であって、自然法則そのものではない。

3　分布定数線路の局所収支

3.1　単位長さあたりの四つの係数

均一な二導体線路の小区間dxを考え、次の値を単位長さあたりで置く。

記号意味単位小区間dxでの量
R'直列抵抗Ω/mR'dx
L'直列インダクタンスH/mL'dx
G'並列漏れコンダクタンスS/mG'dx
C'並列容量F/mC'dx

R'とL'は、線路の長さ方向に電流が進むときの電圧降下へ寄与する。G'とC'は、二導体間の電圧に応じて横方向へ流れる電流、または電荷を蓄える効果を表す。この四つは物質や形状から求める係数であり、任意の配線に同じ値を当てはめてよい定数ではない。

本章で用いる線形・一様な模型では、電圧V(x,t)と電流I(x,t)を、正のx向きを基準に定義する。電圧の正端子、電流の正方向、線路の始点と終点を先に固定しないと、式の符号を比較できない。

3.2　小区間の電圧収支

xからx+dxまでの区間で、正方向の電流をI(x,t)とする。直列抵抗による電圧降下はR'dx I、インダクタンスに蓄積される磁気エネルギーの変化による降下はL'dx ∂I/∂tである。したがって、区間の両端電圧の差を一次のdxまで残すと、

V(x,t) - V(x+dx,t)
  = R' dx I(x,t) + L' dx ∂I(x,t)/∂t

となる。左辺をdxで割ってdx→0の極限を取ると、

∂V/∂x = -R' I - L' ∂I/∂t                 (9.3)

を得る。これは電圧を一つの数へ「消した」式ではない。各位置の電圧の変化率を、局所の直列損失と磁気的な蓄積へ結び付けている。

3.3　小区間の電流収支

同じ区間で、xから入る電流とx+dxから出る電流の差は、並列漏れとコンデンサへ流れる電流になる。二導体間の電圧をVとすると、漏れ電流はG'dx V、蓄積電流はC'dx ∂V/∂tである。第7章の電荷保存をこの小区間へ適用して、

I(x,t) - I(x+dx,t)
  = G' dx V(x,t) + C' dx ∂V(x,t)/∂t

と書く。極限を取ると、

∂I/∂x = -G' V - C' ∂V/∂t                  (9.4)

となる。式(9.3)と式(9.4)をまとめてテレグラフ方程式（telegrapher's equations）と呼ぶ。レジストリのcontinuity_equationとcapacitor_currentを、線路の単位長さへ展開したものと読める。

R'、L'、G'、C'をすべて0にすることは、線路が何も伝えないという意味ではない。損失を無視する理想化になり、電圧・電流の波が伝わる別の式が残る。

3.4　損失を無視した波の速さと特性インピーダンス

R'=0、G'=0で、L'とC'が正の一定値だとする。式(9.3)をxで微分し、式(9.4)を使うと、

∂²V/∂x² = L' C' ∂²V/∂t²                  (9.5)

が得られる。同じ形の式はIにも現れる。この模型の伝搬速度を

v_p = 1/sqrt(L' C')                         (9.6)

と置く。単位は、L'C'が(H/m)(F/m)=s²/m²なので、v_pはm/sである。

進行波の電圧と電流の比を特性インピーダンス（characteristic impedance）Z_0と呼び、損失のない線路では

Z_0 = sqrt(L'/C')                            (9.7)

となる。Z_0の単位はΩである。これは「線路の両端に置く抵抗が常にZ_0」という意味ではない。負荷がZ_0に一致する場合に、理想化した進行波が端で反射しないという境界条件へ使う値である。

式(9.5)〜(9.7)は本章で新たに使う式であり、book-spec/equation-registry.yml の lossless_wave_equation、lossless_line_wave、characteristic_impedance に対応する。本文では、単位、損失を捨てた仮定、始端・終端の条件を必ず式と一緒に保存する。

4　集中RCと分布線路を同じ入力で比べる

4.1　比較用の計算模型

二導体線路の長さをℓ=1.0 mとし、次の値を「計算用の模型パラメータ」として置く。

R' = 50 Ω/m       L' = 250 nH/m
G' = 0 S/m        C' = 100 pF/m

G'=0は漏れを無視する仮定であり、絶縁が完全という測定事実ではない。このとき全長を一つへまとめる集中模型は、

R_lumped = R'ℓ = 50 Ω
C_lumped = C'ℓ = 100 pF

と置ける。L'も残すなら集中RLCだが、ここでは「抵抗と容量が支配的な遅い応答」と「線路としての伝搬」を比較するため、集中RCを基準にする。集中RCの時定数は

τ_lumped = R_lumped C_lumped = 5.0 ns

である。

同じL'とC'から、損失なしの計算上の伝搬速度と特性インピーダンスは

v_p = 1/sqrt((250×10^-9)(100×10^-12)) = 2.0×10^8 m/s
Z_0 = sqrt((250×10^-9)/(100×10^-12)) = 50 Ω

となる。これは入力値からの予測であり、実際の基板やケーブルの測定値ではない。

立上り時間をt_rise=1.0 nsに固定し、長さを変える。v_pを一定とする単純模型では、

0.010 m0.050 ns0.050集中定数候補
0.10 m0.50 ns0.50境界・両方を比較
1.0 m5.0 ns5.0分布効果を明示

と予測する。短い線では、端子のRC波形だけを見れば一つの指数関数に近いと期待できる。長い線では、入力端と負荷端が異なる時刻に変化し、途中の反射や線路損失を無視したRCの波形からずれる可能性がある。

4.3　立上り時間を変えた予測

長さℓ=1.0 mを固定し、立上り時間を変える。

t_riset_propκ判断ラベル
100 ns5.0 ns0.050集中定数候補

同じ線でも、ゆっくり変わる信号なら空間の遅れが応答全体に対して小さくなり、集中模型が使いやすくなる。線の性質だけで近似が決まるのではなく、線と入力の組で決まる。

4.4　終端と反射を別の原因として残す

線路の終端抵抗R_LがZ_0と一致しないとき、端で電圧・電流の境界条件が変わる。終端が開放なら電流はその端で流れにくくなり、短絡なら電圧差が小さくなる。どちらも、抵抗Rと容量Cだけの一つの指数応答へ無条件に押し込める現象ではない。

同じκでも、終端、入力源の抵抗、測定器の入力容量が異なれば波形は変わる。反射を見つけたら、まず「長さの分布効果」と「終端・測定器の境界条件」を分けてログへ書く。波形が滑らかだから集中定数、波形に段差があるから分布定数、と見た目だけで分類しない。

入力の最終値 = 1.0 V
立上り時間 = 1.0 ns
終端抵抗 R_L = 50 Ω, 1.0 kΩ, open の三条件
区間数 N = 10, 100, 1000 の比較

期待するのは実測結果ではなく、次の解析・数値予測である。

  • R_lumped=50 Ω、C_lumped=100 pF、τ_lumped=5.0 nsとなる。
  • v_p=2.0×10^8 m/s、t_prop=5.0 ns、κ=5.0となり、1 ns入力では分布効果を明示する条件になる。
  • R_L=50 Ωは計算上のZ_0と一致するため、理想損失なし線路の反射を小さくする境界条件になると予測する。
  • R_L=1.0 kΩと開放終端では、負荷端の電圧・電流の時間波形が一致終端と変わると予測する。
  • ℓ=0.010 mまたはt_rise=100 nsではκ=0.050となり、集中RCとの比較差が相対的に小さくなると予測する。
  • Nを増やしたとき、同じ分布方程式を適切な刻み幅で解ければ、出力波形の離散化差を評価できる。

必要なartifactは、入力と式の台帳、集中RCと分布線路の時系列、比較図、負のテストログである。各行へsource_kind: analytic_predictionまたはsource_kind: runner_result、measured: false、environment、model、length_m、rise_time_sを保存する。実際に測ったオシロスコープ波形を追加する段階では、source_kind: measurementを別行または別ファイルへ置く。

5.3　実装の骨格と負のテスト

本文の次のコードは、入力の意味と状態を確認するための実装骨格である。執筆時点の実行ログではない。

from dataclasses import dataclass


@dataclass(frozen=True)
class LineModel:
    length_m: float
    r_per_m_ohm: float
    l_per_m_h: float
    g_per_m_s: float
    c_per_m_f: float
    rise_time_s: float

    def check(self) -> None:
        if self.length_m <= 0:
            raise ValueError("length_m must be positive")
        if self.rise_time_s <= 0:
            raise ValueError("rise_time_s must be positive")
        if min(self.r_per_m_ohm, self.l_per_m_h,
               self.g_per_m_s, self.c_per_m_f) < 0:
            raise ValueError("per-length parameters must not be negative")
        if self.l_per_m_h == 0 or self.c_per_m_f == 0:
            raise ValueError("lossless wave estimate needs L' and C' > 0")

    def prediction(self) -> dict[str, float]:
        self.check()
        vp = 1.0 / (self.l_per_m_h * self.c_per_m_f) ** 0.5
        t_prop = self.length_m / vp
        return {
            "r_lumped_ohm": self.r_per_m_ohm * self.length_m,
            "c_lumped_f": self.c_per_m_f * self.length_m,
            "t_prop_s": t_prop,
            "kappa": t_prop / self.rise_time_s,
            "status": "analytic_prediction_recorded_measurement_not_run",
        }

負のテストは、物理的な条件変更と入力エラーを混ぜない。

  • length_m=0、rise_time_s=0、負のR'やC'は入力エラーとして拒否する。
  • L'=0またはC'=0で式(9.6)だけから速度を出そうとするのは、適用範囲外として拒否する。
  • C_per_m_f=100のようにpF/mをF/mへ直さない場合は、単位故障として記録する。
  • Nを増やしてもdx=ℓ/Nを更新しない場合は、区間ごとのR'dx,C'dxが変わらない故障である。
  • 終端を50 Ωから1 kΩへ変えることは正常な条件変更であり、失敗とは呼ばない。
  • source_kindをmeasurementへ書き換えて実測のない波形を通すことは、値の計算とは別のprovenance故障である。

6　結果の読み方と模型の境界

6.1　集中定数の成功は、場がない証拠ではない

集中RCの曲線と分布線路の曲線が、ある条件でよく重なったとする。それは、選んだ出力、帯域、誤差許容幅の範囲で、分布した情報を一つの状態へ隠しても契約を満たせたという意味である。電磁場が存在しない、または配線上のどの点も同じ電圧だという証明ではない。

逆に、曲線がずれたときも、すぐに式の間違いと決めない。次の順で原因を切り分ける。

  1. ℓ、v_p、t_riseの単位と、κの計算を確認する。
  2. R',L',G',C'から区間値を作るとき、dxを一度だけ掛けたか調べる。
  3. 入力源の抵抗、負荷、測定器の容量と、始端・終端の境界条件をログで確認する。
  4. Nとdtを変え、離散化誤差・数値安定性・模型差を分離する。
  5. 最後に、そもそもの線路係数が対象の配線を表しているかを問う。

6.2　電力の行き先を一つのVIへ閉じない

第7章の端子電力P=VIは、指定した端子極性と電流方向で素子が吸収・供給するエネルギーを表す。分布線路では、電力は場所ごとのV(x,t)とI(x,t)、導体損失、誘電体損失、電磁場のエネルギーとして移動・蓄積する。場のエネルギー流束は、レジストリのpoynting_theoremで扱う

∂u_em/∂t + div(S) = -J·E

のような収支に残る。ここでも、集中回路のVIと分布場のSを同じ単位の量として扱わない。集中模型にまとめた後でも、どの領域のエネルギーを数えたかを明示する。

6.3　この章で捨てたもの

本章の線路模型は、次を仮定または省略している。

  • 断面形状と媒質が一様で、単位長さ定数を位置に依存しないとした。
  • 線路をTEMに近い二導体系として扱い、放射・高次モード・複雑な三次元境界を係数へ押し込めた。

*R',L',G',C'を線形で、指定範囲の周波数に対して一定とした。表皮効果・誘電損失・分散があれば周波数依存を残す必要がある。

  • 式(9.5)〜(9.7)ではR'=G'=0という損失なし近似を使った。実線路の減衰を説明する式ではない。
  • 集中RCでは、配線上の遅れ、反射、配線インダクタンス、分布容量、測定器負荷を、選んだR,Cへまとめた。

*κ≤0.1などのラベルは、許容誤差と観測箇所を指定して初めて意味を持つ設計上の目安である。

  • 外部tool・実機測定を伴わない表・図・期待値は、数値予測であって、実物の測定・校正・検証済みのモデルではない。

7　次章への引き渡し

本章では、局所の導電率から抵抗を得た第8章の縮約を、時間変化する配線へ進めた。集中定数模型では端子の少数の状態へまとめ、分布定数模型ではV(x,t)とI(x,t)を残す。伝搬時間と立上り時間の比κ、線路の四つの単位長さ定数、始端・終端を、近似の成立条件として保存した。

さらに後の第11章ではR,C,Lに時間発展を持たせ、第12章では周波数、反射、雑音、伝送線路をより詳しく扱う。本章の予定実験が実行され、runnerの出力が独立確認されるまでは、κの分類も、集中RCとの差も、計算模型に対する予測として扱う。

9.実践ケースブック　宣言から観測へ

このケースブックは、回路という近似の中心問題「空間に広がる電磁場を、回路図の線と素子へ置き換えてよいのはいつか。」を、manifestに宣言された入力から追い直すための作業欄である。本文の結論を写すのではなく、入力、途中状態、出力、境界、出所の順に自分で埋める。ここにない値を補ってはいけない。

5　模型の境界と章間の橋

この章の模型は、適用範囲を明示して初めて安全に使える。次の限界を一つずつ、本文のどの主張に効くかと一緒に読む。

  • 集中定数模型は電磁場がないという意味ではなく、選んだ端子契約へ空間情報を積分した近似である。
  • 分布定数線路も三次元電磁場の完全解ではなく、断面・媒質・モード・放射を単位長さ係数へ縮約している。
  • t_prop/t_riseの閾値は許容誤差、観測位置、終端、測定帯域を含む設計上の目安で、普遍的な境界ではない。
  • テレグラフ方程式は一様・線形・指定周波数範囲のR'、L'、G'、C'を前提とし、表皮効果、分散、非線形、放射を自動的に含まない。
  • v_p=1/sqrt(L'C')とZ_0=sqrt(L'/C')はR'=G'=0の損失なし近似であり、実線路の減衰や複素特性インピーダンスを表さない。
  • 終端抵抗、入力源抵抗、測定器の入力容量は線路係数とは別の境界・負荷であり、同じRやCへ黙って混ぜない。
  • 区間数を増やした分布数値計算の収束は、係数・境界条件・時間刻みが正しいことを単独では保証しない。
  • R=R'ell、C=C'ellの集中化は、線路長、帯域、過渡、配置、寄生素子の条件を分離して初めて使える。
  • 本章のrunnerは固定環境で契約を再生済みだが、図・表の外部tool・実測は未実行であり、本文の数値は計算用入力からの予測である。

8　ひとつの値を最後まで追う

この章で最も小さい代表入力を一つ選び、上位の問いから下位の実装へ、また下位の結果から上位の契約へ往復する。値の名前が層ごとに変わるときは、同じ行に別名を並べ、同一視してよい条件を右側に書く。

最初の行には、入力の出所と固定版を書く。二行目には、本文で導入した式または状態遷移を一つだけ置く。三行目には、式を評価する前の中間状態を書く。四行目には、計算後の値と残差を書く。五行目には、上位の契約へ戻るための不変条件を書く。

単位を持つ量は、数値の横へSI単位または宣言した単位系を必ず付ける。bit列は幅と符号解釈を付け、アドレスは対象memory領域を付ける。状態名は初期状態と更新順を付ける。tokenやASTはsource spanを付ける。これらを省略した値は、数字が同じでも別のcaseである。

途中で予測と結果が異なったら、最後の行から修正しない。入力、仮定、更新、表現、実行環境の順に一つずつ戻り、最初に不一致になった行へ診断名を付ける。診断名を付けられない差は、未解決として後段へ渡さない。

9　逆向きに説明する

今度は出力から出発し、どの入力と規則が必要だったかを逆向きに書く。画面の文字、論理値、レジスタ値、電圧、エネルギーのように異なる表現を、途中のartifactなしで直接つないではいけない。各矢印のそばに、保証する契約と保証しない詳細を一つずつ書く。

逆向きの説明で最初に見つかる欠落は、たいてい三種類のどれかである。入力の単位または幅がない、モデルの適用条件がない、または実行と測定の境界がない。この章の本文へ戻り、欠落を埋める行を一つ追加する。

10　再現記録の最小形

再現記録には、章ID、実験ID、case、入力hash、toolまたはmodelの版、終了コード、出力artifact、source_kind、status、measuredを残す。時刻やhost名は再現性の補助情報であり、計算値や状態遷移の一部として扱わない。

この最小形を満たせないときは、実験が難しいのではなく、契約がまだ閉じていない。閉じていない契約は、成功結果を保存するより先に、未指定欄と診断欄を保存する。

11　次章の読者への引き継ぎ文

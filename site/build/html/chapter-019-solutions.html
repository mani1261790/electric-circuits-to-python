第19章 演習解答

E1

完全解答

正の電場に対し、電子は負電荷なので平均速度v_n=-mu_e Eで−x、正孔は正電荷なのでv_p=+mu_h Eで+xへ動く。電子粒子流束は−xで電荷も−qなので、電子drift電流は+x向き。正孔粒子流束は+xで電荷+qなので、正孔drift電流も+x向きである。速度へそのまま電荷を掛けるのが重要で、電子の速度と電子の慣用電流は反対向きになる。

再挑戦

電場を−xへ反転したとき、四つの矢印をすべて反転させて書け。ただし電子速度と電子電流が逆向きという関係は保つ。

E2

完全解答

J_n=qmu_e nE=(1.602176634×10^-19)(0.10)(1.0×10^21)(100)≈1.602×10^3 A/m^2。J_p=qmu_h pE=(1.602176634×10^-19)(0.05)(1.0×10^20)(100)≈8.011×10^1 A/m^2。合計はJ≈1.682×10^3 A/m^2で、Eが+xなら電流も+x。単位はC·m^2/(V s)·m^-3·V/m=C/(s m^2)=A/m^2。

再挑戦

同じn,p,muでEを10倍にしたとき、drift電流は何倍か。高電場でこの比例が壊れる要因を一つ挙げよ。

E3

完全解答

粒子流束に電荷を掛ける。電子ではJ_n,diff=(-q)(-D_n grad(n))=+qD_n grad(n)、正孔ではJ_p,diff=(+q)(-D_p grad(p))=-qD_p grad(p)。grad(n)>0なら電子粒子は−xへ流れるが、負電荷の電子電流は+x。grad(p)>0なら正孔粒子は−xへ流れ、正電荷の正孔電流も−x。よって電子と正孔のdiffusion電流は、同じ形の濃度勾配でも符号が異なる。

再挑戦

電子濃度が+xに減少する場合grad(n)<0、電子粒子流束と電子diffusion電流がどちら向きになるかを答えよ。

E4

完全解答

Einstein関係D=mu(kBT/q)とkBT/q≈0.02585 Vから、D_n≈0.10×0.02585=0.002585 m^2/s、D_p≈0.05×0.02585=0.0012925 m^2/s。D/muの単位は(m^2/s)/(m^2/(V s))=Vで、右辺もJ/C=V。これは300 K・非縮退・熱平衡近くの予測である。

再挑戦

温度を600 Kへ倍にすると、移動度を固定した模型ではDはどう変わるか。実材料ではmuも温度依存し得ることを注記せよ。

E5

完全解答

0=J_n=qmu_e nE+qD_n grad(n)なので、E=-(D_n/mu_e)grad(n)/n=-(kBT/q)grad(ln n)。濃度が+xへ10%/um増えるならgrad(ln n)≈1.0×10^5 m^-1。300 KでkBT/q≈0.02585 Vなので、E≈-0.02585×1.0×10^5≈-2.585×10^3 V/m、−x向きが目安。指数的に正確な勾配ならgrad(ln n)を直接使う。

再挑戦

正孔で同じgrad(ln p)>0を電流0にする電場の向きを式から求め、電子の場合と比較せよ。

E6

完全解答

電子は∂n/∂t=(1/q)div(J_n)+G_gross-R_gross、正孔は∂p/∂t=-(1/q)div(J_p)+G_gross-R_gross。電子の電荷密度が-qnなので、電荷連続の式を個数nへ直すと電子の発散項が正になる。正孔は+qpなので発散項が負になる。一様電流なら発散0、G_gross=R_grossなら両式とも時間変化0。このときキャリアが動いていないのではなく、局所の流入出と生成消滅の収支が0である。

再挑戦

一様な電子電流が+xへ流れ、G=R=0のとき、電子密度が時間変化しない理由を微分で説明せよ。

E7

完全解答

初期再結合率はR(0)=delta_n(0)/tau=1.0×10^22/(1.0×10^-9)=1.0×10^31 m^-3 s^-1。2 ns後はdelta_n=1.0×10^22 exp(-2)≈1.353×10^21 m^-3。t=tauではdelta_n/delta_n(0)=exp(-1)=1/e≈0.3679。Rも同じ比率で減少する一次模型の予測で、tauは測定値ではなく指定入力である。

再挑戦

2 ns後の再結合率を求め、初期率との比が過剰密度の比と同じになることを確認せよ。

E8

完全解答

分子np-ni^2は密度²、分母tau_p(n+n_1)+tau_n(p+p_1)はs×密度、従ってU_SRHの単位はm^-3 s^-1。平衡np=ni^2では分子0でU_SRH=0。np>ni^2ならU_SRH>0を正味再結合、np<ni^2ならU_SRH<0を正味生成と定義する。SRHは欠陥準位一つを介する模型で、光による放射再結合、三体のAuger再結合、表面再結合などを自動的には含まない。

再挑戦

tau_nを2倍にしたとき、分母のどの項が変わり、他条件固定でUの大きさがどう変わるかを式から説明せよ。

E9

完全解答

for each interior face j+1/2:
    n_face = average_or_limited(n[j], n[j+1])
    grad_n = (n[j+1]-n[j])/dx
    Jn_face = q*mu_e*n_face*E_face + q*D_n*grad_n
    # holes use Jp_face = q*mu_h*p_face*E_face - q*D_p*grad_p
set_boundary_flux(Jn, Jp, kind="no_flux")
for each cell j:
    div_Jn = (Jn_face[j+1/2]-Jn_face[j-1/2])/dx
    n_next[j] = n[j] + dt*((div_Jn/q) + G_gross[j] - R_gross[j])
assert dt <= dx*dx/(2*max(Dn,Dp)) for explicit diffusion case
record charge_balance, positivity, boundary_flux_residual

実装では電子・正孔を別々に更新し、境界の流入・流出を面値で数える。固定濃度接触と無流束境界は同じ設定にしない。陽解法のCFL目安を満たしても、drift項や反応項の制約、負濃度、電荷収支、時間分解能を別に確認する。

再挑戦

格子幅を半分にしたとき、同じ拡散係数で陽解法の許容時間刻みは何倍まで小さくすべきか。計算量とのトレードオフも書け。

E10

完全解答

(a)charge_magnitude_sign_error。q=e>0を入力し、電子の符号は式へ含める。(b)negative_density_input。物理的に非負の個数密度へ修正する。(c)electric_field_unit_mismatch。EはV/m。(d)current_density_unit_mismatch。JはA/m²。(e)equilibrium_residual_failure。平衡条件、n,p,ni、単位を点検する。(f)time_step_instability。dx、D、drift速度、反応時間を使ってdtを下げるか陰解法を選ぶ。(g)positivity_or_charge_balance_failure。clipする前の負値と収支残差を失敗として保存する。clip後だけを成功値にすると、数値不安定性や境界ミスを隠す。

再挑戦

JをA/m^3で保存していた場合、どの物理量と混同した可能性があるか。電荷密度の時間変化の単位と比較せよ。

E11

完全解答

最低限、artifact_id、status、source_kind、measured、inputs（n,p,E,mu_e,mu_h,D_n,D_p,q、recombination_mode、grossを選んだときのG_gross,R_gross、SRHを選んだときのn,p,n_i,n_1,p_1,tau_n,tau_p、dx,dt,boundary_kind、単位、必要なら準Fermiのmu_n,mu_p）、outputs（J_n,J_p,J_total,n_next,p_next、grossならG_gross,R_gross、SRHならU_SRHと源S）、diagnostics（charge_continuity_residual、boundary_flux_residual、positivity、CFL、analytic_relative_error、equilibrium_residual）、equation_ids、runner_version、created_atを保存する。解析式ならanalytic_prediction+predicted、差分を手計算・試作評価した段階ならnumeric_prediction+not_executed、共通runnerが入力由来の契約モデルを生成すればrunner_analytic_contract+executed_analytic、装置値ならmeasurement+measured。共通runnerは実行済みでも実測ではなく、measurement.status="not_run"を維持する。測定なら試料・温度・電極・校正も追加する。

再挑戦

解析予測とrunner出力で温度単位が異なっていた場合、比較前に保存すべき正規化フィールドを三つ挙げよ。

E12

完全解答

第20章へは、n型・p型それぞれのn,p、電子-eと正孔+eの符号、T、移動度、拡散係数、平衡か非平衡かを渡す。接合では濃度勾配によるdiffusionと空間電荷が作る電場によるdriftが同時に現れ、平衡近くで電流が釣り合う条件を使う。空乏層の幅、内蔵電位、金属接触の電位障壁を決めるには、電荷分布と電位を結ぶPoisson方程式、接触境界、バイアスを追加する。キャリア数と局所電流式だけで接合の空間分布を決めない。

再挑戦

第20章へ渡す入力を「キャリア」「輸送係数」「境界」「検証ラベル」に分け、100字以内で書け。
